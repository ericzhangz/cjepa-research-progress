# PRBD 技术报告 · 2026-11-19

在 TwoRoom 作者环境的速度对照中，四个原型吸收一次真实探测后，快慢速度对应的支持分布发生了变化，随后正交动作的预测差平均向真实差异的反方向移动。11 个起点在查询时具有逐像素相同的三帧和相同的近期命令。有向恢复率在 H1 为 **−0.0824%**，在 H4 为 **−0.3281%**。本版包括原始开环记录、拟合参数和逐起点预测。闭环任务成功率未测量。

## 1. 实际计算

PRBD（Native Predictive Response Belief Dynamics）在 LeWM 的同一个冻结预测器上生成四个原型响应。固定零条件的原型使用原生预测，其余三个原型在六个条件块中对最新 token 的动作条件加入可学习偏移。对已经执行的动作，先签发四个后继预测，再用实际到达的编码计算各原型的观测似然。模型对白化后的原型差建立低秩观测模型，以 32 点求积计算共享尺度混合似然。用各原型似然乘以输运后的先验并归一化，得到公共后验。本次速度在单回合内固定，输运矩阵取单位阵。[概率实现](research/p1a/prbd.py) · [原生条件及多步递推](research/p1a/prbd_native.py)

查询另一动作时，四个原型使用相同的实际起点和候选命令，各自递推自己的预测窗口。后验对四条预测加权。若两原型在已执行的动作上签发相同后果，此次到达给它们相同似然，二者相对于**输运后**先验的赔率保持不变。在四原型解析例中，横推动作后两个等响应组的组内赔率都保持 2∶1。一次快横速观察使斜推横向位移预测从 1.250 变为 1.322，反向斜推从 −1.250 变为 −1.322，纯纵推保持。仅将未来动作对应的横速原型交换后，同一证据产生反向修订。此例使用已知的动作响应。[解析例及数值结果](runs/prbd_math_20261119/math.json)

## 3. TwoRoom 速度实验

使用作者环境、渲染、预训练权重及动作归一化。每个模型步包含五个二维原始动作，视觉窗口为三帧。下表的三个划分使用互不重叠的重置种子。标定与拟合取自发布档案的不同动作序列。拟合输入限于单条实际轨迹的 RGB 编码与命令。真实速度、模拟器坐标及跨速度配对仅用于采集和评价。

| 划分 | 采集设置 | 实际用于计算 |
| --- | --- | --- |
| 噪声标定 | 32 个回合，默认速度 5 | 31 个回合提供 413 个一步残差，用于估计 192 维共享协方差。 |
| 原型拟合 | 32 个回合，速度 2.5 和 7.5 各 16 个；每回合最多 16 个动作块 | 30 个回合提供 418 次真实到达。按到达顺序计算边缘负对数似然，每个有效回合执行一次 Adam 更新，共 30 次。拟合后零原型与原生输出逐值相同。 |
| 留出评价 | 16 个起点，各自重复两种速度、两种后续命令，共 64 条轨迹 | 1 个起点在第一个动作块完成前终止；15 个完成 H1–H4，其中 11 个在两种速度下得到相同的查询窗口和命令。4 个完整异窗起点计入全样本统计。 |

留出程序先静止，再沿一条轴探测、反向撤回、静止两块，随后查询一块正交移动或一块停止，两者之后都接三块停止。11 个同窗起点的源探测在两种速度下分别移动 3.125 和 9.375 px。未来正交移动在 9 个起点产生 6.25 px 的速度差；另 2 个起点受边界限制，两种速度产生相同位移。停止命令在全部 11 个起点的 H1 和 H4 实际位移均为 0。[数据清单](runs/prbd_tworoom_speed_20261119/data_manifest.json) · [物理诊断](runs/prbd_tworoom_speed_20261119/data_diagnostics.npz) · [逐回合拟合记录](runs/prbd_tworoom_speed_20261119/fit.json)

## 4. 同一条真实观察传到了哪里

每个起点先算“正交移动减停止”的端点编码差，再算这个动作差在慢速与快速之间的差，记作 \(d_i\)。对预测作同样运算得到 \(\hat d_i\)。表中的有向恢复率为 \(100\sum_i\langle\hat d_i,d_i\rangle/\sum_i\|d_i\|^2\)。0% 对应沿真实差异方向的净分量为零；负号表示聚合投影反向。这是编码空间指标，单位与像素位移及成功率不同。

| 11 个同窗起点，共享候选、共享权重的读出对照 | H1 | H4 |
| --- | ---: | ---: |
| 均匀支持 | 0% | 0% |
| 初始化原型，只写首次探测 | +0.0297% | +0.0536% |
| 拟合原型，只写首次探测 | **−0.0824%** | **−0.3281%** |
| 拟合原型，后续均正常写入，保留首次观察相对仅省略首次观察的增量 | −0.0702% | −0.1974% |
| 拟合原型，固定相同响应与噪声，仅在首次探测改用共享高斯似然 | −0.7212% | −2.1002% |
| 拟合原型，给每个起点的两种速度分别自由分配支持时的最大有向投影（事后计算） | 6.2178% | 20.6111% |

首次探测后，快慢速度的两个后验之间平均总变差距离为 **0.1078**。给同一源动作读回这次观察，可恢复其真实编码差的 **0.4609%**；使用同一后验预报正交动作时，表中两个跨度的有向投影均为负。事后上限使用真实未来选择支持，只描述现有原型能够表达的最大投影。把 4 个异窗起点也计入时，15 个完整起点的 H1 恢复率为写入 **2.5626%**、均匀 **2.6343%**；H4 为 **2.2800%**、**2.5646%**。异窗时，即使不写入，当前画面也能携带速度差。[所有跨度与分组的 CSV](runs/prbd_tworoom_speed_20261119/interaction_summary.csv)

| 同窗样本中的端点绝对误差 | 均匀支持 | 只写首次探测 | 写入后误差下降的起点 |
| --- | ---: | ---: | ---: |
| 正交移动 H1 | 0.208808 | 0.208966 | 4/11 |
| 正交移动 H4 | 0.239970 | 0.239664 | 8/11 |
| 停止 H1 | 0.056158 | 0.056076 | 11/11 |
| 停止 H4 | 0.098797 | 0.097463 | 11/11 |

绝对误差按 192 个编码坐标和两种速度取均值，起点计数用同一起点两种速度的误差和配对。H4 移动的绝对误差和停止误差均有下降，移动与停止之间的速度差仍呈反向修订。这两个指标分别测量端点与真实画面的距离、以及历史造成的动作差是否沿正确方向传递。[拟合后逐起点数据](runs/prbd_tworoom_speed_20261119/fitted_measure.json) · [同初始化对照](runs/prbd_tworoom_speed_20261119/initialized_measure.json)
