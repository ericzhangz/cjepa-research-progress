## 读码速查：两个疑点落实在哪里

**条件偏移确实是共享参数，门控才读当前窗口。** FourRoom 的模式 0 锁下门、开上门，对应模式码 `(1, −1)`；模式 1 相反，码为 `(1, +1)`。两层无偏置线性映射把这两个常量码生成四层的偏移。固定权重后，每层的 \(v_{\ell,\mathrm{bar}}\) 和 \(v_{\ell,\Delta}\) 都不随场景、位置、窗口或动作变。每次预测下一枚 latent 时，第一个 Transformer 块用 \(c+v_{0,\mathrm{bar}}\)，读它的最后一个 token 和同位置的原生动作条件，取出一个 \(\operatorname{ReLU}(2\sigma(q)-1)\)。后三块在各自的原生动作条件上加 \(v_{\ell,\mathrm{bar}}+s\,r\,v_{\ell,\Delta}\)，再进入原有 AdaLN 的 shift、scale 和残差 gate。\(r\) 在这一次原生调用内跨后三层和三枚 token 广播；它按候选、模式窗口和预测步重新计算，不是整条 H5 只有一次开关。两模式的窗口还相同时，同一候选的首块状态和 \(r\) 也相同；递推窗口分开后，\(r\) 可以不同。

这个结构在每层 AdaLN 的输入处只提供一条模式差方向，没有上门、下门各自的空间条件向量。不过原生动作条件和注意力本身依赖输入，固定 \(v_{\ell,\Delta}\) 不等于在所有位置产生相同的 XY 位移，不能从参数化直接推出它表达不了互补门锁。强开检查干预的是**已经训练好的网络**：将后缀模式偏移全量注入，trace 仍保留原始 logits，但 exposure 已被替换为 1；这无法区分当前训练覆盖和表达能力各占多少。

反转档案的三项大数是**固定同一对候选的模式 1 间隔** \(\Delta J_1=J_1(A)-J_1(U)\)，其中 \(A\) 和 \(U\) 分别为原门控下写入和均匀选择的计划。它们不是单条计划因强开增加的绝对代价；查询 42、26 的实际模式还是 0。

| 查询、固定计划 (A,U) | 原门控 \(\Delta J_1\) | 强制 \(r=1\) 的 \(\Delta J_1\) | 模式 1 物理间隔 |
|---|---:|---:|---:|
| 42，(263,321) | +1.0459 | +52.0566 | +4.0741 |
| 26，(213,4) | +5.8769 | +97.1521 | −2.1681 |
| 11，(234,349) | −0.1282 | +80.5423 | +0.4226 |

在上门反转的档案里，原有 13 个写入恶化对中有 8 对的候选间模式差反号；同权重强开只让这 13 对中的 3 对改为偏好实际更好的候选。允许同池重选后，写入相对均匀的整计划遗憾差由 +0.447 变为 +1.025。出处：`runs/native_topology_paired_20261115/writein_attribution_20261116/decision_root_followup/reversal_REPORT.md`，§“固定候选对”及同池重选表。这说明强开不足以解决现有检查点的排序错误。

**真正跑的是三枚历史 token、三块对齐动作、每块五次原始控制。** 记三枚历史 latent 为 \((z_{t-2},z_{t-1},z_t)\)，过去两块为 \((a_{t-2},a_{t-1})\)，候选从 \(a_t\) 开始。H1 按 \((a_{t-2},a_{t-1},a_t)\) 预测 \(\hat z_{t+1}\)；H2 的窗口改为 \((z_{t-1},z_t,\hat z_{t+1})\)，动作也向前滑一格。H3 起同理，每个模式拼接自己的预测。CEM 把一个二维命令复制五次，复制发生在**单个动作块内部**；它不会把当前命令填到三个历史槽。编码动作时逐轴归一化，再把一块的 \(5\times2\) 控制展成 10 维送进宿主的 `action_embed`。真实每块完成后才送入新 RGB；候选自由推演不会中途收到真实 RGB。普通 FourRoom `forecast()` 走独立原生窗口，不传 `ancestry` 或 `reference_action`；下面仍附这两条旧路径的核心代码供辨认。

**RGB、预测头和 XY 读出是三个可分开追踪的接口。** 新布局的 RGB 由同一 FourRoom 环境按新门洞坐标渲染，隐藏锁只在物理碰撞调用内临时生效。在线 RGB 按同样的 ImageNet 通道统计归一，宿主视觉编码及其 projector 产生 `embed_0`；条件预测沿原生四块、Transformer 末尾 `norm → output_proj`、原生 `pred_proj`，从序列中取最后一个输出 token。预测和真实端点在同一 192 维 latent 空间比较。物理 XY 是另一个冻结 MLP 加坐标反归一化（当前新布局读取 `layout_readout.pt`），与上述两个 projector 分开。源码有三帧、四块检查和零偏移等价检查；真实编码的 XY 读出精度也不构成自由预测 latent 的读出保证。

**CEM 读取 H5 解码末点。** 每种解释的 \(J_m(A)\) 是该解释最后一枚自由 latent 解码后的坐标，按可见门中心地图计算的剩余路径长度。房间由 \(x,y=112\) 分隔；坐标落入目标房后，同一代价函数就可以改走房内直接距离。评分不检查预测的中间块是否撞墙。两个 CEM 分量分别按各自的模式代价取精英，合并四轮各 96 条候选后才按当前支持加权两模式的 \(J_m\) 选择；真模式臂把该权重换成 one-hot。实际只执行首块，物理碰撞照常发生。这条链能解释为什么在两个预测解释共享错误时，直接给真模式仍无法救回规划。

**不混用三组证据。** 3.40 px 是冻结官方 checkpoint 在原版设置的 48 个同根动作对上，以独立 P0c 读出得到的 H4 自由位置 RMSE。首布局冻结复播的四条 CEM 选中记录中，H2 的自由预测坐标已侵入可见墙碰撞条带，H3 才进入错误房间；从 H2 读出的坐标再用精确碰撞执行 H3，仍停在 (103,103)。保持权重和动作强开后，这四条仍从 H3 错房。57/64 是另一份西北生命周期的原门控真模式首选假进房，32/64 是另一组独立布局的新 CEM 候选；分别有 28/57 和 17/32 在两模式下均假进房，不能把总计径直称为两模式共同穿墙。两组统计出自 `runs/native_topology_paired_20261115/writein_attribution_20261116/decision_root_followup/REPORT.md` 的分层表。代码和档案支持区分共同预测偏差、条件差方向/幅度、以及首选筛选放大；目前的固定权重对照不能唯一归因到偏移结构、采样、编码器或读出之一。

### 34.2 任务信息价值的正确尺度：不否定旧档案，也不被它绑定

0.539 个覆盖百分点对应 55810–55825 的七候选，每条只有五条原始命令，即 **H1**。它是该菜单、这些实际根和指定均匀规则下真物理模式信息的收益。报告还给出了 6/16 个场景的严格反序候选对和 4/16 个场景的两模式近最优集合不交。因此，“没有任何反序”以及“所有制动任务 H2 的理论上限只有 0.5 点”均不成立。固定菜单在该组没有完成任务，也不能据此推断更长闭环无法完成。[原物理报告](../runs/native_reversible_delivery_20261115/REPORT.md)

对固定根、固定动作集合和跨度，真实代价为 \(C_k(A)\)，信息不足时的模式分布为 \(\pi\)。令
\[
A_\pi\in\arg\min_A\sum_k\pi_k C_k(A),\qquad
V_{\rm info}=\sum_k\pi_k\big[C_k(A_\pi)-\min_A C_k(A)\big]\ge0.
\tag{34.1}
\]
这是有限决策中的完全信息价值，不是新算法。若存在所有模式都最优的同一动作，则该值为零；某对次优候选反序也不保证它大于零。均匀模式规划是在期望代价下选择动作，不等于把左右动作取平均后去撞中间。

即使只有标量减速，也可能产生真实反序。设目标位置为 1、动作位移 \(u\in\{1,2\}\)、代价 \((\alpha u-1)^2\)：开放 \(\alpha=1\) 的代价是 \((0,1)\)，半速 \(\alpha=1/2\) 的代价是 \((1/4,0)\)。均匀规则选 \(u=1\)，知道半速时应选 \(u=2\)。这是纸面反例，不是新的实验环境。

从 §33 继续，设 \(g_k=C_k(A)-C_k(B)\)、\(m=(g_0+g_1)/2\)、\(I=g_1-g_0\)。严格反序条件是
\[
g_0g_1<0\quad\Longleftrightarrow\quad |I|>2|m|.
\]
有两个候选时，混合权重的切换点为 \(p_*=-g_0/I\)，前提是 \(I\ne0\) 且 \(p_*\in(0,1)\)。多候选还须考虑第三个动作是否更优。真正需要记录的是共同排序 \(m\)、模式交互 \(I\) 和支持是否越过有效决策边界，而不是只看模式分类正确率。

旧 PushT 档案仍可用于跨动作物理预测。以同一实际根、固定干预动作 \(A\) 和条件充分的两模式模型为例，设真实条件均值差为 \(D_{A,H}\)，当前窗口与完整合法历史的正确后验分别为 \(p_W,p_{\mathcal H}\)。在模式外未来条件均值不再依赖额外历史的假设下，平方预测风险的降低为
\[
R(W)-R(\mathcal H)=\mathbb E\left[(p_{\mathcal H}-p_W)^2\|D_{A,H}\|^2\right].
\tag{34.2}
\]
这是条件期望的平方分解。即使首选动作不变，历史仍可能改善动作后果预测；实际模型是否做到另需测试。这样可以保留已有档案的技术价值，同时不把它当作正式长程决策的充分证据。

### 34.3 实际训练断点：有多分支目标，但没有整段支持的使用训练

§31 的 `load_fit` 确认各候选和模式的初始 RGB、物理状态相同；`free_batch` 把场景与候选展平，每条候选保留双模式，沿自己预测的 latent 递推四步。`train` 同时学习源相位后果、自由后缀、真实观察和目标的刚体读出，有限证据臂另加源评分约束。因此它既非“仅一路事实训练”，也非“读出始终冻结未训练”。

但该训练函数**不在损失计算中推进多轮公共支持 \(p_t\)**。同根多动作的自由未来来自初始根；中途源过程使用实际窗口。它没有把相关早先观察、无信息中间段、真实反证形成的同一个 \(p_t\)，接到中途实际根的整组候选未来，再由这些未来教早先怎样写入。§17.6 已在纸面定义过这条路径，后来的全层实现没有完整继承。[现行训练](p1a/native_full_depth_paired_effect.py) · [原设计 §17.6](#176-训练直接教这项计算而不是希望模式自行获得语义)

**我的判断：这是一个明确的训练与预期能力之间的缺口，值得沿同一机制补齐；还不能认定它是当前错误的唯一原因。** 给同一模型真模式仍选错的反例，表明只让 \(p_t\) 更准不够。下一次学习要同时训练解释的实际后果与这些后果对合法支持的使用，不能把前者假定为已完成。

仅追加“模式差 MSE”也未必构成新的约束。令同一候选上的两模式物理误差为 \(e_0,e_1\)，则
\[
\tfrac12(\|e_0\|^2+\|e_1\|^2)
=\|\tfrac12(e_0+e_1)\|^2+\tfrac14\|e_1-e_0\|^2.
\tag{34.3}
\]
再对动作求平均，差误差又分成动作均值和中心化方差。§31 的逐模式 MSE 已包含这类监督；同权重重写公式不会改变优化。新增数据覆盖、改变权重或接通真实前缀的梯度是不同干预，应各自说明。

### 34.4 下一项构造：在现有原生路径上接通同一解释的整段使用

保留全层条件预测、逐解释自由窗口、公共支持与精确求值规则。下一项具体作者工作是把下面这条现有但尚未完整实现的关系补成同一训练和部署计算：

\[
\begin{aligned}
\text{合法真实前缀}&\longrightarrow p_t,\\
(W_t,A,k)&\longrightarrow Y_{k,A,H}=Q(F_{\theta,k}^{H}(W_t,A)),\\
(p_t,\{Y_{k,A,H}\})&\longrightarrow
\begin{cases}\text{逐解释代价的支持加权，供部署使用},\\
\text{整组后果训练能量，供离线学习使用}.\end{cases}
\end{aligned}
\tag{34.4}
\]

这里必须保留真实依赖关系：现有逐解释转移 \(F_{\theta,k}\) 不直接读取 \(p_t\)，支持在后果分布、期望代价及学习目标处参与；各解释的下一步仍从自己的 latent 出发，不用加权均值替换窗口。这也说明接通训练链尚不等于发明了新的内部调节算子。

部署时先预发实际动作，再按到达顺序消费观察；公共支持跨真实轮次延续。每次候选查询使用同一份支持，每个解释沿自己的预测窗口推进。假想未来不修订公共支持。多轮里真实条件可能保持或切换；未来窗口内如果允许条件切换，必须明确采用哪一种转移预测，不能把所有长后缀默认成“该模式永远不变”。第一台阶限定未来短后缀内条件不变，切换发生于实际交互，后续新证据修订支持。

**离线怎样教这条链。** 以一条实际发生过的历史形成 \(p_t\)，在该历史最终的同一物理根、同一实际条件下独立执行候选后缀。对每个解释 \(k\) 汇总其对这整组真实后果的误差 \(E_{t,k}\)，再用 §17.6 的训练能量
\[
\mathcal L_{\rm use}(t)=-\log\sum_k p_{t,k}e^{-E_{t,k}},\qquad
r_{t,k}=\operatorname{softmax}_k(\log p_{t,k}-E_{t,k}).
\tag{34.5}
\]
后缀必须先在同一个 \(k\) 下聚合。所有解释面对**同一实际条件的那组目标**；不能让解释 0 对真模式 0 的标签、解释 1 对真模式 1 的标签各自求误差，再把两者混成当前事实的责任。另一真实模式的标签可作直接配对监督，或由另一条真实历史构成自己的训练组。

下一实施保留现有直接真模式配对监督，承担物理分支的身份与绝对后果约束；组能量承担合法支持的后续使用。后者本身仍容许坍缩或不同根的身份重映射，不以一次组训练便保证可辨识性。两项的职责不同，不把现有逐模式监督删除后再把重新学到分化当成新能力。

对支持的未归一化 logits，梯度是 \(p_t-r_t\)，对能量的梯度是 \(r_t\)。它同时作用于早先真实源预测和未来原生后缀；此处不 detach 支持。真实后缀只提供训练标签和反向梯度，离线责任 \(r_t\) 不成为部署输入。源似然继续接受实际到达的适当评分约束，避免只为某个未来菜单调出过度自信的支持。相关时域的平均误差是复合训练能量，不宣称是多个独立未来的精确联合密度。

两动作手算说明与逐候选混合的区别：令各动作的双解释能量分别为 \((0,M)\)、\((M,0)\)，先验均匀。逐候选分别混合的平均损失在大 \(M\) 时接近 \(\log2\)，可由不同解释分别解释；先按解释取整组平均则得到 \(E=(M/2,M/2)\)，损失为 \(M/2\)。若两动作都由同一解释解释，组损失又接近 \(\log2\)。这恢复了原设计中“同一事实支撑同一解释”的学习要求。**共同潜变量的组训练是已有工具，不是本项目的新核心公式；现有模式标注配对也已提供一部分身份约束。**

训练组同时覆盖保持、暂时无关、重新相关、真实反转，才能使正确保留和修订都有后续用途。无区分力的历史不被要求提前猜对隐模式；只有不变条件的样本不能教会反转。已使用的旧档案用于定位与回归，新训练组和留出组在协议确定后分开，不能把已看过的中途根重新称作独立确认。

**同一个原生对象怎样连接源和未来。** 固定实际刷新后的窗口和候选，将源端可见差记为 \(d_s\)、未来物理差记为 \(D_{A,H}\)。此处 \(p^+\) 专指吸收该次观测后、尚未再做模式转移的即时后验。在单相位、两模式共协方差 Gaussian、固定先验及可见区域的条件下，后验均值对源观察的局部响应是
\[
\frac{\partial\bar Y^+_{A,H}}{\partial y_s}
=p^+(1-p^+)D_{A,H}d_s^\top\Sigma^{-1}.
\tag{34.6}
\]
由对数似然比导数 \(d_s^\top\Sigma^{-1}\) 与 logistic 导数直接得到。若候选读取前又以对称切换概率 \(\rho\) 推进权重，响应还需乘以 \(1-2\rho\)，不可把转移后的权重直接代进即时 logistic 导数。多相位用条件新息；此式固定刷新窗口，只隔离支持路径，不包含新画面改变窗口的直接作用。所有 \(A,H\) 共用实际经历形成的支持，源差与未来差由同一组原生解释生成。源能区分而未来差为零时不改变后果；源和未来局部身份错配时可朝错方向修订；整体同时交换模式标签不改变这项响应。

这条关系用于追踪现有机制该学会的传递，不给它另起方法名。相对普通条件预测加滤波的实质区别仍须落在原生解释如何生成、接续与共算，而非声称贝叶斯敏感度本身原创。完整接通这条链是必要的实现推进，不等同于已经解决创新问题。

当前优先作者交付改为：**让一条合法真实前缀形成的支持，在同一组原生解释中同时承担中途根的整组跨动作、跨时域后果，并写清这种整段计算相对普通条件预测与滤波的实质区别。** 本节明确了遗漏的训练链、可追踪的源到未来作用和阶段计划。未来真正的改进仍要由对应中间量和独立长程结果证明，论文定位暂不扩展。

## 35. 在原生注意力中继承真实历史

### 35.1 计算选择

设 \(i\) 为上一真实动作块的解释，\(W_i\) 是在该解释下合法形成的原生历史窗口。进入下一块，\(j\) 表示将作用于新动作的解释。过去两种条件可以留下不同的物体位置、接触构型或速度。即使新块确定处于 \(j\)，曾受哪种条件作用仍会影响当前物理状态。若最新合法状态已经充分，或两种历史窗口完全相同，下面的运算自然退化为当前路径。§25 的遮挡端点结果证明历史原生状态可能有用，§26–32 的全视图制动档案单独证明了模式支持可修订。这两项来自不同档案，尚未建立同一场景里的联合收益。

从持续支持 \(p_i\) 及事前转移 \(T_{ij}\) 得到新解释的先验 \(q_j\) 和它对各条历史的条件权重
\[
q_j=\textstyle\sum_i p_iT_{ij},\qquad b_{i|j}=p_iT_{ij}/q_j.
\tag{35.1}
\]
\(q_j=0\) 的解释没有概率贡献，可跳过。受同一命令 \(a\) 查询时，每条历史先完整计算 LeWM 第一块的因果注意力。沿用当前首块的共同模式条件，\(x_i\) 是加时间位置并投影后的窗口，\(c\) 是同一动作条件，\(g(c)\) 为原生 AdaLN 注意力门。记第一块注意力残差为
\[
r_i(a)=x_i+g(c)\odot W_O\!\left(\operatorname{softmax}_{\rm causal}(Q_iK_i^\top/\sqrt d)V_i\right).
\]
\(W_O\) 包括原有偏置。**先让每条历史做自己的 Q–K–V 匹配，再按 \(b_{i|j}\) 合成注意力残差，交给同一个原生非线性后缀：**
\[
u_j(a)=\textstyle\sum_i b_{i|j}r_i(a),\qquad \hat z_j(a)=S_j(u_j(a),c).
\tag{35.2}
\]
\(S_j\) 从第一块的 MLP 开始，包含现有首次分歧读取、后五块的解释条件及原生预测头。全部 token 遵守原三帧因果时序。持续支持因此在第一块内改变 MLP 实际接收的残差，并影响后续层处理同一动作的方式。每个新解释按自己的 \(b_{\cdot|j}\) 接续，同时保留 \(j\) 的物理作用身份。没有新的路由 MLP、额外 token 或在线梯度步骤。

普通的“各模式独立预测，再在输出处加权”在固定当前模式时给出 \(S_j(r_j,c)\)。穷举全部历史则给出 \(\sum_i b_{i|j}S_j(r_i,c)\)，它保留完整混合，是精度参照。经典 IMM 在模型进入之前匹配上一时刻的状态矩，本方案对应的直接对照是 \(S_j(r(\sum_i b_{i|j}W_i,a),c)\)。式 (35.2) 的位置保留了各历史的注意力质量与 value 的配对。对固定查询位置和注意力头，\(\sum_i b_i A_iV_i=\sum_s(\bar A_s\bar V_s+\operatorname{Cov}_{b}(A_{is},V_{is}))\)。先混窗口通常连 \(\bar A\) 都改变。在源端加同一常数到某历史的整行 logits 不改变该历史的注意力，因此无需比较不同历史未经归一化的配分量。这里的区别是 **LeWM 在动作相关的因果注意力之后、完整非线性预测之前压缩不同历史**。一个通用条件预测器也可被构造为实现它。已有多模型交互及后验计算不构成原创主张。 [Blom 与 Bar-Shalom 原论文](https://doi.org/10.1109/9.1299) · 原生条件块（原工程资料，未随包同步）

对固定 \(a,j\)，这个选择精确保留后缀输入的条件均值。如果后缀在这些输入的凸包内仿射，也等于穷举后缀的条件输出均值。若二阶算子范数有界于 \(L\)，两者的单步距离至多 \(\tfrac L2\sum_i b_i\|r_i-u_j\|^2\)，由一阶 Taylor 项加权相消得到。弯曲后缀、互不相容的接触状态和长程放大都会让截断产生误差。二维旋转不可直接在跨周期的角度坐标求平均。当前合成仅发生在原生 residual，须用物理后果检验是否仍可接续。完全观测时若所有窗口收敛，或 \(T\) 为恒等，每个可达 \(j\) 回到原生独立推进。

### 35.2 真实写入、未来接续和学习

在真实块开始，固定已到达的 \(W_i,p_i,T\)，仅对实际发出的命令预发 \(\hat z_j\)。由同一 \(\hat z_j\) 用 §25 所定义的合法观测算子生成各模式的量测预测，实际到达后用一次似然更新为 \(p_j^+\propto q_j\ell_j(y)\)。使用分相位传感时，消费已经到达且预发的条件新息。完整公开编码替换预计的最新 token，部分观测只用设定的可观测坐标修订预计 token，无量测则继续采用 \(\hat z_j\)。原窗口的较早两个 token 从 \(\bar W_j=\sum_i b_{i|j}W_i\) 递推，最新 token 来自本次原生预测及合法刷新。这样下一轮的 \(W_j,p^+_j\) 落在同一接口。校准似然须针对压缩后预测，旧似然统计只可作诊断对照。这个算法在求后缀前把带有同一 \(j\) 的历史压缩，故它的发射分布是近似。可见到达若区分同一 \(j\) 的多种祖先并诱导双峰，先压缩容易漏掉反证。全历程联合滤波保留这一信息，成本与解释路径数一起增长。

在规划请求里，同一份真实支持为所有候选构造 \(b\)。短预测期间暂固定模式，所以头一步继承历史后，每个 \(j\) 沿各自窗口自由预测到 H1、H2、H4。第一步产生的 latent 是后续原生一步的输入。预测中若建模未来切换，可在私有分支状态逐步重用式 (35.1–35.2)。真实公共支持只接受实际到达。若重规划前已推进转移一次，发给候选和实际块的先验共用该时间点，避免连续两次推进同一转移。头一步最多执行各历史的一组首块注意力和各新模式的一组 MLP 与后缀。两个父窗口、两个新模式为 2 组注意力和 2 个后缀，穷举是 4 个后缀。相对互不交互的双模式基线没有天然节省。计时需包括历史传输与实际写入。

离线先用真实配对以后继和物理读出锚定各解释的动力学，保留同样信息和标签的输入均值 IMM 对照。再沿实际历史推进该递推，以合法到达的预测分数约束 \(p\) 和源预测。用中途根各独立执行的多动作、多跨度后缀监督压缩后原生路径。组目标和梯度循 §34.4，整组未来共同约束解释及真实写入，未来标签只出现在损失。对 \(q_j>0\)，有 \(\partial u_j/\partial\log p_i=b_{i|j}(r_i-u_j)\)。因此在不停止支持梯度时，部署会读取的中间状态本身接受后果监督。学习应看到模式切换与当前画面仍不足以判定物理状态同时存在的记录，另包含同窗相等或单一父历史的对照。原生物理状态错误可能同时使似然和未来变差。独立的真实未来读出、模式后验误差以及反证后跨动作修订须分别报告。

### 35.3 手算与首级中间测试

取最近公开 token 的键和值为零，早先两个解释的 \((K,V)\) 分别为 \((+1,+1),(-1,-1)\)。候选查询 \(a=\pm\log 3\)，两历史先各自归一化。令 \(\beta\) 为第一种历史在当前解释内的条件权重，则两候选的首块读出为 \(u_+=\beta-1/4,\ u_-=\beta-3/4\)。即使 \(\beta=1/2\)，二者为 \(+1/4,-1/4\)；先混窗口会让两边都为零。取标量后缀 \(S(u)=u+u^2\)，本方案给 \(5/16,-3/16\)；穷举再加权给 \(9/16,1/16\)。这三组值分别验证注意力内保留的配对、传入非线性的位置及由此舍去的条件方差。若下一原生步的动作使 \(z'=2z+1\)，上述差可延续到 H2；若动作令 \(z'=-1\)，历史对该终点的影响消失。

实际模式在取证段保持。以均匀先验开始，连续收到预先定义的观测，似然比为 9、1、\(1/162\)，支持从 \(1/2\) 变为 \(0.9,0.9,1/19\)。下一块允许以 0.1 概率对称切换。对“下一块仍是第一种解释”这个**相同的解释请求**，条件祖先权重由约 0.988 变为 \(1/3\)，所以 \(u_-\) 从约 0.238 变为 \(-5/12\)，\(u_+\) 始终为正。中性到达没有改变后验，真实反证改变了一条候选的预测方向。算例的观测由事先定义的传感分布给出，只用于推导，不能代替在 LeWM 中看到同一现象。

首级测试锁定权重和原生窗口格式。先在小型原生条件块检查单一父历史、相同窗口、第一块位置及真实写入的传播关系。随后在已有 PushT 档案的合法原生窗口上，为固定候选作受控父窗口及支持干预，记录注意力残差、每个新解释的 H1/H2/H4 latent 和已有物理读出。固定比较独立原生、先混窗口、式 (35.2) 和同一后缀的穷举参考。档案中的替代父窗口是宿主干预。实际在线估计需要独立的合法观测和接续证据。

**首级实测。** 在 16 个既用 PushT 场景的 32 个根，用保存的实际相机支持前后分别读取两条受控父历史。写入对同一模式预测的 XY 作用为 0.042–0.064 环境单位 RMS，覆盖 H1/H2/H4。实际运算位置造成的额外差异更小。相对先混窗口的多模型交互，所有根按阶段和跨度汇总的 XY RMS 差为 0.00045–0.00133。另在同一真实序列预发三次并处理三次完整 RGB 到达。入场的两历史没有原生预测差，公共窗口偏差在完整刷新后降至约 \(1.74\times10^{-7}\) latent RMS。小型 LeWM 的真实到达路径可对同一解释的 H2 反传，两历史相同时梯度作用消失。当前观测建立了原生通路的存在，其物理准确性与长程用途仍缺直接证据。下一项先利用已有遮挡档案研究可得的父状态差、它在真实刷新后仍能存在的条件，以及合成位置相比先混输入是否有可归因用途。 [首级实测与逐例数据](../runs/native_history_inheritance_20261115/REPORT.md)

## 36. 真实到达先区分历史，再由原生注意力继承

### 36.1 同一个当前模式也需要接受真实反证

回看 §22–25：只让输出变动不足以承载需要的真实物理差，已经公开的完整观测可以沿原生窗口传播。§35 将历史继承移到原生注意力之后，但对每个新模式 \(k\) 在评分前先把父历史合成了一条预测。这相当于假定给定 \(k\) 后，实际观察对不同父历史似然相等，导致新观察无法修改 \(P(j\mid k)\)。在等权的两个父历史中，若可见预测为 \(x=\pm1\)，隐藏位置也为 \(s=\pm1\)，同一个当前模式下观察 \(x=+1\) 与标准差 1 给出 \(E[s\mid x]=\tanh(1)=0.762\)。先合成再观测会留下 \(s=0\)，即使精确写回可见的 \(x\) 也无法恢复它。

旧遮挡档案中两条镜像轨迹的绕位动作已实际不同，两次完整画面只能分别成为自身路径的锚点。115、120、125 的合法条带完全相同，已有档案能检验已见状态的延续。85 和 90 步有各 8 张非空且裁切了蓝色推手的条带。旧档案没有在同一真实前缀上安排隐动力学可逆切换。可逆 PushT 另有同命令下的成对历史，以及同一事实轨迹的多轮真实切换。用它的存档画面声明一个统一观察限制进行回放，可以同时保留真实切换和部分可见性。物理执行本身保持原记录。

### 36.2 一轮状态与原生计算

上一块的公共状态是至多 \(K^2\) 个原生窗口 \(W_{ij}\) 与联合支持 \(P_{ij}\)，\(j\) 是上一块模式，\(i\) 是再前一块的模式。当前合法命令 \(a\) 到来，按上一块模式 \(j\) 在原生第一块注意力后合成早期历史，给下一块每种模式 \(k\) 预发一个预测：
\[
S_j=\sum_iP_{ij},\quad
r_i^{(j)}(a)=r(W_{ij},a),\quad
\hat z_{jk}=F_k\!\left(\sum_i(P_{ij}/S_j)\,r_i^{(j)}(a),a\right).
\]
这里的 \(r,F\) 就是 §35 的原生前半块与后缀，\(j,k\) 没有额外的模型参数。\(S_j=0\) 的支路权重为零。真实到达 \(y\) 后计算
\[
P'_{jk}\propto S_j T_{jk}\,\ell(y\mid \hat z_{jk}),\qquad
W'_{jk}=\operatorname{shift}\left(\sum_i(P_{ij}/S_j)W_{ij},\,U_y(\hat z_{jk})\right).
\tag{36.1}
\]
\(U_y\) 是 §25 的可见坐标更新。方案在真实命令下保留两个相邻模式索引，保留 \(P(j\mid k,y)\) 与对应窗口的关系，同时在每次接续前压缩更早的条件历史，窗口数不会随实际轮数增长。它属于固定滞后的近似多模型滤波。每个当前模式的似然是祖先的加权混合，这一层的似然更新精确。更早的历史已在原生残差处合成，整个滤波并非精确后验。与 §35 的每个真实动作 \(K\) 个后缀相比，预发 \(K^2\) 个后缀是区分历史的真实代价。

候选未来在下一块模式 \(k\) 下使用权重 \(a_{ij|k}\propto P_{ij}T_{jk}\)，让每条存留窗口先计算该候选的原生注意力，然后只给每种 \(k\) 展开一次原生后缀。假想分支沿自己的窗口递推到各跨度，不写回公共状态。H1–H4 比较固定短期模式，使用已知任务中途真值评分同一实际模式下的预测。相同候选、固定 \(k\) 时，隔离观察对权重的写入而固定响应，注意力变化为
\[
\Delta u_k=\frac{\operatorname{Cov}_{a_{\cdot|k}}(\ell,r)}{\mathbb E_{a_{\cdot|k}}[\ell]}.
\]
源观测辨别历史且未来命令对这段历史敏感时才起作用。下一次真实到达继续更新联合支持。对组合事实、当前模式权重与未来物理条件的离线监督仍走同一预测计算，按 §34.4 用中途候选后果更新前面的似然和原生后缀。只加大似然分差无法修复方向错误的同模式预测。

### 36.3 预先确定的回放

使用 §§31–32 同一物理可逆档案，初帧完整公开，此后每块末帧只公开 T 形物体灰蓝色像素的横向质心。相机坐标映射到环境单位，使用已有刚体读出训练出的第一个仿射坐标。在单独校准组、真实模式和完整源窗口估计该标量的恒定偏差及噪声。主回放不再编码任何真实后继全帧。标量更新只约束这一条仿射坐标，其余原生分量依照预测传播。该输出是刻意限定的公开观察接口，保留了允许分配证据的纵深或接触历史不确定性。它不是原遮挡档案的自然观测。

用 16 个既用场景、两次真实切换与各自 6 条独立候选，先固定比较实际两次反转上是否出现同一新模式内的祖先似然差、此差是否改变隐藏的纵向或角度预测，以及相同条件后果在 H1/H2/H4 是否正确。对照包括 §35 预先合成版本、式 (36.1) 在事实等似然时仍执行坐标写回的版本，以及以完全相同的后验窗口和概率先合成输入再读候选的版本。另留完全公开原生窗口及穷举所有有效窗口的读出参照。记录当下模式后验、共同绝对物体位置、逐候选相对保持动作的物理效应、以及过两次真实反转的逐场景误差。结果属于机制开发，模型权重固定。计划先弄清真实单坐标到达是否确能在固定当前模式内提供有方向的历史修订，之后再判断是否有理由离线联合训练。

### 36.4 宿主实测与下一项判断

真实轨迹用九次单坐标到达推进。解除制动后，同模式内祖先支持的更新 RMS 为 0.338，固定模式边缘及窗口后，该次更新推动了未观测纵向质心的预测，H1/H2/H4 分别变化 0.524/0.688/0.914 个单位 RMS。恢复制动后，前段预测的似然差仍有 5.968 RMS，但条件权重变化仅 0.00445 RMS。后验为 6/16 正确。相比每次真实写入都省略祖先证据的对照，绝对误差改善 0.32–0.79 个单位，各跨度 10–12/16 场景改善，第二次反转的相对动作差改善只有 6–7/16。候选位置在相同状态下先混窗口或注意力后合成，只相差 0.00059–0.00140。 [首级实测](../runs/native_history_partial_arrivals_20261115/REPORT.md)

这次更换计算顺序保住了真实观测与历史的对应。固定权重下，原生预测里可归因的短期效果集中在绝对状态；适用于较远候选动作差的作用仍不稳定。下一项以同一类局部观测形成的物理状态及真实后续差为训练对象，比较保留联合支持能否相对输入均值或原生续接带来独立作用。评价沿场景留出，并固定实际到达、模式读出、候选及预算。旧遮挡档案上的原生续接继续承担可用信息对照。

## 37. 沿真实观测递推训练同一组解释

### 37.1 计算与学习的对应

§36 固定权重下，真实横坐标只直接改写仿射测量轴。设 \(w\) 是冻结的测量方向，预测值 \(z\) 在获得到达 \(y\) 后, 物理更新对 \(z\) 的导数为 \(I-ww^{\mathsf T}/\|w\|^2\)。对同一次到达，似然对 \(z\) 的变化方向仍是 \(w\)。因此同一真实观察影响稍后物理位置有两条可明确检验的路径：保留和推进正交分量，以及通过似然给与观测相符的历史增重。前者只学当前状态可以改善，后者要在固定候选与原生状态时额外改变同一模式下的未来。把两个末端误差混成一个训练后的总分无法归因。

训练每次都运行 §36 的九步真实递推。起点公开完整图像，此后先预发动作、消费本步横坐标、再更新窗口与公共联合支持。源项用实际前一模式的发行行来对齐两个已经独立执行的源终点，监督同一真实命令下两种当前模式的可见坐标和刚体姿态。可见坐标目标为实际相机质心减冻结的漂移估计，另外三个坐标来自独立执行的真实刚体状态。标签只进入损失，不替换窗口、支持、候选模式或似然。这样限制原生解释在源命令上的错误模式差和共同传感偏差。

在两个实际反转后的中途根分别取 6 个同根候选，两个未来固定模式下均有独立实际执行。候选损失对所有模式和 H1/H2/H4 取平均。令 \(e_{k,a,H}\) 为同一原生预测输出的四维刚体坐标误差，\(a_0\) 为保持动作。两项训练同一个读出：
\[
L_{\rm future}
=\mathbb E_{k,H}\left[
\|e_{k,a_0,H}\|^2 +
\mathbb E_{a\ne a_0}\|e_{k,a,H}-e_{k,a_0,H}\|^2
\right].
\]
第一项要求已经历形成的隐藏状态在保持动作下仍然正确，第二项要求切换动作改变同一个绝对参考的方式正确。二者都由部署会实际调用的原生预测计算给出。两种预测模式的独立实际目标允许辨别「两边都靠近共同均值」的失败。统一尺度在拟合集用相对保持坐标的 RMS 固定。总目标为标准化的成对源误差加标准化的候选误差。更新权重和可见坐标刷新都可反传。训练沿同一源时序建立后验，从而可见测量不只接受单步传感误差，也接受晚到候选对它的监督。推理只消费已发生的事实。

### 37.2 锁定试验与解释

使用已有 55840–55855 拟合，55900–55915 验证机制，55710–55725 作另一批归档验证，保留 55130–55133 的已有传感标定。三批同根候选档案的物理场景不重叠，均已用于过往研究并共享真实命令和反转时序。本轮测已有时序下跨场景效果，独立新时序及正式任务仍待后续证明。每次训练抽两个拟合场景，运行整个九块实际过程，不采用晚到完整观测作捷径。固定 48 次更新、同一场景顺序、学习率 0.0005、梯度裁剪 5。使用相同预训练编码器、内容选择门、读出轴及转移先验，只训练现有模式 conditioner 与原生预测投影头，部署固定。三臂同一原始权重与预算：

| 路径 | 事实写入 | 原生历史合成 |
| --- | --- | --- |
| 联合支持 | 完整 §36 似然更新 | 注意力后 |
| 省略祖先证据 | 保留同一次似然的当前模式边缘，模式内部只沿用事前祖先比例 | 注意力后 |
| 先合成输入 | 完整 §36 似然更新 | 原生预测输入窗口 |

先检查冻结初始值是否复现 §36，记录训练归因及真实源误差；再对实际两次反转报模式 Brier、保持位置、相对保持动作效果及逐场景差。在同一已训练模型和窗口上仅撤去最近同模式内证据，衡量作用是否来自历史支持。评估真实未来模式只用作固定评分索引，两条预测都预先生成。三个训练臂具有相同的源后缀数和参数数，输入先合成包含更少的首块注意力窗口。预算按固定更新次数与实际运行时间报告。这里验证训练及机制幅度，物理任务收益在动作和反转作用明确后评价。

训练完成后若固定根的最后一次写入变弱，按两项定位，避免把相对误差改善当成机制改善。第一项固定候选模式，比较写入前后供原生注意力读取的四个历史权重的总变差。第二项保持同一窗口与模式，逐一单独读取四个现存历史，报告候选相对保持的纵向物理作用跨度。后一读出是对已形成表示的有限干预，不是任意连续权重的全局上界，也不提供部署可读的真实父标签。另报告两物理模式真实相对作用的 RMS、预测幅度与对真实差的有符号投影，区分方向正确和只靠缩小预测差降低 MSE。该归因不改变已经锁定的训练。

### 37.3 实测与可辨识的下一步

问题在监督覆盖上有一个明确的结构缺口。令 \(Y_{j,k}(a,H)\) 表示同一命令前缀曾处于两种真实物理历史 \(j\)，在同一当前模式 \(k\) 下执行未来命令的后果。旧候选标签均从该场景的一条真实历史分支开始，相当于仅提供一个 \(j\) 下的完整 \(k,a,H\) 组合。因而无法直接约束固定当前模式时的历史作用
\[
\Delta_{j|k}(a,H)=[Y_{1,k}(a,H)-Y_{1,k}({\rm hold},H)]
                       -[Y_{0,k}(a,H)-Y_{0,k}({\rm hold},H)].
\]
另一个 \(j\) 在移除事实分支后仍会产生某个预测，但监督无法指出其正确方向。混合绝对误差还把两模式中心误差与四分之一的模式差误差相加，损失允许牺牲已经很小的条件差。旧数据的 16 个拟合场景也具有远小于 55900 的真实相对模式差，低拟合误差不能替代真实幅度见证。

下一项保持 §36 的推理 API，先形成**同一物理起点、相同实际命令、可见事实不同的历史配对**。两条轨迹只因早期的实际物理条件不同而得到不同感觉—运动资料。各自消耗已经到达的完整初帧和同一个部分传感器。先在相同当前条件下执行真实取证命令，收集源条件分差。再从各自真实历史根独立执行相同候选，保存保持差、相对动作差与上述交叉差。源尚不能区分两段历史时，两条后续预测只能保留不确定性。源能区分且动作效应不同的根上，同一个原生状态与支持需要复现可见区别以及冻结当前模式下的未来作用。训练与独立评价都复用已验证的 PushT 物理与动作接口，不由网络误差临时更换任务。眼下的下一台阶是验证这组物理关系是否存在于同一真实过程，随后把成对监督施加于同一原生解释。

## 38. 固定当前模式的物理历史配对

### 38.1 对应关系与可辨别的计算

在 §36 原生状态里保留历史支持的目的，是让已知测量把原生预测导向真实历史仍将产生的作用。用 §37.4 的两条各自合法的前缀 \(r=0,1\) 测这条关系。真实历史标签 \(r\) 不等同于模型内部的祖先 \(i\)。每条前缀在实际命令后只读取自己的已到达标量，第八块先预发全部内部边 \(i,k\) 的传感预测再更新。未来两种模式均预发。统一的 \(k\) 由真实分支事后评分索引。另作已知当前模式的干预，同时将当前边固定在 \(k\)、保持同一个 \(k\) 的未来读出，以排除「本次物理模式分类不同」对历史效应的干扰。命令与物理标签分开；没有真实祖先、历史索引或未来物理状态进入模型。

在固定场景、\(k\) 和候选时，记 \(D=Y_1-Y_0,\ \hat D=\hat Y_1-\hat Y_0\)。三种输出配对共用同一中心。正确配对、互换、以及使用两预测均值的平方误差分别是
\[
E_{\rm mid}+\tfrac14\|\hat D-D\|^2,\qquad
E_{\rm mid}+\tfrac14\|\hat D+D\|^2,\qquad
E_{\rm mid}+\tfrac14\|D\|^2 .
\]
故正确优于交换只说明平均方向同向，且 \(\langle\hat D,D\rangle>0\)。还须优于共同预测，要求 \(2\langle\hat D,D\rangle>\|\hat D\|^2\)。将这套关系分别应用于字面可见的源、保持绝对后果、减去各自保持值的相对动作后果。源读出记录两个口径。每个前缀的合法模式边缘预测使用发出时已知联合权重，另记录离线选择真前一物理模式的源投影，仅用于定位有限表达。对同一已经发行的传感预测，反事实改用另一条归档观测时，两祖先对数似然比变化精确为 \((\mu_1-\mu_0)(y_1-y_0)/\sigma^2\)。前者可对、后者仍可为零。因此同时报告源有向误差与同发行窗口的证据区分。

未来再以三项分开定位。固定当前模式时，保留实际更新的窗口和模式边缘，将最后一次写入后的祖先比例替换为该次写入前的比例。只改这一项造成的 H1/H2/H4 变化是证据路由的增量。保持原生预测权重不动，将两个现存祖先分别完整展开再取期望，以区分压缩与响应本身；二者误差与真实预测差比较。输出平均、原生输入平均和固定当前模式下的同根证据干预分别报告，不能将其中任一个当作真最优值。报告 \(\hat D\) 的有符号投影、幅度与逐场景误差。模型若有同向效果，仍需给出单位量级及共同误差。

### 38.2 固定的学习对照

若源码和配对数值关系验证成立，使用同一原生 §36 参数路径做一次固定预算学习。56000–56011 拟合、56012–56015 在拟合后检验，都是既有物理见证的开发场景。锁定传感标定、输入、基本模型、现有 gate、测量及形状读出。沿每个轨迹的真实已到达资料保留梯度，只学习原 conditioner 与原生预测投影。源损失约束真前一模式所发行的两个配对传感读出，均值和间隔均用合法两路的实际终点监督。未来损失以固定当前模式下的保持、非保持减去保持的四维形状读出分组，分组标准化后分别拟合中心与历史差。历史差的尺度取拟合组各跨度真实 RMS，最低 1；中心用 §37 固定尺度。正确、互换、共同三个目标对照仅用 \(+D,-D,0\) 替换未来历史差标签，共享源与中心监督、训练场景顺序、48 次 AdamW 更新及 0.0005 学习率。二者共同表达形成的预测器仍是原生物理分支。训练赋予两个已经执行不同历史的样本正确意义，部署不调用对照分支。独立验证要看的量是同一合法证据和预测响应的匹配，而非只给模型真解释的可拟合结果。

学习结果若仍无法传出动作差，补一个固定原生能力的反事实。重现同一实况的源命令与物理状态，取同一个真实节点前的三幅完整画面，单独向原生预测提交这三帧并固定同一未来模式和命令。完整画面为离线能力对照。真实窗口若能给出正确幅度而部分路径不能，定位优先回到可见观测向预测状态的写入；若完整窗口也错，先区分原生计算的短时后果与自由滚动误差。三帧完整观测是一个具体反事实输入，不是最大可能模型能力或真实物理的信息上界。

### 38.3 实测与后果

永久冻结的 §36 在 16 个完全配对场景对实际横坐标差有正确的有向作用，但普通预测的 H4 相对动作差投影仅为开放 0.044、制动 0.036。完整展开与输入平均没有恢复有向差。正确、互换和共同目标训练均完成 48 步。四个未拟合的开发场景上，H4 正确组的实际作用投影 0.020/0.046，小于冻结部分观测的 0.052/0.241，绝对保持和相对动作 RMSE 均上升。真源区分没有陆续传播到相同原生解释的预测后果。该轮拟合没有胜过简单对照。

完整三帧物理回放保有更大的有向差。冻结模型在所有 16 场景的保持 H4 投影为 1.117/0.948。相对动作 H1 投影为 1.202/0.829，H4 降为 0.270/0.149，且 H4 相对动作的正确配对 MSE 仍劣于共同预测。训练组给完整三帧也没有恢复 H4 动作差。故部分观测造成一个缺口，原生推演在完整起点后仍留下另一个。重新校准源事实不解决后一问题。[实测、训练与组别归因](../runs/native_history_matched_fit_20261115/REPORT.md)

下一段保持 §36 的因果写入。以一个明确的原生问题推进：对同一个真历史差和动作，在完整真实根下得到的局部实际响应，是否会在闭合的预测状态中失去物理方向？同一冻结后缀的两条自由轨迹在单步的精确有限差，可写成沿两根之间的原生 Jacobian 积分作用在分支状态差上，动作相对保持则是两个独立动作路径的响应差。这只是定位关系，不预设近似线性，也不意味着单步交叉差可简单相加。下一步的目标是区分实际根上的局部原生误差和模型状态递推引入的误差，再约束同一原生解释的跨步作用。继续使用已采集的物理根、原生动作与镜像约束，避免再对传感温度、合成位置或最终分数试错。

## 39. 用原生注意力的相对动作响应读取持续支持

### 39.1 计算对象

固定一个未来模式 \(k\)。令 \(b_i=P(i\mid k,\mathcal H_t)\) 为 §36 在真实经历 \(\mathcal H_t\) 后留给各原生历史窗口的条件支持。同一声明时刻的所有候选共享 \(b\)。在 LeWM 第一块，历史 \(i\) 最新 token 的原生注意力在每个头上对因果位置 \(s\le T\) 产生 logits \(L_{is}(a)\)、概率 \(A_{is}(a)\) 和原生值 \(V_{is}(a)\)。\(T\) 为最新位置。令 \(a_0\) 为与实际或候选动作同块长的物理保持命令。两次计算共享历史及前两条已执行命令，仅最后一条不同。保持结果是模型预发参考，部署没有读取保持分支真正发生的后果。

§36 先对每条历史独立归一化，再以同一组 \(b_i\) 组合各头的回答。它保留各条历史内部的匹配，但每个头分给一条历史的总质量与请求动作无关。这里改动**首块最后一行注意力的归一化**。设 \(\lambda_{is}(a)=L_{is}(a)-L_{iT}(a)\)，并令 \(Z_i(a)=\sum_{s\le T}\exp\lambda_{is}(a)\)。新的联合注意力为

\[
\Pi_{is}(a;b)=
\frac{b_i\,\exp\lambda_{is}(a)/Z_i(a_0)}
{\sum_j b_j Z_j(a)/Z_j(a_0)}
=\omega_i(a;b) A_{is}(a),\qquad
\omega_i(a;b)=\frac{b_i Z_i(a)/Z_i(a_0)}{\sum_j b_j Z_j(a)/Z_j(a_0)} .
\tag{39.1}
\]

这个选择由两条条件唯一确定。每条历史内部的任意两位置之间，注意力赔率是该历史的原生动作条件赔率。各历史在最新位置 \(T\) 的赔率，等于保持请求的联合赔率 \(b_i A_{iT}(a_0):b_j A_{jT}(a_0)\)。将这组锚点赔率乘以原生位置赔率再归一化即可得到式 (39.1)。因此改变的是**同一头如何向可追溯的历史分配读取质量**。保持动作下 \(\omega=b\)，既有绝对参考路径精确保持。若各历史的动作响应比率 \(Z_i(a)/Z_i(a_0)\) 相同，给再多支持也不会产生额外的重分配。对于零支持的历史，联合质量始终为零。对每条历史及请求整行 logits 加任意常数，式 (39.1) 不变。\(Q\to QS,K\to KS^{-\top}\) 保持原生点积时，此运算也保持不变。

把 \(\sum_{i,s}\Pi_{is}V_{is}\) 送入原来的 head 合并、输出投影及 AdaLN 残差；第一块较早位置和残差底座仍按 §36 的 \(b\) 组合。此后继续同一原生 MLP、后五块和预测头。第一步进入自由推演的最新 token 就是此处生成的 latent，H2–H4 用原来的同一 predictor 消费它。这一版本明确只在从持续窗口分支进入一次预测请求时使用式 (39.1)，其后作用由递推状态传递。真实时间每前进一步时，新的 §36 窗口和支持再次进入同一操作。

这项机制的比较对象有三种。普通条件预测加滤波保留各历史的独立预测，事后用真实 \(b\) 加权。§36 让 \(b\) 固定地作用于各头的回答，然后运行原生后缀。式 (39.1) 让同一 \(b\) 在同一未来模式内改变原生 head 对历史位置的非线性分配，且不同头、不同动作一般没有一组公共输出加权可实现它。保持只有一个有质量的历史时，运算回到该历史的原生路径。若真实世界满足已给定窗口的充分性且每条独立预测恰好准确，完整物理后验预测仍应使用真实 \(b\) 积分。式 (39.1) 是用于有限原生工作状态的预测构造，\(\omega\) 既不声称是真实模式概率，也不回写公共支持。

向注意力加入混合先验本身已有先例。这里的具体构造是用同一动作条件 predictor 的**保持请求和最新位置共同锚定历史间的赔率**，令真实支持改变的是候选相对保持的读取，保持路径精确恢复。Henderson 和 Fehr 的分布注意力已包含 \(\log\pi_i\) 的混合偏置。式 (39.1) 还要求每个头、每条历史重用同一个宿主的保持行归一量，并规定其在真实更新与自由递推中的时序。这里讨论的是可比较的运算特征，文献优先权和物理优势仍未建立。 [分布注意力 §2.1](https://openreview.net/pdf?id=6QkjC_cs03X) · [LeWM](https://arxiv.org/abs/2603.19312)

### 39.2 真实经历、多个动作和多个时域

实际命令发出后，按上一块实际支持对源窗口分组，同一式 (39.1) 为每条 \(j\to k\) 预发预测；与保持相关的量亦在到达前由模型计算。观察 \(y_{t+1}\) 到来后，沿 §36 的真实似然和测量修订更新 \(P'_{jk}\) 及 \(W'_{jk}\)。一个合法到达只写一次。真实后继与未来动作后果来自同一个预测器及同一种原生归一化；下一真实交互可以重新判断哪个父历史能够解释新事实。没有判别力的量测保留相对似然比为一，转移先验仍按原协议工作；新的反证在两种解释均有正先验时可以改变支持。规划中所有预测到达均为私有，不能给事实支持增加证据。

固定 \(W_i\) 与动作 \(a\) 时，令 \(u_i(a)=\sum_s A_{is}(a)V_{is}(a)\) 且 \(U=\sum_i\omega_i u_i\)。对支持 logits \(l_i\) 求导得到 \(\partial U/\partial l_i=\omega_i(u_i-U)\)。与固定平均的差为
\[
U-\sum_i b_i u_i=\frac{\operatorname{Cov}_{b}(Z_i(a)/Z_i(a_0),u_i(a))}{\mathbb E_b[Z_i(a)/Z_i(a_0)]}.
\tag{39.2}
\]
两个因素共同限定作用。真实经历须改变相关历史的支持，原生动作须在这些历史上产生不同读取且具有不同的 head 答案。即使支持强烈改变，如果两历史在该动作下原生响应相同，此机制也不会凭空制造它们之间的差。后续原生 Jacobian 或有限差路径决定该 latent 差是否在 H2–H4 放大、保留、抵消或误向。这里没有从局部注意力差推出远期物理准确性的定理。

在两条历史与单个头的手算例中，保持时两条历史的注意力均为 \((1/2,1/2)\)，当前值为 0，较早值为 \(+1,-1\)。令实际动作 A 的历史相对最新赔率为 \(3,1\)。若 \(b=(1/2,1/2)\)，则普通受支持的回答为 \(1/8\)，式 (39.1) 为 \(1/3\)；若合法到达先把第一条支持改为 \(3/4\)，则两者分别为 \(7/16\) 和 \(4/7\)。这个手算只说明支持和动作如何在头内耦合。若把 H2 的另一个原生动作写成 \(z'=2z\)，H1 的差延续；若写为 \(z'=c\)，差在 H2 消失。把两个历史的较早值同时改为 0，会保留全部注意力赔率变化而令实际回答无差。这是第一项明确反例。

### 39.3 学习及分阶段中间量

构造没有额外在线参数或 learned router。学习沿现有原生 predictor 的因果路径，由同一真实前缀预发预测并在合法观察后推进 §36。训练只使用独立实际执行的候选后继作为目标。先锚定源可见后果与绝对保持，从训练根的同模式成对历史出发，在相同命令菜单上共同拟合候选相对保持的有向物理差。对单组而言，所有候选共享真实 \(P\)，物理模式和未执行候选结果只参与离线损失。后续目标经 H2/H4 原生递推和真实支持回传到式 (39.1) 用到的原生 Q/K/V。设 \(\rho_i=Z_i(a)/Z_i(a_0)\)，则 \(\partial U/\partial\log\rho_i=\omega_i(u_i-U)\)，所以有向未来监督会让物理差调节 \(\rho_i\) 的相对值。须同时保留冻结和同参数同预算 §36 对照，防止原生能力的普通微调被当成该运算带来的效果。

本轮首级检验固定权重。先在原生块检查保持、一条历史有效、共同历史、等响应比的相等关系，以及式 (39.2) 的预测量。再在已固定的 16 组物理历史上执行同一个测量与原生候选路径。首先冻结窗口、当前条件、候选和所有权重，只替换最新 token 的注意力分配，并用省略最后证据的对照量出真实支持的独立作用。随后整段回放使相同运算承担真实预发。逐场景记录真实源读出、原生分配、支持、固定未来模式的绝对保持及相对动作，H1/H2/H4 分开。用正确、互换和共同配对解释方向。冻结结果只能判断原生相对注意力是否已经具有方向性、影响是否能沿同一递推传播。若分配有作用但方向不匹配，才有理由用上述训练教会既定运算。在新的中间量成立后再考虑独立闭环。

### 39.4 冻结中间量及边界

手算中的 \(1/3\)、\(4/7\)、零支持和保持对照由原生 attention 单元复现。完整 LeWM 上，保持轨迹、单一历史和相同历史的 latent 差均低于 \(2\times10^{-6}\)。16 个既有物理场景中，每头的历史分配相对原支持变化 0.00409 RMS。固定原生窗口及真写入时，H1/H2/H4 的物理端点改变量为 0.00047 / 0.00066 / 0.00117 单位坐标 RMS。开放条件 H4 的交叉差有向增益仍为 0.03745，制动仍约 0.03356。真值交叉差本身为 45.39 / 23.70 单位 XY 向量 RMS。整段八个实际块更换预发计算以后，最终支持变化 \(2.46\times10^{-6}\) RMS。保持与零支持性质成立，幅度和方向均未超出固定权重参照所能提供的实际用途。 [逐场景结果与口径](../runs/native_history_relative_attention_20261115/REPORT.md)

关键约束可以从公式直接看到。在一个固定头上，令 \(\bar u=\sum_i b_i u_i\)。由于改变只沿同一组原生值回答的凸包移动，
\[
\|U-\bar u\|\le {\rm TV}(\omega,b)\max_{i,j}\|u_i-u_j\|.
\]
等式右侧同时取决于相对动作赔率和历史间回答可分性。当真实后果的区别已存在于 \(V\) 或后续状态，但保持与候选的最新行归一量始终同比变化时，本构造有真实信息也无法调节。这个反例即使 \(\ell\) 评分准确也成立。如果后一种情况发生，单纯增加真实支持的置信度或反复微调预测头都不会解除首块的计算约束。下一项沿 §38 原来规定的同一物理分支拆开真实根/预测根，不再把区别存在于注意力赔率当作已成立的经验事实。保留 \(b\) 与未来使用的分离原则，现有候选保持为可明确对照的未证实构造。

更具体地，在两个父窗口 \(W_0,W_1\) 上记 \(\rho_i=Z_i(a)/Z_i(a_0)\)。式 (39.2) 精确等于
\[
U-\bar u=
\frac{b_0b_1(\rho_1-\rho_0)}{b_0\rho_0+b_1\rho_1}(u_1-u_0).
\tag{39.3}
\]
沿连接两个窗口及两个连续动作 embedding 的区域，若 \(D_W D_a\log Z\) 有界，且 head 回答对 \(W\) 局部 Lipschitz，则 \(\log\rho_1-\log\rho_0\) 至多为 \(C\|W_1-W_0\|\|a-a_0\|\)。这是 \(\log Z(W,a)\) 的混合有限差，可由对 \(W\) 和 \(a\) 依次积分得到。由于 \((\rho_1-\rho_0)/\mathbb E_b\rho\) 的绝对值在这一区域至多为 \(e^{|\log\rho_1-\log\rho_0|}-1\)，新增的 head 作用在窗口接近时为
\[
O\!\left(\|W_1-W_0\|^2\|a-a_0\|\right).
\]
这个结论针对同一固定当前模式和头，不要求 \(b\) 接近均匀。原有 §36 的支持乘历史回答差通常已有一阶作用。此处的新归一化只提供二阶补量。因此若真正需要恢复的是被真实更新或原生递推压小的一阶历史×动作差，这一计算选择在局部从结构上不合适。它仍可能在分开的物理历史上有作用。已测的小幅度与这个约束相容，尚未单独验证局部区间、导数大小或测量中有多少衰减来自该项。

该约束不只适用于式 (39.1)。若任意平滑重分配 \(\omega(W,a,b)\) 在有效历史重合时回到 \(b\)，且只重加权已有 head 回答，则 \(\sum_i(\omega_i-b_i)u_i=\sum_i(\omega_i-b_i)(u_i-u_\star)\)，因为权重改变量之和为零。两个因子在历史重合处均为一阶小量，所以这个家族与 §36 在重合处有相同的一阶导数。要求所有窗口的保持请求也回到 \(b\) 时，动作差进一步成为上式中的共同因子。对 §39 还有更强的具体盲点：\(\rho_i=A_{iT}(a_0)/A_{iT}(a)\) 只读取最新位置的注意力份额。保持这个份额、任意重新排列两个较早位置的原生质量，可以产生实际的 head 答案差，却始终不会让 \(\omega\) 偏离 \(b\)。因此继续扫描本类归一化或其温度，无法回答消失的一阶作用在哪里产生、由哪一个原生状态传递。

## 40. 分开物理读出与原生窗口传递

对 §38 每个已有分支末端，把真实物理坐标 \(D\)、直接读取真实编码 \(C\)、用该分支实际三帧预测一步 \(L\) 与从完整实际起点自由推演 \(F\) 带入恒等式 \(F-D=(C-D)+(L-C)+(F-L)\)。在每一项分别取同模式的历史差和候选相对保持，线性分解保持成立。这一运算不把不同根看作同一个物理动作干预。H1 的两原生窗口相同，H2 起每条候选从自身实况跟进。固定读出误差不是编码器信息上界。

384 条既有分支的 1,536 个块端点重放成立。H4 相对动作交叉差在真实方向的归一化投影，开放/制动条件下真实末帧读出为 0.426/0.384，真实三帧一步为 0.381/0.416，自由推演为 0.270/0.149。换真实窗口能追回 0.111/0.267 的有向量，真实末帧直接读出已损失 0.574/0.616。后一项没有区分冻结编码和仿射姿态读出，也没有证明两项不可以互相抵消。保持的自由 H4 有向量 1.117/0.948。将候选差进一步限制为只改变第一块命令，H4 两路直接动作输入完全相同。对这组首块动作的历史交叉差，真实窗口一步还能给出 0.315/0.108，自由推演只剩 0.011/0.011。 [归因报告与逐例](../runs/native_history_rollout_attribution_20261115/REPORT.md)

下一步的构造约束可落到同一个原生接口。令 \(W_3^{(a)}\) 与 \(W_3^{(b)}\) 是执行不同首块后在同后缀中自由得到的原生窗口，\(F_\theta(\cdot,A_{2:4})\) 是 H4 的原生一步。在该步没有新动作差可以用来触发注意力重分配，区别只能来自 \(F_\theta(W_3^{(a)},A_{2:4})-F_\theta(W_3^{(b)},A_{2:4})\)。所以应让真实支持选择的解释在产生新 token 时就建立需要的跨状态差，并在同一原生映射可读的坐标上接续。真实首块和候选首块共享生成规则。已见真实参考仍由现有观测锚定。仅保护当前读出、仅调整当前读出或仅改善源似然，都不足以同时满足这两条有向要求。新构造应分别证明当前观测一致性和脉冲传递的非零一阶作用；未执行后缀用于离线配对监督，部署不重新播放它。

## 41. 全视野底座与可逆任务的重新执行

### 41.1 目标与附件判断的范围

原定能力是任务中持续用真实经历判断交互条件，并使同一原生预测解释在不同动作和跨度上正确响应。全视野允许物理状态由公开图像接续，持续支持承担尚未直接显现的交互规律。§26、§28 的条件化与共享可重用，算法作用仍需新的匹配数据证明。

附件中的“96.5% 信息丢失”对应一个特定四分支交叉差的有向投影比。该量能定位传播作用，不能计量整个 latent 的信息量。“共享头被炸毁”是对训练结果的解释，旧记录足以证明那些训练恶化了完整输入上的原生预测，但尚未把学习率、梯度尺度、缺少 latent 目标各自的因果贡献分开。0.012/0.038 是此前固定菜单上的覆盖百分点差。采用新任务前直接测量其模式决策价值，避免把旧菜单结论外推到整个任务类。

### 41.2 全视野宿主

分别读取正式 PushT、TwoRoom/FourRoom checkpoint、预处理与动作归一。先固定拟合场景和未参与开发的新评价场景。在同一个物理起点执行只在首块不同、后续动作相同的分支，保留完整真实三帧及全部物理终点。对每个 H1–H4，\(Y\) 为真物理位置，\(C\) 为真实终点编码经诊断读出的坐标，\(L\) 为终点前真实三帧经原生一步预测的坐标，\(F\) 为完整起点的自由预测，满足 \(F-Y=(C-Y)+(L-C)+(F-L)\)。相同动作时序、物理单位与逐场景分解均写入输出。

PushT 使用原生单模式开放物理，不带既有制动 adapter。比较冻结 checkpoint 与单次 H1–H4 自回归 latent 一致性微调。encoder 固定，原 predictor 和 pred_proj 接受 \(\frac14\sum_h\|\hat z_{t+h}-\mathrm{sg}(E(o_{t+h}))\|^2\)，预定学习率 \(10^{-4}\)，记录裁剪前梯度与每跨度误差。真实未来只出现在目标。读出拟合只用训练场景的真实编码，固定比较线性与一个小型 MLP，评价时也用于同一冻结坐标上的真实编码和预测 latent。两种读出误差帮助区分诊断读取能力，读出改善不单独记为世界模型改善。

房间宿主保留各自官方物理、完整观察与原生三帧预测，先用固定 checkpoint 作同样的分解。对应 XY 读出在训练分区拟合。不同宿主的像素、动作速度和几何不同，同时报告物理单位误差、相对尺度、有向增益及正交误差，避免仅按绝对像素给宿主排名。将附件建议的 H4 增益 0.70 和读出 5 像素作为事先记录的参考值，连同场景分布与置信区间判断稳定性。

### 41.3 纯物理 Gate 0

采用官方房间运动与碰撞接口，在画面相同的门口引入互补可逆锁。当前完整观察显示位置和可见墙，锁的状态只通过真实通过/受阻显现。两模式改变哪条绕行路线可通达。预先锁定新场景种子、方向、切换时刻、任务时限、CEM 候选生成与 H4–H6 预算，然后用相同物理规划器比较当前真模式、均匀模式和仍沿用旧模式。

每臂对两模式执行等量候选物理展开，成本与采样预算一致。CEM 共享随机数而各自按自身评分更新精英，同时报告同一固定候选池的配对决策差，区分候选差异和重规划差异。记录任务成功、实际动作、步数、碰撞、切换前后和逐场景收益，按场景计算成对置信区间。预定有意义的成功差至少 20 个百分点，并要求其配对区间下界大于零；同时记录物理真模式的绝对成功率。目标是先证明这个具体任务具备模式决策价值。若条件未满足，报告失败原因和任务可达性，不以模型训练覆盖物理可行性缺口。

### 41.4 接入顺序

一旦具体宿主和任务支撑相应作用，沿现有原生路径扩展全层条件化，真实每步使用完整三帧窗口。一次动作执行前，原生各解释预发下一 latent，真实编码到达后由同组预测形成似然。可用训练分区的动态潜变量方向与残差协方差构造固定尺度，标定和评价分开。该尺度承担辨别物理可见后果的角色，跨模式的 latent 差并不自动等于有效似然。

共享只发生在窗口及实际原生调制一致时。共享预测的似然也相同，因此观测项不会重新分配概率。若继续使用非零切换先验，休眠期间概率仍会向先验松弛，必须记录此量。潜在切换和保持证据的时长由同一训练与部署假设约束。模式分歧后使用各自生成的窗口继续，公共支持只吸收已到达真实量测。

训练保留原生多步 latent 目标，同根真实分叉约束跨动作的一致解释，反转序列把真实到达与后续用途串起来。第一台阶以正确模式输入比较均匀及物理 Oracle。第二台阶固定部署参数后看取证、远行、返回、反转的概率与真实候选变化。第三台阶在新场景、共同 CEM 预算下比较 Frozen、Uniform、Keep-Old、匹配 GRU、作者适配接口的 AdaJEPA/OpTTA，并记录全部前向和在线反向成本。每台阶同时记录失败及其覆盖范围。

这三个组成目前属于已有计算原理的具体组合及可检验路径。候选最终的核心创新需来自已明确的原生共享与持续解释作用，不能由任务选择、底座修复或组合本身推出原创结论。

# 从实际规划查询追溯 FourRoom 原生预测失效

本轮问题是同一个原生条件预测器为什么在固定 H4 候选上有效，进入 H5 CEM 后却给物理不可达的动作序列低代价。原冻结 FourRoom 的 0.989 是原版布局的首块**动作差**。新布局的 2.89/4.46 px 是固定 H4 库的门前/导航**绝对位置**误差，0.951/0.742 对应**模式差**增益。旧报告四条约 44 px 是同一新布局的已选 H5 计划。三个量的样本、跨度和差分对象各不相同。

## 原生递推怎样产生这类错误

四层原生 predictor 接收最近三枚 latent 和对齐的三个动作块。首块使用两个解释的共同调制，产生门控 `r`。后三块插入 `common + r × (mode − common)`。每个解释把自己的下一枚 latent 接回自己的窗口。`r=0` 只取消本步的模式偏移。共同动力学仍由原生块给出，已经分开的两个窗口也可以继续输出不同结果。已知真模式只用于选择这一解释产生的代价，因此不能修复两个解释共有的错误。

当前训练用 80 个布局，共 320 个根，每根四个候选。导航候选为可见地图两条路线种子及物理 CEM 在两个模式下各自选出的优胜者。门前样本为规定的推进、后退和转向。训练对每个真实候选使用 H1–H4 自由 latent MSE，另外拟合来自脚本实际窗口的一步双模式 latent。门控的显式 BCE 只作用于候选首块和脚本的一步源。H2–H4 自由预测有回传，后段门控处于 `r=0` 时，ReLU 的死区截断该点经模式偏移的梯度。评价时 H4 的 301/434 来自真实后段窗口和块内任一原始步的物理分歧。训练标签和似然则匹配实际每五步才观察到的块末。块内短暂分叉后重新合流是两种口径相异的真实例子。 拟合和评价（原工程资料，未随包同步） · 实际分支采样（原工程资料，未随包同步） · 原生门控（原工程资料，未随包同步）

判断公共约束和新模式作用时，可将同根同动作的预测分成 `μ̂=(ẑ₀+ẑ₁)/2`、`Δẑ=ẑ₁−ẑ₀`。对实际编码同样定义 `μ*、Δz*`。每一前缀已有的双模式 MSE 满足

\[
\tfrac12\sum_m\|\hat z_m-z_m^*\|^2
=\|\hat\mu-\mu^*\|^2+\tfrac14\|\Delta\hat z-\Delta z^*\|^2.
\]

共同穿墙误差可以出现在第一项，模式差增益只看第二个对象。对真实模式差为零的候选，哪怕两种预测一起错到另一个房间，也不给合计的模式有向增益贡献分母或分子。绝对 RMSE 会计入这些误差，但只在它被测量的样本总体上约束平均量。

第五块延续前四块产生的窗口。CEM 每轮筛选 96 条候选，两个分量分别按模式代价更新精英，四轮总计 384 条评分。成本用读出末点所属房间选可见路径，房间边界可能使代价跳变。设物理上更差的候选 A 和更好的 B 的终点代价为 `J_A>J_B`，预测偏差 `e=Ĵ−J`。若 `e_A−e_B<−(J_A−J_B)`，同一个评分器就会把 A 排在 B 前面。CEM 精英会传播这种错误偏好。四条已选计划可以区分首个错误房间、真实窗口一步能否造成同类偏差，以及后续自由窗口扩大了多少。端点 `F₅−L₅` 自身无法确定第一次错误发生的时间。

## 同一机制的最小修订

修改的对象是**同一个原生条件映射在规划所查询的前缀上的监督**。训练样本的单位从固定四块候选和单独的脚本源改为“共同根、完整五块动作、每个已经执行的前缀、从该前缀重新分叉的下一块”。在原训练布局上，仅用一次冻结的现模型产生 H5 CEM 候选，保留具有虚假低代价的共同受阻序列、同根实际可达的路线和有真实块末模式差的动作。候选与真实后果一同存档。合法候选保留正反面，避免把抑制运动当成学会墙体。

从共同真实根自由展开两种解释到 H5，每个跨度仍用原生 latent MSE 监督。对每条实际分支已经到达的窗口 `W`，保留真实三帧和过去动作，固定真实当前状态，在两种模式下分别实际执行**同一个**下一动作块。使用这两条真实末帧编码训练已有的一步双模式 MSE。现有 BCE 沿用**块末观测是否受模式影响**的标签口径，将监督推广到实际前缀。若起点处于另一模式下不允许切换的门洞占用状态，仅保留已执行分支的自由预测目标，局部配对目标留空。训练标签的几何真值留在离线，原始步内的首分歧也保存供诊断。两条真实分支已经分开时，在各自的窗口分别构造这对目标。跨两个不同真实窗口相减会把继承的状态差误标为当前动作新产生的作用。

共享墙体由两模式一致且实际受阻的预测目标学习。对真实可通行的动作，两模式仍应输出正确运动。只有从同一实际输入执行同一动作、块末的实际观察才出现区别时，才要求这一块的原生模式调制产生有用的差。部署沿原先的分支递推和预发写入。实际观察只进入真实窗口和实际似然。修改没有数学上保证所有预测都物理可达，提出的是可用同一原生接口和原监督检验的学习关系。采集思想与 [DAgger](https://proceedings.mlr.press/v15/ross11a.html) 的分布覆盖动机相关，此处标注的是模型所查询动作的真实后继，并非专家动作。

## 中间测试的先验判断

- 先用冻结模型重放存档中四条已选 H5 计划及真物理 CEM 参照计划。记录每块的 `Y/C/L/F`、两模式门控、第一处错误房间、同一模型下参照与误选的预测和真实代价。不把已执行的跨轮 MPC 首块拼接成单次 H5 序列。
- 共同受阻的计划在两个真实后果相同的块末若同时产生大幅正向位移，优先归因为共同预测误差。去掉门的说法可在冻结权重上用已有 `force=1` 路径作同动作干预，区分结果是否依赖抑制模式偏移。强制读出会改变原拟合曝光强度，属于干预诊断。若给正确模式及强制开启仍过墙，开门本身不足以解释该次误判。
- 固定训练库和存档 CEM 计划分别统计中央角点受阻及持续对角推进的样本量，说明覆盖差异。四条复播不足以估计全局尾部频率。模型生成的 latent 与物理读出在真实图像外的适用性也要独立判断。`C−Y` 小只表明同一真实终点可读。
- 原训练动作与换锁试探都只通过同一块动作的双模式后果参与学习和评分。若执行中发生反向写入，先看实际执行的同根局部反事实和似然差符号。共享尺度的温度只改变证据大小，不能使错误方向变成正确方向。给正确模式的失败已经说明，解决支持更新无法单独完成闭环修复。

本轮零训练中间测量先检验上述归因。训练预期是同一独立冻结候选库上，共同受阻的 `L−C` 和 `F−L` 降低，合法打开路径的位移不被压扁，新的块末模式差仍能产生方向正确的似然与候选差。判断训练目标覆盖是否为主因需要未来同预算训练对照，单模态无锁闭环、重新训练编码器或调整后验属于后续独立问题。现有单模式臂的 1/16 来自有隐藏锁的任务，不能作为全开门基线。

```python
class FullDepthConditioner(nn.Module):
    def __init__(self, model, code_width):
        super().__init__()
        transformer = model.predictor.transformer
        self.depth = len(transformer.layers)
        self.width = transformer.norm.normalized_shape[0]
        reduced_width = min(code_width, 16)
        self.shared = nn.Linear(code_width, reduced_width, bias=False)
        self.layers = nn.Linear(reduced_width, self.depth * self.width, bias=False)
        nn.init.zeros_(self.layers.weight)

    def forward(self, code):
        return self.layers(self.shared(code)).unflatten(-1, (self.depth, self.width))


class FirstEffectReadout(nn.Linear):
    def __init__(self, model):
        width = model.predictor.transformer.norm.normalized_shape[0]
        super().__init__(2 * width, 1)
        nn.init.zeros_(self.weight)
        nn.init.ones_(self.bias)

    def logits(self, state, condition):
        width = state.size(-1)
        return self(torch.cat((F.layer_norm(state[:, -1], (width,)),
                               F.layer_norm(condition[:, -1], (width,))), dim=-1)).squeeze(-1)


def _pair_representatives(shared):
    """Representative rows and inverse map for independent two-mode requests."""
    rows = torch.arange(2 * len(shared), device=shared.device)
    source = rows.clone()
    source[1::2] -= shared.long()
    retained = rows == source
    return rows[retained], (retained.cumsum(dim=0) - 1)[source]
```

```python
def _first_effect_suffix(model, state, condition, offsets, common, factor):
    transformer = model.predictor.transformer
    for layer, block in enumerate(transformer.layers[1:], 1):
        common_part = common[:, layer]
        mode_part = offsets[:, layer] - common_part
        applied = torch.where(factor == 0, common_part, common_part + factor * mode_part)
        state = block(state, condition + applied[:, None])
    state = transformer.output_proj(transformer.norm(state))
    return model.pred_proj(state.flatten(0, 1)).unflatten(0, state.shape[:2])[:, -1]


def _relative_attention(block, native_input, reference_input, ancestry):
    """Normalize the last causal row across histories relative to the native hold request."""
    def heads(x):
        return x.unflatten(-1, (block.heads, -1)).transpose(-3, -2)

    q, k, v = map(heads, block.to_qkv(block.norm(native_input)).chunk(3, dim=-1))
    hold_q, hold_k, _ = map(heads, block.to_qkv(block.norm(reference_input)).chunk(3, dim=-1))
    hold_keys = torch.cat((k[..., :-1, :], hold_k), dim=-2)
    scores = (q[..., -1:, :] @ k.transpose(-2, -1)).squeeze(-2) * block.scale
    hold_scores = (hold_q @ hold_keys.transpose(-2, -1)).squeeze(-2) * block.scale
    relative = scores - scores[..., -1:]
    hold_relative = hold_scores - hold_scores[..., -1:]
    log_ratio = relative.logsumexp(-1) - hold_relative.logsumexp(-1)
    log_prior = ancestry.clamp_min(torch.finfo(ancestry.dtype).tiny).log()
    log_prior = log_prior.masked_fill(ancestry == 0, -torch.inf)
    reachable = ancestry.sum(dim=-1, keepdim=True) > 0
    log_mass = log_prior[..., None] + log_ratio[:, None]
    mass = torch.where(reachable[..., None], log_mass, 0).softmax(dim=2) * reachable[..., None]
    answers = (scores.softmax(-1).unsqueeze(-2) @ v).squeeze(-2)
    last = torch.einsum("bjih,bihd->bjhd", mass, answers).flatten(-2)
    prefix = F.scaled_dot_product_attention(q[..., :-1, :], k[..., :-1, :],
                                            v[..., :-1, :], is_causal=True)
    prefix = prefix.transpose(-3, -2).flatten(-2)
    # An unreachable destination had no residual or projection bias in the original inheritance.
    return block.to_out(prefix), block.to_out(last) * reachable, log_ratio, mass


def _inherit_first_effect(model, windows, controls, offsets, readout, ancestry, forced_exposure, trace,
                          reference_action=None):
    """Advance each destination from its weighted bank of native attention responses."""
    predictor = model.predictor
    transformer = predictor.transformer
    block = transformer.layers[0]
    batch, parents, length, _ = windows.shape
    destinations = offsets.size(1)
    state = transformer.input_proj(predictor.dropout(windows + predictor.pos_embedding[:, :length]))
    condition = transformer.cond_proj(controls)
    common = offsets.mean(dim=1)
    first = condition + common[:, 0, None]
    shift, scale, gate, mlp_shift, mlp_scale, mlp_gate = [
        x[:, None] for x in block.adaLN_modulation(first).chunk(6, -1)
    ]
    native_input = block.norm1(state) * (1 + scale) + shift
    if reference_action is None:
        attention = block.attn(native_input.flatten(0, 1)).unflatten(0, (batch, parents))
        residual = state + gate * attention
        inherited = inherit_window(residual, ancestry)
        if trace is not None:
            trace["parent_attention_residual"] = residual
    else:
        hold_condition = transformer.cond_proj(reference_action.expand(batch, -1)) + common[:, 0]
        hold_shift, hold_scale, *_ = block.adaLN_modulation(hold_condition).chunk(6, dim=-1)
        hold_input = block.norm1(state[:, :, -1:]) * (1 + hold_scale[:, None, None]) + hold_shift[:, None, None]
        prefix, last, ratio, mass = _relative_attention(block.attn, native_input, hold_input, ancestry)
        prefix = inherit_window(state[:, :, :-1] + gate[:, :, :-1] * prefix, ancestry)
        last = inherit_window(state[:, :, -1:], ancestry) + (gate[:, :, -1] * last).unsqueeze(-2)
        inherited = torch.cat((prefix, last), dim=-2)
        if trace is not None:
            trace.update(reference_log_mass_ratio=ratio, parent_attention_mass=mass)
    if trace is not None:
        trace["inherited_attention_residual"] = inherited
    mlp_input = block.norm2(inherited) * (1 + mlp_scale) + mlp_shift
    state = inherited + mlp_gate * block.mlp(mlp_input.flatten(0, 1)).unflatten(0, (batch, destinations))
    condition = condition.repeat_interleave(destinations, dim=0)
    logits = readout.logits(state.flatten(0, 1), condition)
    exposure = (2 * logits.sigmoid() - 1).relu()
    if forced_exposure is not None:
        exposure = torch.full_like(exposure, forced_exposure)
    forecast = _first_effect_suffix(model, state.flatten(0, 1), condition, offsets.flatten(0, 1),
                                    common.repeat_interleave(destinations, dim=0), exposure[:, None])
    return forecast, logits, exposure, (batch * parents, batch * destinations)
```

```python
def _first_effect_step(model, window, controls, offsets, readout, compact, forced_exposure):
    predictor = model.predictor
    transformer = predictor.transformer
    common = offsets.unflatten(0, (-1, 2)).mean(dim=1).repeat_interleave(2, dim=0)
    bits = window.contiguous().view(torch.uint8).flatten(1)
    same_window = (bits[::2] == bits[1::2]).all(dim=-1)
    can_share = same_window if compact else torch.zeros_like(same_window)
    prefix_rows, prefix_inverse = _pair_representatives(can_share)
    state = predictor.dropout(window[prefix_rows] + predictor.pos_embedding[:, :window.size(1)])
    state = transformer.input_proj(state)
    condition = transformer.cond_proj(controls[prefix_rows])
    state = transformer.layers[0](state, condition + common[prefix_rows, 0, None])
    logits = readout.logits(state, condition)[prefix_inverse]
    exposure = (2 * logits.sigmoid() - 1).relu()
    if forced_exposure is not None:
        exposure = torch.full_like(exposure, forced_exposure)
    share_suffix = can_share & (exposure[::2] == 0) & (exposure[1::2] == 0)
    suffix_rows, inverse = _pair_representatives(share_suffix)
    prefix = prefix_inverse[suffix_rows]
    state, condition = state[prefix], condition[prefix]
    factor = exposure[suffix_rows, None]
    forecast = _first_effect_suffix(model, state, condition, offsets[suffix_rows], common[suffix_rows], factor)
    rows = (len(prefix_rows), len(suffix_rows))
    return forecast[inverse], logits, exposure, rows


def conditioned_rollout(model, history, past, actions, offsets, *, first_effect=None, compact=False,
                        trace=None, forced_exposure=None, ancestry=None, reference_action=None):
    """Expand separate native windows for explicit [batch, candidate, mode] requests."""
    batch, candidates, steps, action_width = actions.shape
    modes = offsets.size(1)
    if first_effect is not None and (modes != 2 or model.training):
        raise ValueError("First-effect routing uses two modes in native eval mode")
    if history.ndim == 3:
        history = history[:, None].expand(-1, modes, -1, -1)
    lineage = history.size(1)
    if ancestry is None and lineage != modes:
        raise ValueError("Independent rollout requires one history window per mode")
    if ancestry is not None and (first_effect is None or ancestry.shape != (batch, modes, lineage)):
        raise ValueError("History inheritance requires a distribution over histories for each mode")
    length, latent_width = history.shape[-2:]
    controls = torch.cat((past[:, None].expand(-1, candidates, -1, -1), actions), dim=2)
    controls = controls[:, :, None].expand(batch, candidates, modes, length + steps - 1, action_width)
    controls = controls.flatten(0, 2)
    window = history[:, None].expand(batch, candidates, lineage, length, latent_width).flatten(0, 2)
    offsets = offsets[:, None].expand(-1, candidates, -1, -1, -1).flatten(0, 2)
    forecasts, logits, exposures, rows = [], [], [], []
    for step in range(steps):
        command = controls[:, step:step + length]
        parents = None
        if step == 0 and ancestry is not None:
            parents = ancestry[:, None].expand(-1, candidates, -1, -1).flatten(0, 1)
        if parents is not None:
            bank = window.unflatten(0, (-1, lineage))
            arrival, score, exposure, step_rows = _inherit_first_effect(
                model, bank, command[::modes], offsets.unflatten(0, (-1, modes)),
                first_effect, parents, forced_exposure, trace, reference_action,
            )
            window = inherit_window(bank, parents).flatten(0, 1)
        elif first_effect is not None:
            arrival, score, exposure, step_rows = _first_effect_step(
                model, window, command, offsets, first_effect, compact, forced_exposure,
            )
        else:
            arrival = model.predict(window, command, condition_offsets=offsets)[:, -1]
        if first_effect is not None:
            logits.append(score.reshape(batch, candidates, modes))
            exposures.append(exposure.reshape(batch, candidates, modes))
            rows.append(step_rows)
        forecasts.append(arrival)
        window = torch.cat((window[:, 1:], arrival[:, None]), dim=1)
    if trace is not None and first_effect is not None:
        trace.update(logits=torch.stack(logits, dim=-1), exposure=torch.stack(exposures, dim=-1), rows=rows)
    return torch.stack(forecasts, dim=1).reshape(batch, candidates, modes, steps, latent_width)
```

```python
def advance_log_support(log_support, switch_probability):
    """Binary physical regime transition at an actual control-block boundary."""
    if switch_probability == 0:
        return log_support
    stay = log_support.new_tensor(1.0 - switch_probability).log()
    switch = log_support.new_tensor(switch_probability).log()
    return torch.logaddexp(log_support + stay, log_support.flip(-1) + switch)


def write_observation(log_support, issued, arrived, scale):
    """Score the one issued actual action with fixed sensor scales before refresh."""
    standardized = (issued - arrived[..., None, :]) / scale
    log_likelihood = -0.5 * standardized.square().sum(dim=-1)
    return (log_support + log_likelihood).log_softmax(dim=-1), log_likelihood
```

```python
class FourRoomHost(nn.Module):
    """Expose the checkpoint's existing projected modules through the native LeWM interface."""

        super().__init__()
        self.level = level

def action_embeddings(host, raw):

    raw = torch.as_tensor(raw, device=host.action_mean.device)
```

```python
def endpoint_metrics(values, y):
    targets = np.diff(y, axis=3).squeeze(3).reshape(-1, 4, 2)
    power = np.square(targets).sum((0, 2))
    c, l, f = (values[k].astype(np.float64) for k in ("C", "L", "F"))
    parts = {"C-Y": c - y, "L-C": l - c, "F-L": f - l}
    closure = float(np.abs(sum(parts.values()) - (f - y)).max())
    if closure > 1e-10:
        raise AssertionError("The physical decomposition must close per heldout branch")

    def rms(array):
        return np.sqrt(np.square(array.reshape(-1, 4, 2)).sum(-1).mean(0)).tolist()

    def gap(array):
        return np.diff(array, axis=3).squeeze(3).reshape(-1, 4, 2)

    def gain(array):
        return [float(num / den) if den > 0 else None
                for num, den in zip((gap(array) * targets).sum((0, 2)), power, strict=True)]

    return {"truth_gap_rms": rms(targets), "absolute_rmse": {k: rms(v - y) for k, v in values.items()},
            "mode_gap_rmse": {k: rms(gap(v) - targets) for k, v in values.items()},
            "mode_gap_gain": {k: gain(v) for k, v in (values | parts).items()}, "decomposition_max_residual": closure}
```

```python
def native_rollout(model, history, past, actions):
    """Continue one native window per candidate with no factual observations."""
    batch, count, horizon, _ = actions.shape
    length = history.size(1)
    controls = torch.cat((past[:, None].expand(-1, count, -1, -1), actions), dim=2).flatten(0, 1)
    window = history[:, None].expand(-1, count, -1, -1).flatten(0, 1)
    trajectory = []
    for step in range(horizon):
        predicted = model.predict(window, controls[:, step:step + length])[:, -1]
        trajectory.append(predicted)
        window = torch.cat((window[:, 1:], predicted[:, None]), dim=1)
    return torch.stack(trajectory, dim=1).reshape(batch, count, horizon, -1)
```

```python
                source_bce = F.binary_cross_entropy_with_logits(local_trace["logits"][:, 0, 0, 0], source_labels[s].float())
                loss = .5 * (per_h.mean() + mse + root_bce + source_bce)
                optimizer.zero_grad(set_to_none=True)
                loss.backward()
                grad = torch.linalg.vector_norm(torch.stack([p.grad.norm() for p in parameters]))
                record = torch.cat((loss[None], grad[None], per_h, mse[None], root_bce[None], source_bce[None]))
                record = record.detach().cpu().numpy()
                if not np.isfinite(record).all():
                    raise FloatingPointError(f"Nonfinite loss or gradient at {arm} update {update + 1}")
                optimizer.step()
                update += 1
                totals.append(record)
                rows.writerow([epoch, update, *record.tolist()])
            stream.flush()
            if epoch == 1 or epoch % 5 == 0:
                print(f"{arm} {epoch}/{EPOCHS}: {np.mean(totals, axis=0)}", flush=True)
    if update != 160:
        raise RuntimeError(f"Expected fixed 160 updates, got {update}")
    torch.save({name: module.state_dict() for name, module in modules.items()}, directory / "conditioned.pt")
```

```python
def clipping(start, actions, xy):
    """Use the stock position update before clipping, at each actual position."""
    trace = xy.reshape(len(actions), 2, -1, 2)
    source = np.concatenate((np.broadcast_to(start, (*trace.shape[:2], 1, 2)), trace[:, :, :-1]), axis=2)
    expected = source + SPEED * actions.reshape(len(actions), 1, -1, 2)
    return (expected != trace).any(axis=-1)


def choose_pair(scene, physical, score, start, root, raw, xy, parent_cost, false_goal, blocked):
    """Rank bad live queries and find a same-mode legal witness independently of their model rank."""
    candidates, modes = np.nonzero((false_goal | blocked)[4:])
    candidates += 4
    order = np.lexsort((modes, candidates, parent_cost[candidates, modes], ~false_goal[candidates, modes]))
    if not len(order):
        return None, "no_bad_live_query", False

    def legal_pool(actions, traces):
        terminal = traces[:, :, -1, -1]
        cost = score(terminal)
        legal = (~clipping(start, actions, traces).any(axis=-1)
                 & (room(terminal) != room(start)) & (cost < score(start)))
        return actions, traces, cost, legal

    menu = legal_pool(raw[:4], xy[:4])
    physical_pool = None
    for i in order:
        bad, mode = int(candidates[i]), int(modes[i])
        bad_cost = float(score(xy[bad, mode, -1, -1]))

            actions, traces, cost, legal = pool

            different_first_end = (traces[:, mode, 0, -1] != xy[bad, mode, 0, -1]).any(axis=-1)
            return np.flatnonzero(legal[:, mode] & (cost[:, mode] < bad_cost)
                                  & different_command & different_first_end)

        witnesses = matches(menu)
        if len(witnesses):
            routes = witnesses[witnesses < 2]
            preferred = routes if len(routes) else witnesses
            legal_index = int(preferred[menu[2][preferred, mode].argmin()])
            source = "visible_route" if legal_index < 2 else "archived_physical_cem"
```

```python
def encode_groups(env, host, groups, batch, known=None):
    """Render the exact stock RGB at reached positions, with scene-fixed geometry."""
    inputs = (known[0], *groups) if known is not None else groups

                                  axis=0, return_inverse=True)

    if known is not None:
        prefix = known[0].size // 2
        values[indices[:prefix]] = known[1].reshape(-1, 192)
        available[indices[:prefix]] = False
```

```python
def execute_selected(env, physical, start, goal, raw, full, chosen):
    """Verify every saved supervision trajectory and fixed sentinels against stock transitions."""
    sentinels = 4 + np.arange(ITERATIONS)[:, None] * SAMPLES + np.array((0, SAMPLES // 2))
    verify = np.unique(np.concatenate((chosen, sentinels.ravel())))
    for mode in (0, 1):
        env.begin(start, goal, mode)
        for index in verify:
            # There is no hidden dynamical state besides position and lock. The
            # actual common root is restored, with fixed geometry and goal.
            env.agent_position = torch.from_numpy(start.copy())
            observed = np.stack([env.execute(command) for command in raw[index]])
            np.testing.assert_array_equal(observed, full[index, mode])

    local = np.full((len(chosen), 2, HORIZON, 2, ACTION_BLOCK, 2), np.nan, dtype=np.float32)
    valid = np.ones(local.shape[:3], dtype=bool)
    actual = full[chosen]
    for i, index in enumerate(chosen):
        for mode in (0, 1):
            for horizon, command in enumerate(raw[index]):
                source = actual[i, mode, horizon - 1, -1] if horizon else start
                x, y = source
                # Inside the expanded vertical slab, closing its occupied
                # aperture would overlap the disk with a wall. Boundary touch
                # is legal in the canonical transition's strict inequalities.
                alternate = 1 - mode
                if (physical.near < x < physical.far
                        and abs(y - physical.lock_centers[alternate, 0]) > physical.aperture):
                    valid[i, mode, horizon] = False
                    continue
                for counterfactual in (0, 1):
                    env.set_mode(counterfactual)
                    env.agent_position = torch.from_numpy(source.copy())
                    local[i, mode, horizon, counterfactual] = env.execute(command)

    changed = (local[..., 0, :, :] != local[..., 1, :, :]).any(axis=-1)
    onset = np.where(valid & changed.any(axis=-1), changed.argmax(axis=-1), -1).astype(np.int8)
    np.testing.assert_array_equal(valid[:, 0, 0], valid[:, 1, 0])
```

```python
def _split_encoder_output(
    encoder_output,
    allow_cls_token: bool = True,
) -> torch.Tensor:
    hidden = (
        encoder_output.last_hidden_state
        if hasattr(encoder_output, "last_hidden_state")
        else encoder_output
    )

    if hidden.ndim == 2:
        return hidden
    if hidden.ndim == 3 and allow_cls_token:
        return hidden[:, 0]

    if hidden.ndim == 3:
        raise ValueError(
            "Chunked temporal encoder inputs must be collapsed by the encoder "
            "to rank-2 shape (B*T, D); got rank-3 output "
            f"with shape {tuple(hidden.shape)}"
        )

    raise ValueError(
        "Encoder output must be rank-2 or rank-3, "
        f"got shape {tuple(hidden.shape)}"

class ProjectedEncoder(nn.Module):
    """Encoder followed by its projection head."""

    def __init__(self, encoder, projector=None):
        super().__init__()
        self.encoder = encoder
        self.projector = projector or nn.Identity()

    def forward(self, x, *, allow_cls_token: bool = True):
        output = _run_encoder(self.encoder, x)
        hidden = _split_encoder_output(output, allow_cls_token=allow_cls_token)
        return self.projector(hidden)

    def encode_info(self, info, *, key: str, allow_cls_token: bool = True):
        x = rearrange(info[key].float(), "b t ... -> (b t) ...")
        return {"embed": self(x, allow_cls_token=allow_cls_token)}
```

```python
        """Encode observations and actions into embeddings.
        info: dict with pixels and action keys
        """
        chunked_state_input = False
        if chunk_temporal_inputs:
            if temporal_stride is None:
                temporal_stride = getattr(self, "temporal_stride", 1)
            temporal_window_size = getattr(self, "temporal_window_size", 1)
            chunked_state_input = int(temporal_window_size) > 1

            info = self._chunk_temporal_info(
                info,
                key=key,
                stride=temporal_stride,
                window_size=temporal_window_size,
            )

        B = info[key].size(0)
        encoder_outputs = self.encoder.encode_info(
            info,
            key=key,
            allow_cls_token=not chunked_state_input,
        )
        for output_key, value in encoder_outputs.items():
            info[f"{output_key}_0"] = rearrange(
                value,
                "(b t) ... -> b t ...",
                b=B,
            )

        if "action" in info:
            action_mask = info.get("action_mask")
            if action_mask is None:
                latent_actions = self.action_encoder(info["action"])
            else:
                latent_actions = self.action_encoder(info["action"], action_mask)
            self._update_latent_action_queue(latent_actions)
            info["action_0"] = self.action_embed(latent_actions)

        return info

    def predict(self, emb, act_emb):
        """Predict next state embedding
        emb: (B, T, D)
        act_emb: (B, T, A_emb)
        """
        return self.predictor(emb, act_emb)
```

```python
class ConditionalBlock(nn.Module):
    """Transformer block with AdaLN-zero conditioning"""

    def __init__(self, dim, heads, dim_head, mlp_dim, dropout=0.0):
        super().__init__()

        self.attn = Attention(dim, heads=heads, dim_head=dim_head, dropout=dropout)
        self.mlp = FeedForward(dim, mlp_dim, dropout=dropout)
        self.norm1 = nn.LayerNorm(dim, elementwise_affine=False, eps=1e-6)
        self.norm2 = nn.LayerNorm(dim, elementwise_affine=False, eps=1e-6)
        self.adaLN_modulation = nn.Sequential(
            nn.SiLU(), nn.Linear(dim, 6 * dim, bias=True)
        )

        nn.init.constant_(self.adaLN_modulation[-1].weight, 0)
        nn.init.constant_(self.adaLN_modulation[-1].bias, 0)

    def forward(self, x, c):
        shift_msa, scale_msa, gate_msa, shift_mlp, scale_mlp, gate_mlp = (
            self.adaLN_modulation(c).chunk(6, dim=-1)
        )
        x = x + gate_msa * self.attn(modulate(self.norm1(x), shift_msa, scale_msa))
        x = x + gate_mlp * self.mlp(modulate(self.norm2(x), shift_mlp, scale_mlp))
        return x
```

```python
class Transformer(nn.Module):
    """Standard Transformer with support for AdaLN-zero blocks"""

    def __init__(
        self,
        input_dim,
        hidden_dim,
        output_dim,
        depth,
        heads,
        dim_head,
        mlp_dim,
        dropout=0.0,
        block_class=Block,
    ):
        super().__init__()
        self.norm = nn.LayerNorm(hidden_dim)
        self.layers = nn.ModuleList([])

        self.input_proj = (
            nn.Linear(input_dim, hidden_dim)
            if input_dim != hidden_dim
            else nn.Identity()
        )

        self.cond_proj = (
            nn.Linear(input_dim, hidden_dim)
            if input_dim != hidden_dim
            else nn.Identity()
        )

        self.output_proj = (
            nn.Linear(hidden_dim, output_dim)
            if hidden_dim != output_dim
            else nn.Identity()
        )

        for _ in range(depth):
            self.layers.append(
                block_class(hidden_dim, heads, dim_head, mlp_dim, dropout)
            )

    def forward(self, x, c=None):
        x = self.input_proj(x)

        if c is not None:
            c = self.cond_proj(c)

        for block in self.layers:
            x = block(x) if isinstance(block, Block) else block(x, c)
        x = self.norm(x)
        x = self.output_proj(x)
        return x


class Embedder(nn.Module):
    def __init__(
        self,
        input_dim=10,
        smoothed_dim=10,
        emb_dim=10,
        mlp_scale=4,
        patch_embed=True,
    ):
        super().__init__()
        self.patch_embed = (
            nn.Conv1d(input_dim, smoothed_dim, kernel_size=1, stride=1)
            if patch_embed
            else None
        )
        feature_dim = smoothed_dim if patch_embed else input_dim
        self.embed = nn.Sequential(
            nn.Linear(feature_dim, mlp_scale * emb_dim),
            nn.SiLU(),
            nn.Linear(mlp_scale * emb_dim, emb_dim),
        )

    def forward(self, x):
        """
        x: (B, T, D) or (B, T, C, D)
        """
        x = x.float()
        if self.patch_embed is not None:
            if x.dim() == 3:
                x = x.permute(0, 2, 1)
                x = self.patch_embed(x)
                x = x.permute(0, 2, 1)
            elif x.dim() == 4:
                b, t, c, d = x.shape
                x = x.reshape(b, t * c, d)
                x = x.permute(0, 2, 1)
                x = self.patch_embed(x)
                x = x.permute(0, 2, 1)
                x = x.reshape(b, t, c, -1)
            else:
                raise ValueError(f"Expected 3D or 4D input, got shape {tuple(x.shape)}")
        x = self.embed(x)
        return x
```

```python
class TorchVisibleMapCost:
    """Use the exact visible paths from the physical scorer and differentiate their lengths."""

    def __init__(self, score, device):
        points, residual = zip(*[list(zip(*choices)) for choices in score.paths.values()])
        self.first = torch.as_tensor(np.asarray(points), dtype=torch.float32, device=device)
        self.residual = torch.as_tensor(np.asarray(residual), dtype=torch.float32, device=device)

    def __call__(self, xy):
        right, bottom = (xy >= CENTER).unbind(-1)
        room_index = torch.where(bottom, torch.where(right, 2, 3), right.long())
        candidate_cost = torch.linalg.vector_norm(xy[..., None, :] - self.first[room_index], dim=-1)
        return (candidate_cost + self.residual[room_index]).min(dim=-1).values
```

```python
        ).transpose(2, 0, 1)

        next_x = np.where((x < CENTER) & (next_x > self.near) & ~vertical, self.near - .5, next_x)
        next_x = np.where((x >= CENTER) & (next_x < self.far) & ~vertical, self.far + .5, next_x)
        horizontal = ((np.abs(next_x - self.left) <= self.aperture) |
                      (np.abs(next_x - self.right) <= self.aperture))
        next_y = np.where((y < CENTER) & (next_y > self.near) & ~horizontal, self.near - .5, next_y)
        next_y = np.where((y >= CENTER) & (next_y < self.far) & ~horizontal, self.far + .5, next_y)
        return np.stack((next_x, next_y), axis=-1)

        for controls in plans.transpose(1, 0, 2):
```

```python
class VisibleMapCost:
    """Stock door-centre path length, independent of the invisible lock mode."""

    def __init__(self, scene, goal):
        self.goal = goal
        target_room = int(room(goal))
        self.paths = {}
        for source_room in range(4):
            choices = []
            for direction in (1, -1):
                entries = doors_between(source_room, target_room, direction)
                points = [door_xy(scene, door) for door in entries] + [goal]
                residual = sum(np.linalg.norm(end - begin) for begin, end in zip(points, points[1:]))
                choices.append((points[0], residual))
            self.paths[source_room] = choices

    def __call__(self, xy):
        locations = room(xy)
        cost = np.empty(xy.shape[:-1], dtype=np.float32)
        for source_room, choices in self.paths.items():
            mask = locations == source_room
            points = xy[mask]
            cost[mask] = np.minimum(*(np.linalg.norm(points - first, axis=-1) + residual
                                      for first, residual in choices))
        return cost


def route_points(scene, start, goal, direction):
    source = int(room(start))
    doors = doors_between(source, int(room(goal)), direction)
    points = []
    for door in doors:
        center = door_xy(scene, door)
        axis = 0 if door in ("top", "bottom") else 1
        before = center.copy()
        before[axis] += (-10 if source in ((0, 3) if axis == 0 else (0, 1)) else 10)
        points.extend((before, 2 * center - before))
        source = (source + direction) % 4
    return points + [goal]


def route_seed(scene, start, goal, direction, horizon):
    """Visible-map centrelines give both CEM components equally legal warm starts."""
    position = start.copy()
    commands = []
    for target in route_points(scene, start, goal, direction):
        while np.max(np.abs(target - position)) > 1e-4 and len(commands) < horizon:
            command = np.clip((target - position) / (SPEED * ACTION_BLOCK), -1, 1)
            commands.append(command)
            position += command * SPEED * ACTION_BLOCK
    return np.asarray(commands + [np.zeros(2, dtype=np.float32)] * (horizon - len(commands)))


def cem_population(scene, goal, start, horizon, rng, candidate_cost):
    """Two equal proposal components, all candidates scored under both modes.

    One component optimizes each hypothesis. The proposal and raw sample draws are
    independent of which policy requests the action. All policies can select any
    candidate in the pooled bank using their specified beliefs.
    """
    means = np.stack([route_seed(scene, start, goal, direction, horizon)
                      for direction in (1, -1)])
    spreads = np.full_like(means, 0.65)
    plans_seen, costs_seen = [], []
    for _ in range(ITERATIONS):
        noise = rng.standard_normal((2, SAMPLES // 2, horizon, 2), dtype=np.float32)
        proposals = np.clip(means[:, None] + noise * spreads[:, None], -1, 1)
        proposals[:, 0] = means
        plans = proposals.reshape(SAMPLES, horizon, 2)
        costs = candidate_cost(plans)
        if costs.shape != (2, SAMPLES) or not np.isfinite(costs).all():
            raise ValueError("Each CEM candidate must have two finite hypothesis costs")
        plans_seen.append(plans)
        costs_seen.append(costs)
        # Both components may inherit elites from either part of the shared bank.
        elites = plans[np.argsort(costs, axis=1, kind="stable")[:, :ELITES]]
        means = elites.mean(axis=1)
        spreads = np.maximum(elites.std(axis=1), 0.10)
    return np.concatenate(plans_seen), np.concatenate(costs_seen, axis=1)
```

```python
            self.grid_x <= (self.WALL_CENTER + half)
        )
        horizontal_wall = (self.grid_y >= (self.WALL_CENTER - half)) & (
            self.grid_y <= (self.WALL_CENTER + half)

        bottom = self.door_positions['bottom']

        right = self.door_positions['right']
```
