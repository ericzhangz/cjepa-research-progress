# 用已到达的经历确定哪些原生动作条件可以合并

2026-11-12 · 构造、适用条件及进入原生测试前的判据

## 1. 计算选择

在已证实无接触的一段控制里，推手的中间路径可能不同，但只要动作结束时的位置和速度相同，且物体仍处于同一静止位姿，后面的相同命令就具有相同物理后果。用这个关系定义 LeWM **动作嵌入的输入等价性**。模型每个动作 token 是五个按序打包的二维原始命令。压缩只在一个动作 token 内进行，时间索引、实际执行命令和候选后缀都保留。修改发生在原生动作嵌入的非线性之前，所有后续条件块读取同一个代表。 原生动作嵌入（原工程资料，未随包同步） · 控制打包（原工程资料，未随包同步）

## 2. 由原生控制时间导出等价类

对每个空间轴，以 \(p,v\) 表示推手位置和速度。一个原始控制开始时目标为 \(q=p+100a\)。每个子步的误差—速度矩阵是
\[
K=\begin{pmatrix}.99&.008\\-1&.8\end{pmatrix}.
\]
记 \(K^{10}=\left(\begin{smallmatrix}d_{11}&d_{12}\\d_{21}&d_{22}\end{smallmatrix}\right)\)。十个子步后
\[
\begin{pmatrix}p'\\v'\end{pmatrix}
=M\begin{pmatrix}p\\v\end{pmatrix}+B a,\qquad
M=\begin{pmatrix}1&d_{12}\\0&d_{22}\end{pmatrix},\quad
B=100\begin{pmatrix}1-d_{11}\\-d_{21}\end{pmatrix}.
\]
长度为 \(m\) 的前缀 \(U\in\mathbb R^{m\times2}\) 在边界上的贡献为 \(C_m U\)，其中 \(C_m=[M^{m-1}B,\ldots,B]\)。定义代表和投影 \(U_*=P_m U,\ P_m=C_m^+C_m\)。此处投影作用于实际命令坐标，保留已知动力学的完整边界状态。\(m=1,2\) 没有需要消除的自由度。

等价成立还需要前缀中的每一条相关路径都不使物体获得冲量。记 \(\mathcal X_t\) 为只用截至 \(t\) 已到达的图像和已执行命令得到的物理可能集合。在可认证的动作域 \(\|U\|_F\le R_m\) 内，所有同边界命令都形如 \(U_*+N\)，且
\[
C_mN=0,\qquad \|N\|_F\le \sqrt{R_m^2-\|U_*\|_F^2}.
\]
令 \(L_k\) 为同一控制律到第 \(k\) 个物理子步位置的线性作用。用
\[
\|L_k(I-P_m)\|_2\sqrt{R_m^2-\|U_*\|_F^2}
\]
作为代表轨迹到整类轨迹的偏差界，再计入 \(\mathcal X_t\) 的位置、速度和物体姿态不确定性。只有整类扫掠均不与物体相交、物体静止且不受墙干涉、代表命令可执行时才合并。可用原有距离下界对逐段折线证明分离。以整类扫掠作判断，避免两条同边界命令因为路径不同而得到不一致的代表。此证书是充分条件，覆盖率可能低。

任一已认证前缀可换成代表，后面的原始命令保持。替换前后的 \((p,v)\)、物体姿态和速度在边界相同，后缀的确定性原生物理推进从同一状态出发。因此任何后续模型边界和跨度的真实物理后果相同。对较长前缀 \(m'>m\)，边界作用的差仍为 \(M^{m'-m}C_m(U_*-U)=0\)。若固定动作域使用每步同一界，且只考虑原始与代表均在域内的替换，则用按类定义的条件从 \(m=5\) 向下选第一个可行前缀，不会因为换成代表而使已检查的较长边界类改变。实验先固定一个 \(m\)，避免不同长度的约束相互影响。该关系只针对模型边界及其后续，前缀内部图像、路径代价、终止条件和未建模接触均须单独处理。

## 3. 经历怎样维持、修订与撤销

对于实际执行的命令 \(U_t\)，公共可能集合由同一控制律推进。若某段不能保证分离，必须允许实际物体改变，直至新观察重新提供依据。新真实观察到达后，以相容的测量集合缩小先前已推进的 \(\mathcal X_{t+1}^{-}\)，得到 \(\mathcal X_{t+1}^{+}\)。如果测量和先验不相容，原先的无接触依据失效，以真实观察重建该时刻的状态。依赖失效证据的历史动作 token 在仍处于三帧窗口时恢复原始命令。假想推进只影响候选内的证书。保留真实原始命令和时间索引作为写入依据。原生三帧调用的每个历史动作 token 按该动作起点的已到达证据构造，缺证时走原始编码。未来预测使用与真实历史相同的规则。

**多轮可执行例。** 一维简化控制 \(v'=v+a,\ p'=p+v'\) 的三步矩阵行是 \((3,2,1),(1,1,1)\)，零空间含 \((1,-2,1)\)。从 \((0,0)\) 出发，保持命令与这条命令都在三步后回到 \((0,0)\)。若首个真实图像只约束障碍可能在 \(p=0.8\) 或足够远处，则不能消去来回路径。真实执行一次保持后，新观察排除近处障碍。只要同类扫掠的上界远小于确认距离，任意后缀的 H1/H2 均可共享三步边界，下一轮在遮挡中仍可继承这一依据。若再一次到达的真实观察显示物体已进入扫掠区，代表规则撤销。实际近处障碍为反例，两条命令端点虽然相同，其中一条会撞到物体。一个一直位于扫掠外的无关视觉变化无需触发改写。

## 4. 训练、归因与阶段退出

只在真实执行命令的合法证书成立时，将等价代表作为原生动作嵌入输入，使用原始轨迹实际到达的模型边界 latent 和后续真实未来监督。未通过证书的部分仍使用原始命令。冻结部署权重。主要对照为原生相同数据与预算的微调、同一代表计算加仅当前窗口的证书，以及固定场景无关的端点动作压缩。Do-JEPA 的成对未来差直接监督动作效果，可作为同数据的训练参照。当前计算的额外要求是：已到达经历决定一个有限等价类是否可用，并在模型输入侧对齐这个类的所有命令。两种方法都需在真实物理后果上评估。 [Do-JEPA §3、§4.3](https://arxiv.org/html/2609.37378v1#S3)

首阶按顺序看边界精确性、发生接触的反例、跨真实到达的证书变化，以及现有档案是否真有可改写的动作。若档案只包含已经在 \(C_m\) 行空间内的命令，任何证书也不能改变动作嵌入。若有可改写命令但合法前缀无法支持整类分离，当前证据链仍不成立。随后才可固定原生窗口、比较真实动作与等价代表的 action embedding、AdaLN 条件和多步预测。这个对照可以度量物理等价命令的原生敏感性，独立预测增益仍需真实分支与匹配对照。

## 5. 独立审查与初阶裁定

取 \(\ell^\top=(1,d_{12}/(1-d_{22}))\)。则 \(\ell^\top M=\ell^\top\)，且
\[
\ell^\top C_m=(\ell^\top B)\mathbf 1^\top,\qquad
\ell^\top B=100\,\frac{\det(I-K^{10})}{1-d_{22}}\ne0.
\]
因此恒定命令前缀已经在 \(C_m\) 行空间内，精确的改写为恒等。若把压缩扩到两个模型块并额外保护中间边界，约束重新分解为块内约束，仍为恒等。若省去中间边界约束，H1 的监督和真实观察时间将失去原来的对应关系。

遮挡档案与 MSP 共 21,600 个存储动作块，均为块内恒定控制，证明与数值结果一致。现有作者专家前缀的 48 个动作块在 \(m=3,4,5\) 都有非零改写。按同一无碰撞推手递推，完整块末的位置和速度差分别在 \(10^{-13}\) 像素、\(2.1\times10^{-13}\) 像素每秒内。运动学相等仍不能判定扫掠分离。二维反例中，原路径从障碍旁绕过，代表路径穿过障碍，终端位置和速度依旧相同。

本轮止于解析和动作输入台阶。已有专家前缀提供非恒定动作和事实图像，但尚未建立仅凭已到达视觉的分离证书，也没有满足当前归因要求的多轮真实动作分支。把确定的代表函数置于嵌入调用之前，与在嵌入入口实现同一个函数等价。若后续推进，首先须证明持续合法经历对可合并范围有可辨识作用，再用相同历史重算对照归因。 [原始结果与阶段裁定](../../runs/native_action_equivalence_20261112/REPORT.md)
