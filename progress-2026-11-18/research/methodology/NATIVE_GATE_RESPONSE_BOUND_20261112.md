# 用真实后果限定原生动作作用

## 一个接触例子中的保持与撤销

在原生自由运动预报的局部坐标中，设 \(q\) 是候选命令的预报端点，\(p\ne q\) 是该命令实际到达的接触端点，\(u\) 与 \(p-q\) 同向。假定接触是同一固定支撑面上的单侧反作用，且反作用方向保持不变。其他已确认的接触端点相对 \(p\) 的差张成切空间 \(D\)。相容的支撑面法向协向量满足 \(\ell(u)=1,\ell(D)=0\)。若一个新命令的原生预报满足 \(q'-p=d+\lambda u,\ d\in D\)，所有相容支撑面给出的修订相同。

\[
q'\longmapsto q'+u[-\lambda]_+.
\]

一条接触经历已约束反作用线上的预测。另一条独立的接触端点会扩充可迁移的方向。在该仿射子空间外，仅凭这些端点无法保证同一修订。这项计算对可逆仿射坐标变换保持等价。原生预报已经在可行侧时，修订严格为零。一次外向行动可以让本次反作用消失，同时保留仍有效的支撑面。若已执行动作真实穿过此前边界，旧条件才受到反证。上述结构是已知的接触辨识与斜投影，作为可手算的参照。已有工作从真实接触轨迹联合辨识接触与连续动力学，也有在 MPC 前持续学习接触残差的实现。 [Bianchini 等](https://proceedings.mlr.press/v229/bianchini23a.html) · [Huang 等](https://arxiv.org/abs/2310.09893)

## LeWM 的具体计算位置

FourRoom checkpoint 的 `ProjectedPredictor` 包住 `ARPredictor`。最后一个 `ConditionalBlock` 在最后 token 计算 \(h=x+g(a)\odot m(x,a)\)。这里 \(x\) 是已包含该块 attention 的残差，\(m\) 是该块原生动作条件 MLP 输出，\(g\) 是该块第六组 AdaLN 系数。剩余原生映射 \(P\) 是 `transformer.norm → output_proj → predictor.projector`。保持动作命令、\(x\) 与 \(m\) 时，改变 \(g\) 对 \(h\) 的作用是精确的逐通道乘法。最后一块之后没有另一层动作条件 attention 或 MLP 重新读取命令。

预期的单侧作用需要明确的分段运算。在固定观察和固定持续状态下，只用原有 SiLU、GELU、LayerNorm、线性投影及带固定因果 mask 的 softmax 做平滑调制，预测差对连续动作是实解析的。若它在相连动作域的开子集严格为零，解析函数的恒等定理使它处处为零。这个结论只针对精确不干预的性质；平滑近似仍可有效。这里采用 \([\cdot]_+\)，让未触发的候选完全走原生计算。

考虑一条固定的 gate 方向 \(u\) 与一条预测端点坐标 \(s=w^\top h\)。两者是离线可学习的量。由于原生末端 LayerNorm 消去 \(h\) 的共同平移，取 \(w^\top\mathbf1=0\)，使同一可见预测的这项规范自由度不改变边界判断。定义当前命令的原生乘积方向 \(d=m\odot u\) 与归一化的 \(v=d/(w^\top d)\)。只在分母有足够裕量的作用域使用这一坐标。给定持续条件 \(b\)，预测为

\[
h_b=h-v[s-b]_+,\qquad \hat z_b=P(h_b).
\]

当 \(s\le b\)，直接返回原生计算，且无需计算分母。约束起效时，原生 gate 只增加 \(-u[s-b]_+/(w^\top d)\)，且 \(w^\top h_b=b\)。\(u\) 的非零标量缩放抵消，\((w,b)\) 的共同正缩放也不改变输出。相同边界在不同动作及观察上共用。\(m\) 仍随每次原生命令与历史变化，因此一项共同约束可以在不同命令下改变不同的隐藏方向。\(s\) 读的是计算后的端点，能够随当前间隙变化；仅从动作依赖的 \(g(a)\) 读取不具备这个性质。此处隐藏量的等式不证明物理位移或切向效果。必须用真实后果检验这个坐标和作用范围。

## 真实后果用同一条曲线约束边界

已发出的实际动作预测提供未经约束的 \(h_i,v_i,s_i\)，即使当次实际向 planner 提供的是受限预测。写入以未经约束的曲线为参考，实际后果才能反证旧边界。如果用上次已经截断的端点定义曲线可达范围，真实结果突破旧边界时可能被误判为曲线失配。令

\[
T_i(c)=P\big(h_i+v_i(c-s_i)\big),\qquad
S_i=\{c\le s_i:\|T_i(c)-E(o_{i+1})\|\le\epsilon_i\}.
\]

限定在预先定义的局部曲线范围内，真实后继只检验一条原生输出曲线，无需把编码器的输出假设为某个内部激活。可观测量为集合 \(S_i\)，其误差带涵盖原生映射能力和视觉噪声。\(w^\top d\) 有裕量只保证内部坐标可控，\(P\) 之后仍可能不可辨。若在该区间有一个单位读出方向 \(r\) 满足 \(\partial_c(r^\top T_i(c))\ge\mu>0\)，则 \(S_i\) 的直径最多为 \(2\epsilon_i/\mu\)。这提供了一项可测的事实写入条件。与这条经历相容的边界集合为

\[
B_i=\{b\in\mathbb R\cup\{+\infty\}:\min(s_i,b)\in S_i\}.
\]

持续状态在同一局部规律内保留相容边界的交集。只施加所有相容边界都要求的最小修订，即用其上确界作为 \(b\)。若上界无限，当前事实尚未支持非零修订。实际预测的原生中间量和到达观察用于写入。假想候选只读取状态；每一步用该分支的当前 \(h,m\) 重新计算受限程度。真实后继在前面条件不足时仍可收紧区间。已观察后果与旧区间冲突、但与本次原生曲线和边界族相容时，才有依据在解析例的切换假设下重建当前区间。若 \(S_i\) 为空，本例的解释族失配，不能把这个事件当成有证据的释放。一般情境中一次矛盾也可能来自噪声或新物理机制，释放规则须单独建立。

无噪声、局部可逆时，若真实曲线坐标为 \(c_i<s_i\)，则 \(b=c_i\)。若 \(c_i=s_i\)，事实只说明 \(b\ge s_i\)。例如原生端点依次为 \(-1,2,-1,2\)，真实端点依次为 \(-1,0,-1,2\)。第一次只排除低于 \(-1\) 的边界。第二次建立 \(b=0\)，两个后续想象命令的预测可以立刻使用。第三次原生输出保持，边界仍是零。第四次真实端点穿过零，旧边界被排除，新的相容集合为 \([2,+\infty]\)。以上是同一模型族内的算例。若共享偏差发生在接触前，它会移动阈值，不能直接套用前文（原工程资料，未随包同步）所用的接触后共同偏差模型。

这条方案的计算对象是**真实端点支持的、对所有候选共享的原生预测作用边界**。读与写使用同一条由原生乘积确定的曲线。斜投影与区间辨识各有先例。潜在新增内容在于这条受当前原生命令驱动的曲线能否把跨事实证据转换为有选择性的预测作用。必须检验它能否表达真实受限后果，同时保留另一项独立的命令效应。以纯 XY 为评价时，可逆的动作映射可能产生同一结果。例如原生响应 \((s,t,j)=(a_x,a_y,a_x)\)，其中 \(j\) 是独立可见的命令后果。受限响应 \((\min(a_x,0),a_y,a_x)\) 在 \(a_x>0\) 时无法通过替换同一个原生命令得到。PushT 应先确认 pusher 与被推物后果是否提供这样的可区分条件。

## 监督与成本边界

后续小型学习先要求跨真实输入的原生曲线具有一致、可观测的作用。保留一小组同根自由和接触分支，先执行真实前缀来形成边界集合，再用两个以上动作的真实端点来监督读取。约束项的任务相关方向由真实运动/接触后果定义。被保留的独立命令效应也由真实分支监督，避免学到只靠改写动作的解。实际训练之前须先固定曲线局部可辨识性、隐变量能否迁移及原生非退化条件。在线后果只写状态，部署参数固定。多时域通过同一预测器逐步展开；该机制没有产生宏步。假想阶段只需一次原生 predictor，门控干预新增向量内积与逐通道运算。一次事实写入需要保留当前曲线输入并在末端 \(P\) 上求区间；需要计量求解器调用与持有量。无需重放此前动作或重新跑前缀。此处没有训练结果或时间收益。

## 已固定的第一项宿主中间量试验

只使用原始 FourRoom checkpoint 和已有评估集的前八个起点。每根使用既有 `stop`、`constant_0`、`constant_2`、`constant_4` 四条候选的首个动作块。观察止于分支起点，预测取最后一个 token。在 T=1 与 T=3 分别检查以下性质。

1. 捕获 \(x,m,g,h\)，重构原生最后一块并用原生后部生成 latent。数值对照绝对容差 \(2\times10^{-5}\)。
2. 仅以固定的前两个激活通道设 \(w=(e_0-e_1)/\sqrt2\) 与 \(u=e_0+e_1\)。每根用四候选原生 \(s\) 的最小与最大值中点定义人工边界。该边界只用于中间量干预，原始帧和真值不提供条件。对照实际原生 gate hook 与解析 \(h_b\) 的后部输出，非触发请求原生输出逐元素相等，触发请求的坐标精确到同一容差。报告所有坐标、作用、分母和误差。分母小于 \(10^{-4}\) 的触发请求直接作为局部坐标不适用的失败记录。

本台阶不解释冻结方向的物理语义。只有原生拆分成立后，才研究真实端点是否在共享曲线附近，以及同一局部规律能否从已执行的真实命令支持不同候选。这两项需要一项有独立命令后果的接触任务，随后才考虑模型训练与多步自由预测。

第一台阶已完成。固定方向能实现预定作用，但个别输入需要很大的原生 gate 改变量。最大的系数变化为 66.01，两个相应原生通道在全部请求中的最大绝对值为 1.90。条件 \(w^\top d\ne0\) 只保证代数可算。未来须同时报告将真实后果带回曲线所需的系数与灵敏度，才能判断它能否成为稳定的物理作用。 [接口结果](../../runs/native_gate_bound_20261112/interface/REPORT.md)

## 同一个原生边界由动作后果差支持的条件

对一个只调节某项动作作用的机制，要求它重建整个视觉后继，会额外要求它解释与此作用无关的原生失配。可以直接从两条合法事实推导适合该作用的证据。令 \(R_n\) 为一项事先定好的可观测后果读出，\(y_i=R_n(E(o_{i+1}))\)，\(k_i(b)=R_n(T_i(\min(s_i,b)))\)。假设两条经历处于同一约束规律，且读出在该局部窗口有同一个未知的加性偏差 \(\nu\)。将两次观测建模为 \(y_i=k_i(b)+\nu+e_i\)，就得到

\[
\big|(y_2-y_1)-(k_2(b)-k_1(b))\big|\le \epsilon_1+\epsilon_2 .
\]

右侧是两次观测的误差界。它直接给出共同边界的相容集合。写入由两次已经发生的动作后果决定，对共同的输出偏差不敏感；预测仍通过同一原生曲线使用边界。这个式子不改变实际世界条件，不允许用未执行的候选形成观测证据。

一个可手算的例子。若 \(k_i(b)=\min(s_i,b)\)、\(s_1=-1,s_2=2\)，两事实的观测差为 1，则 \(b=0\)，与共同偏差取值无关。观测差为 3 时只说明 \(b\ge2\)，两个动作都没有激发边界。差为 0 时只说明 \(b\le-1\)，两动作都受到相同截断。实际曲线中，在 \(s_1<b<s_2\) 上只有第二条曲线受限，若其可见斜率有已知正下界 \(\mu\)，该区间里的相容边界直径至多为 \(2(\epsilon_1+\epsilon_2)/\mu\)。还需排除该区间外产生同一差值的其他可行解。两条历史的偏差不同、偏差发生在截断前、或物体变化使边界发生移动时，上述推导不能推出共同边界。这些属于各自应识别的物理条件。

这条推导规定了下一项学习的对象。要用真实后果直接监督同一有限原生曲线在两种实际作用下的差，并用独立后果检验该改变有没有伤害其余原生响应。上一阶段只用局部导数定方向；事后逐候选选点的改善上限已经很小，单独更换写入误差无法解决曲线幅度和方向的问题。后续候选需要学会产生所需的有限作用，同时确认两条真实事实是否满足共享条件。当前没有将这条关系用于旧 PushT 分数重试。
