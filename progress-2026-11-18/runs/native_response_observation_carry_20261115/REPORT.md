# 冻结 LeWM 中完整观测的跨步作用

2026-11-15，核心机制稿 §25.3 的固定宿主台阶。目的为测量已公开的历史在经过官方原生递推后，是否仍包含足够且方向正确的绝对状态与相对动作差。

## 输入和对照

使用记录中的 16 个历史开发场景，每场景 4 个基础世界，每个世界两条镜像执行历史，共 64 对。步 110 的输入是当时已经公开的步 100、105、110 编码，后两个画面实际为完整公开。之后仅按已执行的新命令滚动推进到步 125，没有使用期间实际已到达的三个局部画面。对照直接从 115、120、125 的三份公开编码启动。同对的这三个编码和最近两段动作相同。各臂用相同官方模型、原生三帧递推和四条真实候选，候选 3 是零命令保持。H1/H2 为 5/10 个环境步。后续完整图像编码和模拟器坐标只用于事后评分。物理预测使用此前只用拟合数据得到的冻结读出。

## 可见历史传播后的中间量

沿 110 继续传播时，对真实完整编码的逐维 RMSE 在步 115、120、125 分别为 0.0789、0.1089、0.1358。镜像差的逐维 RMSE 分别为 0.1083、0.1496、0.1868。误差随时间增加，同时仍保留了可用的物理差。

| 步 125 输出，H1 / H2 | 真实镜像差 RMS | 公开三帧的镜像差 RMSE | 110 续接的镜像差 RMSE | 110 续接时交换历史导致的端点均方误差增量 |
| --- | ---: | ---: | ---: | ---: |
| 绝对保持位置 | 54.03 / 54.03 | 54.03 / 54.03 | 17.45 / 19.00 | +2952.74 / +3002.00 |
| 非保持候选相对保持 | 19.99 / 37.66 | 19.99 / 37.66 | 11.21 / 19.50 | +297.90 / +1058.06 |

每种输出、每个跨度，历史差误差在全部 16 个场景均降低。直接从公开等价窗口询问，两段历史的预测差为零。110 续接预测的镜像差 RMS 分别为保持 57.37/58.70，相对保持 17.94/32.83。交换历史后共同中点不变。在两种输出上，交换均增大聚合平方误差，说明匹配的预测差和真实差总体同向。

完整端点的绝对保持 RMSE 从公开窗口的 66.49/65.92 降至 14.32/15.44。相对保持从 14.20/26.48 降至 7.61/13.44。真实完整后继编码经同一个冻结读出得到的端点 RMSE 为绝对保持 9.05/9.05、相对保持 5.24/10.21，读出自身存在有限误差。

两臂消费的观测不同，所得结果定位的是在这个档案里官方原生状态传播的可用性。当前候选的部分观测评分与写入仍需单独验证。尤其步 115–125 的局部图像可能有信息，它们在续接臂被人为省略。没有运行训练、引入新权重、重建场景或评价长程闭环。这份冻结续接本身也是后续机制的直接基线。
