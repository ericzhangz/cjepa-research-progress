# 无接触前缀的物理证据与原生输出锁定裁定

## 已完成的台阶

复用原 PushT 96 个开发场景、48 个回归场景。每个场景四个物理世界，每个查询时刻四个原候选。初始位置、速度和物体姿态来自已到达的模拟器真值，仅用于物理诊断。十个物理子步的推手递推在两档全部分支中精确复现每个环境步的位置和速度。正例通过，路径中途穿过物体与物体仍在运动两个反例均拒绝发证。

| 查询时刻 | 回归分支 | H1/H2 有证书 | H1/H2 观察到无接触 |
| --- | ---: | ---: | ---: |
| t10 | 768 | 34 / 34 | 36 / 36 |
| t15 | 768 | 205 / 205 | 254 / 249 |
| t20 | 768 | 99 / 99 | 104 / 104 |
| t30 | 768 | 268 / 267 | 285 / 284 |

所有有证书的分支均无实际接触，物体位姿变化均为零。回归档只有一条证书从 H1 延续后在 H2 失效的分支，即场景 102022、world 1、t30、候选 0。该分支 H2 实际发生接触。 完整计数（原工程资料，未随包同步） · 逐场景中间量（原工程资料，未随包同步） · 计算入口（原工程资料，未随包同步）

## 合法输入和最简对照

独立审查在已有档案中找到一个不可辨识例。场景 102000 的 world 2/3 在 t10 的全部已到达遮挡图像和实际命令相同。候选 2 在 world 2 有无接触证书，在 world 3 实际接触。任何仅从合法前缀得出的保证都须覆盖两种解释。t15 局部可见信息可揭示推手侧别，已有证据尚未给出足以证明分离的度量位置、速度和物体静止性。t20/25/30 的遮挡输入也没有第二次区分这些世界的观察。因而物理覆盖率是此证书的特权诊断，线上覆盖率仍未知。

设原生最后仿射层为 \(y=Wq+b\)。在层前将 \(q\) 改为 \(q+Ld\)，精确等价于在层后将 \(y\) 改为 \(y+WLd\)。二者若把同一修订后的完整 latent 追加回原生窗口，归纳可得各跨度的输入、状态和输出均相同。只修终点的对照没有这一递推，无法判断原生接入是否有独立价值。此外，现有提升矩阵只改物体 XY，保持角度读出。
