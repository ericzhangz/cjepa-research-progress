# 全深度条件化的 Oracle 容量见证

按核心稿 §26 先固定档案和损失，再执行 384 次全层条件适配。原生 LeWM 权重冻结。八种解释来自初始物体朝向、推手侧别与已执行绕位三个二元事实，并与公共直推方向组合。选择正确索引是离线 oracle，未来真值仅用于训练与评价。旧拟合与开发分别为 16 个场景，开发 64 对同窗镜像共享步 125 当前三帧、近期动作和候选。条件变化进入六层 AdaLN。零码使原生分支恢复旧输出。

覆盖按真差和预测差的内积除以真差能量计算。两类输出的配对增量在全部 16 个场景同向。H1 相对动作的历史差误差在 15/16 个场景降低，其余三项为 16/16。绝对保持中点误差 41.73/38.73，相对动作中点 8.54/15.30。交换 Oracle 索引后保留中点，历史差变差，说明增益不只由共同拟合产生。

H1 的同向覆盖突破一半但低于事先指定的约 0.75，当前档案不升级到端到端联合训练。这是给定输入、训练预算和适配器下达到的值。§22 给出的 0.00760 与 0.02208 是另一固定关系族的上界。覆盖的增加证明全层构造有实质物理作用，但既不改变旧上界的范围，也不构成新架构的上界。

最强参考依然是 §25.3 的合法完整续推。它的绝对保持差 RMSE 17.45/19.00，相对动作 11.21/19.50，且绝对端点误差小得多。Oracle 的 H2 绝对差略好，其余三项未超过合法原生续接。因此不把这次能力见证当成最终方法提升。全视图可逆条件用独立的任务区分物理动力学与遮挡状态估计。
