# 原生动作前缀、逐次真实证据与候选用途

沿用 §28 原生第一次分歧、两种模式和粗时间续推。仅学习 4 个原生动作 embedding 宽度的向量，用实际前缀的原始控制步数缩放一项动作条件的仿射变化。先遮蔽当前未执行的命令。第 5 步直接调用旧动作条件。中间视觉既不改变原生窗口的时间，也不作为模型预测下一状态的真值。320 次更新，20 个拟合场景的 960 个同根物理对。固定观测尺度拟合用另外 4 个场景的 192 对，即 384 条五步残差。模式头、冻结物理读出和 LeWM 其余权重均未调整。

数据总计 1296 对。从各自真实历史回放相同物理根后，独立在两个条件下执行同一条命令，每一步后均渲染。所有块末事实及对侧编码输入匹配粗时间实际轨迹；遮蔽编码的反事实更改对当前前缀的精确不变、完整命令与旧冻结路径一致均通过。结构测试确认按顺序求证据与联合高斯等价，修改实际未来观测不改变已到达的证据，两个模式完全相同的预发路径产生精确等似然。 新数据与逐时刻配对（原工程资料，未随包同步） · [时间条件和似然实现](../../research/p1a/native_full_depth_substep.py)

## 新场景的真实多轮修订

训练固定后对 16 个新场景（55630–55645）实际执行原来的九个命令块。一次先验推进对应一个实际块。块内条件 Gaussian 只使用当前及已到达的原始步，归一化相关误差。同一原生完整终点和同一校准协方差的边缘与完整联合是主要对照。物理条件差明确的两次实际切换分别有 15/16、13/16，合计 13 个场景两次均可见物理差。严格“改判”要求上一步判断旧模式并在该块改到正确的新模式。

## 同窗口下的真实候选用途

对上述 16 条实际历史的第 8、9 次到达各取一个相同根，从头回放验证实际 RGB 和状态，保持最后物理规律不变后独立执行旧六候选各四步。32 个配对根，共 192 条分支、768 个端点，H1/H2/H4 只换原生目标代价的后验权重。无序两候选真实覆盖差大于 0.0001 才计排序，同一候选集合的实际最佳覆盖减去模型所选的实际覆盖为 regret。两次改判用的是同一窗口上的同一个原生模型，时间预测没有改写候选的原生展算。

| 同一原生候选的支持 | H1/H2/H4 与物理覆盖的排序一致率 | H1/H2/H4 覆盖率 regret |
| --- | ---: | ---: |
| 同模型末帧边缘 | 65.76% / 63.64% / 55.33% | 0.365 / 0.374 / 0.598 个百分点 |
| 块内时间联合 | 65.76% / 63.27% / 54.92% | 0.365 / 0.374 / 0.598 个百分点 |
| 同窗口省略当前块真实证据 | 62.65% / 59.27% / 51.64% | 0.365 / 0.499 / 0.598 个百分点 |
| Oracle 使用现有物理模式 | 66.15% / 64.00% / 54.51% | 0.365 / 0.374 / 0.598 个百分点 |
| 真实后继 RGB 经原目标代价 | 52.92% / 60.73% / 51.64% | 0.369 / 0.331 / 0.303 个百分点 |

时间联合较末帧只在一个 H1 根改变最佳候选，H2/H4 都没有改变。省略同一时间路径整个当前块的证据之后，排序与 H2 regret 变差，说明实际更新能被候选使用。细粒度更新的额外收益尚未建立。物理真值有差的候选对中，只有 38/257、35/275、25/244 对会因支持改变而在两种模式之间翻转原生排序。正确模式也只在 3/32、6/32、2/32 个根能换掉另一模式的原生第一候选。用真实后继 RGB 直接计算同一个原生目标代价，排序仍与物理覆盖明显不一致，说明当前任务读出自身已有偏差。其 regret 可略低，排序与最终选择继续分别报告。

这里保留两项实证，即同一原生模式的时间证据可以提高真实反证修订，实际证据在同窗上确实会改变候选排序。端到端改善还要求新信念改变的原生因素是目标实际消费的因素，并重新处理单次证据的共同误差。在旧目标代价下加大支持强度无法改变占多数的同序候选对。阶段没有重新设计 CEM、训练目标头或运行新的闭环任务。
