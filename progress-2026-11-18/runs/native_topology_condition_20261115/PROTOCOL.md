# FourRoom · 原生条件预测和实际到达

使用官方 FourRoom flat LeWM level 1、五原始步一块的官方动作归一化、真实完整 RGB 的三帧窗口和 Gate 0 同一可逆锁门布局。物理反转腿 H5 中，真模式与均匀相差 24.22 个百分点，真模式绝对成功率 63.28%。保留原协议 80% 的规划余量目标作为限制。 [物理 Gate 0](../physical_topology_gate_20261115/REPORT.md)

96 个已锁定训练布局中的 2026111600–2026111679 用于优化，2026111680–2026111695 只用于残差校准。2026111800–2026111831 共 32 个独立布局作为留出。校准、留出和 Gate 0 布局均不进入梯度。布局迁移检查发现真实末帧经过原 P0c 探针的 H4 物理位置误差为 12.27 px。根据在预测留出打开前预定的迁移检查，主物理诊断改用同样从最初 80 个布局真实 RGB 拟合后冻结的 MLP。附报原 P0c 迁移对照。世界模型训练与在线似然均使用原生 latent。 [读出诊断](readout_diagnostic_fit80/REPORT.md)

一次固定的 40 epoch AdamW 拟合，16 个同根四候选组为一个 batch，学习率 `1e-4`，weight decay `1e-4`，梯度记录未裁剪，使用第 40 个 epoch 的模型。冻结视觉编码器及其 BatchNorm 统计，保持所有网络在与部署一致的 eval 模式。训练官方动作嵌入、四块预测器及其输出投影、现有二模式 `FullDepthConditioner` 和 `FirstEffectReadout`。每次更新等权计入四候选×双模式×H1–H4 自由递推 latent MSE，以及来自同一优化布局的真实窗口一步对照 MSE。后者每 batch 用八条局部有信息和八条局部无信息的真实轨迹起点，使用同一动作在物理双模式中的真实终点编码。加入现有首块 BCE，等权覆盖自由候选 H1 和真实窗口 H1。有信息标签由同一时刻、同根同动作的物理模式差给出。H2–H4 已经分叉后的差异不充当局部门标签。匹配训练的单模式原生对照使用同一初始化、动作、目标、随机 batch 顺序和更新次数，每条候选的一份预测对双模式目标同时计分。

先复核冻结模型的原生入口数值、同根模式零偏移等价、首块强制休眠共享、致动时模式分支和压缩与密集输出误差。随后留出评估分别取真实末帧编码 \(C\)、同分支真实三帧一步 \(L\) 和完全自由递推 \(F\)，对物理 \(Y\) 验证三项误差分解，并报告 H1–H4 两模式差的投影增益、绝对误差、局部门误激活与遗漏。Oracle、均匀和错误模式在同一模型、同一根和候选中比较候选排序及真模式代价遗憾。候选库有离线真实分支，不承担闭环规划结论。

最后固定模型及读出。在 16 个独立校准布局的真实轨迹上，真模式的一步 native latent 残差逐坐标估计一份正 RMS 尺度，两个模式共享，相关性采用对角近似。留出生命周期中先由三帧真实窗和即将执行的动作预发两模式的 H1 native latent，再从唯一真实到达更新，随后把该真实编码纳入下一窗口。每次实际块都按固定 `s=.01` 先转换 prior，再按现有 `write_observation` 评分。正共享会给出完全相等的证据，预测模式对齐不依赖物理标签或事件时机。统一报告 prior、后验、两个 log likelihood、预测门、首探/重访/反转和无信息期间信念。离线 `omit` 在每个回合最后一次真反转探测移除这一块的似然，依旧执行物理动作、转换 prior 和刷新窗口。`uniform` 与真模式参照在已保存的同一发出预测上比较。留出场景及最终测量均不反馈优化和阈值。
