# 可逆门锁布局的全视野 XY 读出

官方 FourRoom 冻结编码器在新布局仍保留门口接触造成的实际位移差。旧档案 P0c 读出在 32 个留出布局的 H4 真实 RGB 上只有 0.543 的同动作跨模式增益，绝对 XY RMSE 为 12.27 px。仅用 80 个独立真实轨迹布局拟合的固定 MLP 得到 1.009 和 1.65 px。H4 真实跨模式差是 13.36 px RMS，MLP 的差向量误差为 1.41 px。

| 真实 RGB 读出 | 根 XY RMSE (px) | H1/H2/H3/H4 XY RMSE (px) | 门口同动作跨模式增益 H1/H2/H3/H4 | H4 门口跨模式差 RMSE (px) |
|---|---:|---|---|---:|
| 原 P0c MLP | 8.50 | 11.42 / 13.00 / 12.42 / 12.27 | 0.514 / 0.482 / 0.510 / 0.543 | 8.20 |
| 80 布局 MLP | 0.85 | 1.24 / 1.46 / 1.66 / 1.65 | 1.017 / 1.018 / 1.010 / 1.009 | 1.41 |

冻结编码器输出中，门口同动作跨模式的真实 latent 差范数 RMS 为 5.64、6.60、6.43、6.50。导航同动作跨模式 H1 的真实物理和 latent 差均为 0，H4 真实坐标差为 11.93 px RMS，latent 差范数为 7.29，80 布局读出增益为 1.027。同模式下，候选 0 和 1 的 H4 分支差用该读出测得门口增益 1.015、导航增益 1.003。

与原生 Oracle 实验共用同一份冻结 RGB 编码和同一批物理坐标。布局 `2026111600–2026111679` 供读出拟合，`2026111680–2026111695` 留给原生实验校准，`2026111800–2026111831` 作场景留出。训练采用固定 `Linear(192,256)→LayerNorm→GELU→Linear(256,2)`，以真实编码对应的物理坐标为监督，AdamW 学习率 `1e−3`、权重衰减 `1e−4`、100 epochs。读出使用第一版与房间底座诊断相同的超参数。先完成的 96 布局版本 H4 真实编码 RMSE 为 1.48 px、门口跨模式增益为 0.981。正式版本改用前 80 个布局以匹配原生训练划分。两版均保存，超参数未重新搜索。 [正式留出指标](summary.json) · 第一次诊断（原工程资料，未随包同步） · [原始数据协议](../DATA.md)
