# 共享 H5 双门训练集

`data_train_symmetric.npz` 供两臂逐值共用。旧拟合布局 2026111600–2026111631、每布局四个实际三帧根、每根四个动作槽及五块跨度均保持。两个门前根的全部训练目标保留原配对库；导航根从已有训练原菜单、覆盖库、配对库和两个完整训练候选库取动作。不使用验证布局或验证候选，也不重新运行 CEM。每个选中动作保存两个实际锁模式的完整未来及物理可达的真实前缀反事实。

导航根的四个槽为上门开放见证、下门开放见证、共同受阻角点、共同合法离开起始房间。门锁见证要求：开放模式在 H5 真实穿过竖墙，关闭模式全程没有穿过竖墙；两者的第一个不同原始步中，只有关闭模式的 x 坐标被截在竖墙边界；开放模式 H5 代价低于关闭模式和起点。两条门锁见证的首块控制和物理末端相异。优先选出真实物理代价在换锁时严格换序的上、下门对，再依次优先开放分支截断较少、两条开放分支的终点代价之和较小、档案顺序较早。截断指至少有一步实际坐标不同于未经碰撞的推进；报告发生过任何截断的开放分支。

共同受阻在两模式下逐原始步完全一致，停在起始房间角点且 H5 有碰撞。它和两个门锁见证各自具备不同的首块控制与真实末端，两个见证在各自开放模式的终点代价均低于角点。共同合法槽同样在两模式下逐原始步完全一致，无碰撞，离开起始房间，终点代价低于起点及共同受阻候选，且和受阻候选的首块控制及真实末端不同。失败指派由布局序号及导航根交替固定；在该模式优先取冻结模型实际误报目标房的合格共同受阻项。指派只用于报告，不屏蔽任一真实模式的训练目标。

用原环境逐步复核 1,536 条所选或固定参照的模式轨迹。两臂共用 5,120 个自由预测真编码与 H2–H5 的 3,872 个有效真实前缀源，其中 416 个源的两模式块末实际不同。仅为未编码的所选档案候选生成 1,227 张位置去重的完整 RGB 编码。有效局部源的实际模式标签与实际自由轨迹逐值一致。四个实际根、两个门前根的所有标签及旧训练种子逐值核验；动作和真编码分别为 `(32,4,4,5,5,2)` 与 `(32,4,4,2,5,192)`。
