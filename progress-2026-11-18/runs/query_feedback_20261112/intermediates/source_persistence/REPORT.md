# 第 7 级 持续状态在无新观察期间的作用

在原始冻结参数下，从空态按真实视觉—行动顺序构造全部 50 条经历的 M6。前六个动作块的实际后继分别在环境步 5、10、15、20、25、30 到达。六条记录全部使用源请求读回。随后用同一个 M6 从共同真实窗口 z4、z5、z6 预测两种固定行动程序，分别为归档第 0 个 root 的 `stop` 与 `constant_0`。每种程序给定四个动作块。

所有假想请求期间新观察数和状态写入数均为 0。M6 对象、张量和记录数保持不变，最终内容逐元素一致。运行其他请求后重发首个请求，原生 query、读出和输出逐元素一致。六个实际源请求捕获兑现量，25 次假想及重发调用共捕获 0 份新源记录。

| 固定程序 | 预测深度 | 直接作用范数中位数 | 累计作用范数中位数 | 直接作用非零的经历数 |
|---|---:|---:|---:|---:|
| stop | 1 | 0.14552 | 0.14552 | 50 / 50 |
| stop | 2 | 0.14179 | 0.26908 | 50 / 50 |
| stop | 4 | 0.13740 | 0.48332 | 50 / 50 |
| constant_0 | 1 | 0.17117 | 0.17117 | 50 / 50 |
| constant_0 | 2 | 0.15138 | 0.27725 | 50 / 50 |
| constant_0 | 4 | 0.15178 | 0.44470 | 50 / 50 |

直接作用在相同预测历史和动作上切换 M6 与空态，固定宿主参数。累计作用比较从同一个真实起点分别持续用 M6 或全程清空。中间记录还保存空态在两份历史上的差作为传播项，逐样本满足直接项与传播项之和等于累计项。第 4 步可见差异有早先预测传播的部分，也有当前这一步直接读取同一个 M6 的部分。这里的差异只衡量持续状态的作用，真实后果上的有效性由学习和后续对照研究。

状态形成执行 6 次批量原生 predictor 调用与 6 次批量兑现，每次兑现计算两组后果 K/V。25 次假想调用只读同一份状态。逐项 GPU event 和同步墙钟记录见 `summary.json`，用时包含当前仪器和冷启动。保存 `variables.npz` 和 `cases.csv`，包括各分支的预测、读出、query、直接及传播差、实际形成顺序和状态张量。 复现脚本（原工程资料，未随包同步）
