# 第 2 级：同观察下的读取

固定全部 50 个真实 z4/z5/z6 窗口，使用现有32个行动程序的首块；实际仅16个独立即时动作。M5/M6直接读取第1级已形成状态。没有真实写入、训练、自由 rollout、准确率评分或第3级原生响应测试。

| 快照 | 第6条追加作用分解最大差 | 重复首块 q/alpha/r 最大差 | 换过去 token 的 q 最大差 | 换过去 token 的原生 o 变化范数均值 |
|---|---:|---:|---:|---:|
| initial | 1.0849908e-07 | 0 | 0 | 0.000121946194 |
| trained | 1.24797225e-07 | 0 | 0 | 0.0310046013 |

原生 head 输出 o 来自先于注入注册的只读 to_out prehook，未重写 attention。合成过去替换保留当前 latent、动作和p2，只将前两组(z,a)在episode间循环偏移；这不是实际经历，不写入记忆。

位置对照另固定同一z6和constant_0，给T1/T2/T3窗口读取同M6，保存每组q/score/alpha/r及历史记录发出slot。它隔离的是首块最后query对位置的依赖，不把整个原生attention回答的差异归因于位置。

每组variables.npz保存完整向量与地址权重；cases.csv含12800条episode/candidate/head记录，position_cases.csv含1200条位置对照。所有统计只描述地址及作用分配，alpha大不能说明选择正确。第2级到此停止。

## 固定动作与位置对照的读数

对每个 episode 和 head，固定 T3 窗口，计算 16 个不同首块之间全部 120 个动作对的平均距离。位置对照固定 `constant_0` 的首块和当前观察，比较 T1、T2、T3。权重距离取含零地址的总变差距离，即对应权重之差的绝对值和除以二。向量距离采用同一快照内的欧氏范数。数值由两组 `variables.npz` 中的 `candidate_equivalence_group`、`q`、`read_M6`、`alpha_M6_including_null` 和 `position_*` 算出。

| 参数快照 | 改变项 | query 平均距离 | read 平均距离 | 权重平均总变差距离 |
|---|---|---:|---:|---:|
| 原始 | T3 动作对 | 1.49524 | 0.01117 | 0.02239 |
| 原始 | T1 与 T2 | 11.50713 | 0.38466 | 0.97808 |
| 原始 | T1 与 T3 | 12.21585 | 0.77441 | 0.90397 |
| 原始 | T2 与 T3 | 13.39215 | 0.73420 | 0.98766 |
| 训练后 | T3 动作对 | 1.52786 | 0.01095 | 0.02310 |
| 训练后 | T1 与 T2 | 11.90151 | 0.39389 | 0.97654 |
| 训练后 | T1 与 T3 | 12.68279 | 0.70488 | 0.86261 |
| 训练后 | T2 与 T3 | 14.14317 | 0.72207 | 0.98982 |

在这些固定对照中，位置带来的读取重分配明显强于改变即时动作。原始参数在 T1 将平均 80.64% 的权重放在 slot 0 发出的记录，在 T2 将 98.59% 放在 slot 1 发出的记录，在 T3 将约 99.999% 放在 slot 2 发出的四条记录。训练后对应值约为 75.99%、98.76% 和 99.9997%。这解释了形成阶段所见的第三条记录占优现象中的一项结构因素。实际转移的观察和动作同时变化，其贡献仍无法用该结果单独确定。

固定 T3 的每次查询时，加入第六条记录产生的平均读取变化范数为 0.18332（原始）和 0.17957（训练后）。新反馈项的平均范数为 0.18105 和 0.17749，旧作用重分配项为 0.01117 和 0.01016。三者是向量范数的均值，分解等式成立在向量层。已进入原生输出投影的变化量需要第三级的成对调用来测定。
