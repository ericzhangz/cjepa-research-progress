# 第 6 级 原生读回与事实状态的梯度

原始固定参数下，复用 episode 0 和 1 的第六个实际源请求、原生 M5 及固定 +u 干预。梯度诊断分别在响应重放与事实状态递推上运行。所有参数值保持固定。

标量响应 \(G(r)=b+r\) 使 \(r+y-G(r)=y-b\)。两个前向值都是 1.25。完整导数为 0，停止旧预测求导后的导数为 1。这个可解析例子区分了前向相等与梯度相等。

在 LeWM 原生路径中，用固定的全部 token attention 输出重放。独立注入量收到有限非零梯度，重放对首块 QKV 的直接边为空。用数值相同、可导的源读回量替换该注入量后，Q、K、V 的权重梯度在两条案例均非零。权重梯度还经可导的源 q、回答和 log 配分量及两端后果 K/V 传回。逐张量值和梯度保存在 `variables.npz`。
