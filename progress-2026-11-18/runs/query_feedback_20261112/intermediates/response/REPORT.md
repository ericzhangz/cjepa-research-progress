# 第 3 级：读取如何进入首个原生 block

沿用第2级的50个真实窗口、32个候选首块及同一M5/M6。两组参数各做两次原生 predictor 调用。完整数据保留全部32个候选，分布统计每个等价组只用一个代表，共50×16个案例。

| 快照 | 跨记忆 q/o 最大差 | 首块过去 token 输出最大差 | Δx_attn 与 g⊙W_OΔr 最大差 | ‖Δx_attn‖ 中位数 | ‖Δx_block‖ 中位数 | Δx_attn 与 Δx_block 夹角中位数（弧度） |
|---|---:|---:|---:|---:|---:|---:|
| initial | 0 | 0 | 1.86823308e-06 | 0.132408172 | 0.129067935 | 0.471358707 |
| trained | 0 | 0 | 2.68220901e-06 | 0.130578823 | 0.120508634 | 0.448928666 |

`variables.npz` 保留实际 hook 读到的 o、o+r、投影、adaLN gate、norm2 输入和首块输出，以及两种记忆的原生 q/r、逐案例数值差和角度。W_OΔr 只乘权重，投影偏置在相减时抵消。Δx_block−Δx_attn 是 MLP 残差支路贡献的有限变化。`cases.csv` 中未定义角度留空。

`summary.json` 记录含 hook 的原生调用用时及样本 token 数。此级只验证首块计算和有限响应，没有训练、自由 rollout、候选排序或预测准确率评分。

## 同观察下的动作差异来自哪里

由 `variables.npz` 的 `WO_delta_r` 及最后 token 的 `gate` 重建动作对的中点分解。每个真实窗口比较 16 个不同首块的 120 个动作对，每个快照共 6,000 对。对于两个动作 \(a,b\)，\(p_a=W_O\Delta r_a\)，原生残差差由 \(\bar g\odot(p_b-p_a)\) 和 \((g_b-g_a)\odot\bar p\) 相加得到。

| 参数快照 | 读取变化项平均范数 | 动作门变化项平均范数 | 合成变化平均范数 | 动作门项更大的动作对 |
|---|---:|---:|---:|---:|
| 原始 | 0.004664 | 0.140361 | 0.140570 | 6,000 / 6,000 |
| 训练后 | 0.005115 | 0.144670 | 0.144893 | 6,000 / 6,000 |

原生残差差与两项之和的最大坐标偏差分别为 \(2.83\times10^{-6}\) 和 \(2.97\times10^{-6}\)。对这组窗口与首块，加入第六条记录后，原生残差响应在动作间的差异主要来自既有动作门。首块 MLP 进一步改变作用方向，前后差向量的夹角中位数约为 27.0° 和 25.7°。这组结果定位了动作条件作用所在，后续的后果复现实验将沿同一个原生响应计算检查反馈形成量。

两次调用的含 hook 用时原样保留。原始快照第一次调用为 0.127 秒，其余调用为 0.013–0.014 秒。这些用时包含首次调用开销与采集开销，适用于复查本次执行成本。
