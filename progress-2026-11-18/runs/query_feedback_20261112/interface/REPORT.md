# Query feedback：运算阶段

本阶段只运行预先定义的运算性质和一次未来损失反传。没有优化器、参数更新、训练或预测精度比较。数据是已使用过的 P0b episode 0–3；不构成独立评价。

- 默认容量 64。空态 T1 / T3 与原生最后输出的最大差分别为 0 / 0。
- 一次真实观察使记忆从 0 条变为 1 条；后续 predict 不修改原记忆。
- 已有非零记忆下，把发出的预测作为合成兑现值，同 context 重复请求：query / readout / 最终 latent 最大差为 0 / 7.4505806e-09 / 4.76837158e-07。这是零创新边界例，不是真实预测正确的证据。
- float64 小张量实现一般延迟式 (4)、期间发生写入的零创新例、容量为 2 时的 FIFO 删除加插入分解。延迟和删除的实际作用均保留，未要求它们为零。各项差值和作用量见 metrics.json。
- 真实时点 5 / 10 / 15 依次写入三条记录；随后从 t15 仅用候选后续动作展开至 t20 / t25，期间不写入任何未来观察。真实未来仅用于末端反传目标。
- 仅首层原生 attention 的 QKV 与输出 Linear 共 393,408 个参数允许求导。未来损失到达记忆 query、value 以及原生 Q / K / V / O；其余宿主参数没有梯度。仅调用一次 backward，未调用 optimizer.step。
- 临时 hook 均已移除；宿主始终 eval，结束时重新冻结并清除梯度。

这些结果说明代码实现了所声明的读取、兑现和离线学习通路；不证明该方法能提升精度、长期稳定性或任务表现。
