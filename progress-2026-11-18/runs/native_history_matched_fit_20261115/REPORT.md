# 同一当前模式的历史差学习

2026-11-15。按[机制稿 §38](../../research/CORE_REGULATION_MECHANISM.md#38-固定当前模式的物理历史配对)，在同一个 §36 真实到达路径比较两条物理历史。每条从自己的合法前缀推进，两次实际取证前先发行原生假设预测。物理历史和当前模式索引只用于离线损失或评分。冻结对照包含旧模型、上一轮训练模型、正确/互换/输出平均，以及固定当前模式后将原生窗口合成在输入、注意力后和输出的三个口径。

学习沿相同观测与物理目标进行。在 56000–56011 各做 48 次等预算 AdamW 更新，56012–56015 场景不参加拟合。这四个场景此前已参加物理关系测量，本次只承担开发检验。三个训练组共享真实源与中心目标，仅用正确、反向或零目标约束两条历史之间的预测差。三个组依次耗时 15.87、15.21、13.03 秒，不含数据读取和验证。仅修改既有 conditioner 与原生预测头。

## 冻结预测具备可见差，动作后果仍弱

冻结模型在 16 个场景的实际第八步中，源横坐标预测沿真实历史差的有符号投影为开放/制动 0.546 / 0.718。保持动作 H4 的同一统计为 0.615 / 0.551。对整个候选相对各自保持后果的差，该统计只有 **0.044 / 0.036**。以实际评分的共同预测比分支正确配对的 H4 相对动作 MSE 低 48.57 / 17.62 环境坐标平方。

离线固定已知当前模式后，在保持同一实际模式、同一后验和窗口时，注意力后合成与完整展开的 H4 有向投影分别为 0.037 / 0.034 和 0.038 / 0.034，输入均值也相近。两条物理历史的可见差确实存在，已经发行的两个祖先预测在固定窗口上对它有可辨别的似然变化，其中与物理标签方向一致的比例为开放 93.75%、制动 100%。这排除了“当前模式内完全没有源区别”的解释，未来动作差无法由换合成位置单独恢复。

## 正确配对没有赢过定额训练对照

下表只使用未参加拟合的四个场景，保留同一尺度、读出及候选。RMSE 为预测相对各自保持动作的实际二维后果。投影为预测的历史差在真实历史差上的有符号比例，并非正确率。

| H4 路径 | 开放投影 | 制动投影 | 开放相对 XY RMSE | 制动相对 XY RMSE |
| --- | ---: | ---: | ---: | ---: |
| 冻结部分观测 | 0.052 | 0.241 | 58.59 | 68.60 |
| 正确配对训练 | 0.020 | 0.046 | 90.93 | 83.59 |
| 互换配对训练 | 0.026 | 0.032 | 63.04 | 68.23 |
| 共同目标训练 | 0.054 | 0.062 | 90.36 | 93.07 |
| 冻结模型，完整真实三帧 | 0.449 | 0.738 | 42.23 | 38.99 |
| 正确配对训练，完整真实三帧 | −0.057 | −0.048 | 108.64 | 111.69 |

正确训练的两个模式在同发行窗口对可见证据的似然方向均为 100%。互换组为 12.5% / 12.5%。正确组因此保有可见源的解释区分，未来实际效应却未相应改善。对正确组单独省略最后一次祖先证据，开放 H4 历史差投影从 0.0204 变成 0.0211，制动从 0.0457 变成 0.0450。任何保留下来的增量都远小于真实差。该结果是对 48 次定额路径的裁定，不能排除宿主经过不同受约束学习可以获得上述能力。

完整观测只作为离线参照。用同一初态及相同命令物理重放 64 条实际历史，并核对最终物理状态和全部已存标量读出完全匹配。完整输入明显改善冻结预测的保持差与动作差，但并没有消除自由推演问题。16 个场景的完整输入 H1 相对动作投影为 **1.202 / 0.829**，H4 降至 **0.270 / 0.149**，两模式均劣于消去差的公用输出。正确配对学习对完整输入也造成了退化。直接恢复更多完整状态只能解释一部分误差，尚需厘清预测本身怎样推进已形成的动作响应。

**下一项可判别的关系。** 保留 §36 合法区分历史的写入路径，以冻结完整根为原生参照，把同一组后果的原生推演拆为逐步实际根下的一步后果和在模型预测根下的自由后果。对相同上一模式、同一动作和跨度，绝对参考与动作差前者同样弱时，再决定本地计算的针对性修订；一步预测给出方向而自由推演中失真时，学习对象应是原生状态中的跨步响应关系，不能用另一个源似然或单纯增加归档规模解决。本阶段未建立可归因的独立长程价值。

57 项回归通过。场景原始输出验证了正确与互换配对的 MSE 差等于有向内积。所有数据均来自同一物理模型下已执行的分支。
