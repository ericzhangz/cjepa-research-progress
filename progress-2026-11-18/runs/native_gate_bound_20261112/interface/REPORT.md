# 原生最后一层 gate 的第一阶段对照

用原始冻结 FourRoom LeWM 和评估档前 8 根，每根 4 个已确定的候选命令块，共 32 个请求。T=1、T=3 各执行一次。固定两个隐藏通道定义坐标，每根用四个原生坐标的最小和最大值中点设人工边界。实验不读取候选真实未来。 [运行前协议](../../../research/methodology/NATIVE_GATE_RESPONSE_BOUND_20261112.md#已固定的第一项宿主中间量试验)

| 量 | T=1 | T=3 |
|---|---:|---:|
| 触发数 | 19/32 | 19/32 |
| 触发且分母绝对值小于 0.0001 | 0 | 0 |
| 原生隐藏状态和 latent 重构最大差 | 0 | 0 |
| 实际 gate 修改与解析结果的隐藏状态最大差 | 9.54e−7 | 4.77e−7 |
| 实际 gate 修改与解析结果的预测 latent 最大差 | 4.77e−7 | 2.38e−7 |
| 干预后坐标相对所设边界的最大差 | 4.77e−7 | 2.38e−7 |
| 触发时 gate 系数绝对变化中位数 | 2.79 | 2.60 |
| 触发时 gate 系数绝对变化最大值 | 66.01 | 39.90 |

未触发的预测与原生结果逐元素一致。T=3 的过去两个 token 逐元素一致。最大改变量发生在 T=1 的 717000、`constant_0`，当次分母约 −0.00635。两个被修改通道在原生全部请求中的最大绝对值约 1.90。该请求的 latent 改变范数为 7.02。人工边界也会选中 `stop`。此处固定坐标仅为实现对照，不能据此赋予它物理含义。

接口对照成立。物理坐标的稳定性要求仍然开放：分母可以非零但很小，使解析上准确的截断需要很大的 gate 改变量。后续需要研究真实观测是否能由此原生曲线解释、真实效应是否共享边界以及未受影响的命令后果是否保留。未训练模型，未运行自由轨迹或闭环任务。
