# 全层条件预测在全视图可逆 PushT 上的阶段结果

物理环境不渲染隐藏制动。相同状态和画面下，只有执行实际推动才会揭示开放与制动的效果。复用官方 LeWM 的六个原生 AdaLN 块，每块接受同一个二元解释经共享编码和分块线性映射后的偏移。固定预算离线拟合 320 次，20 个物理场景拟合、4 个拟合侧场景标定真实观测残差。部署只维护支持和真实公开三帧，不改变参数。源似然比较同一推演分支的物体位置读出与合法到达帧在同一读出中的位置。条件转移使用固定每动作块 0.05 的对称切换率。先前预测在实际到达后才评分。首帧重复、用零动作填过去槽仅是初始化，部分环境之后仍有自然沉降。

## 独立候选与真实事件

12 个独立留出场景，两个条件与六个固定候选从配对状态独立执行。H1–H4 对应 5、10、15、20 次物理控制。真实 (x,y) 只用于离线拟合或评价。表中是完整绝对物体位置端点 RMSE，单位为原始 PushT 环境坐标。

| 条件使用方式 | H1 | H2 | H3 | H4 |
| --- | ---: | ---: | ---: | ---: |
| 官方冻结 | 11.35 | 18.21 | 29.01 | 40.27 |
| 全深度、均匀支持 | 7.63 | 13.06 | 21.06 | 29.40 |
| 全深度、正确条件诊断 | 6.28 | 9.99 | 16.44 | 23.99 |

条件真值诊断的两种后果差同向覆盖为 0.649、0.740、0.738、0.817。预测条件差 RMSE 为 4.33、7.23、14.19、22.16，真实差 RMS 为 9.69、18.33、29.90、40.59。两臂同为全深度，诊断中真条件比均匀支持更准，说明监督除了提高共同拟合，也学出了有用差异。正确模式属于离线诊断。每段首个实际后继评分下，总平均模式 NLL 为 0.512 nats，均匀参照为 0.693。正推和两条斜推的首块条件分类率为 0.917、0.875、0.833，保持、后退和以退离开始的返回序列首块均为 0.5，符合成对物理中性标签。保持和退离的预测似然差仍为小非零量。

## 同一任务内的多轮真实修订

连续物理轨迹在相同任务中依次探测、退离、三个休眠块、返回、接触、切到开放、再切回制动。切换瞬间不改变画面。制动支持从 0.5 经第一次探测到 0.908，三个休眠块后为 0.761，返回后为 0.975。三个休眠块的两个模式读出相差 0.215、0.319、0.180 环境单位。返回读出差增至 6.91。保持了证据并复现相对静默，但并非结构性零差。第一次切换后制动支持下降到 0.168，第二次实际制动后只回到 0.394。

两次反转都用同一根实际执行相反条件，分解源对数似然为预测与真实**配对中点偏差**和**配对后果差**。这一步只离线使用反事实 RGB。第一次实际开放的对数证据 −2.790 中，配对物理差贡献 −1.115，中点偏差贡献 −1.675；前一项单独不足以克服当时 +1.193 的先验。第二次真实制动的两项为 +1.259 与 −0.314，合计 +0.945，同样未克服 −1.376 的先验。切换前的再次接触甚至出现中点偏差 −1.84、真实条件差贡献 +0.66 的逆向证据。当前需要修订的是源预测在动作情境下的共同偏差与反转强度，不能只提高似然温度、提高切换率或看最大的 posterior。

## 固定 CEM 候选预算的真实闭环小试

4 个另外的物理场景，7 次真实闭环重规划，同一 H2、16×3 候选与 4 个精英。各 LeWM 臂使用官方末端 latent 平方目标代价，条件模型按每个解释的终点代价取期望。物理状态不进入 LeWM 评分。达到原生 PushT 大于 0.95 覆盖率才记为成功。

| 模型 | 平均最终覆盖率 | 成功 |
| --- | ---: | ---: |
| 官方冻结 LeWM | 78.15% | 0/4 |
| 全深度、均匀支持 | 86.04% | 0/4 |
| 全深度、仅最近一次证据 | 85.86% | 0/4 |
| 全深度、持续支持 | 88.47% | 0/4 |
| 全深度、普通 GRU 估计支持 | 87.29% | 1/4 |
| 全深度、真实条件 Oracle | 81.89% | 0/4 |
| 原生 AdaLN 偏置在线梯度适配 | 75.72% | 0/4 |
| 作者发布的 LeWM AdaJEPA 端口 | 84.90% | 1/4 |
| 作者发布的 LeWM OpTTA | 84.73% | 0/4 |

持续支持较均匀支持平均改善 2.43 个百分点，较冻结模型改善 10.31 点。已执行场景中部分实际切换后不再接触，两次真实反转用上述受控连续序列明确评价。GRU 使用同一信号与预测器，训练来自恒定模式样本。它在两次反转的受控序列未修订，却在闭环里完成一个场景。作者适配器以相同 CEM 预算、真实反馈及原论文端口的作用参数运行，AdaJEPA 也完成一个场景。真实条件 Oracle 小试低于持续支持。这说明目标、候选分布与模型误差会影响闭环收益，当前四场景不支持成功率优势。另有精确物理 CEM 知道当前真条件为 1/4，假定始终开放为 2/4，说明这个小试预算下的优化方差仍很大。 [作者端口的配置与闭环结果](../native_full_depth_mpc_optta_20261115/REPORT.md)

精确共享另外实测。训练的旧档案条件在第 1 块即分叉，未减少主干请求。在新物理轨迹里预测差虽小，数值近似也不等于可复用的确定性等式。当前持续支持 CEM 使用密集推演。正式独立长程成功率、稳定的两次反转修订、按需计算实测收益都尚未建立。
