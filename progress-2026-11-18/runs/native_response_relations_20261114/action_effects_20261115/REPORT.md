# §20 实际写入对绝对保持与动作作用的首个离线结果

2026-11-15。完成预先规定的零更新和两组各 128 次优化。**这次拟合没有学到有用的持续调节。** 在历史开发数据上，两次真实观察写入对动作差的作用约 \(10^{-6}\) 环境单位 RMS。关系版的绝对位置和动作差误差与同预算原生微调近乎相同。两种拟合较原生冻结模型均降低聚合绝对保持误差，却使所有 16 个开发场景的相对动作误差上升。结论限于当前参数化、档案和固定训练方案。

## 协议

- 使用原有 PushT 物理记录及固定官方编码。各取 16 个拟合、16 个历史开发场景，每场景四世界、两种已执行历史。步 125 每组 128 个有效根。每根的四候选从当时物理状态独立执行。H1/H2 为 5/10 环境步，H2 重复该候选的首块命令。查询根只读当时公开的窗口和合法动作。
- 原来已公开的 105/110 全帧提供真实似然。校准使用 256 条拟合转移相对原始冻结 LeWM 的逐维残差 RMS，得到共用固定对角高斯。均匀先验、恒等状态转移。未评分帧仍照常进入宿主窗口。预测候选每个解释独立递推。模拟器 XY 和真实未来仅提供离线监督、分组与评分。
- 关系版沿用 §18 的两关系共同求解和四解释。两组都由官方 LeWM 初始化，公共训练参数为末条件块与预测头。其余冻结。关系版额外训练 4,104 个关系参数。保持 eval BN 和 dropout，用同样的 128 个每批一场景的样本序列、AdamW 学习率 \(10^{-4}\)、梯度范数截断 1、种子 1714。取末步权重。两组均最小化 FULL 观察 NLL（每维）加步 125 的逐解释绝对 latent 和物体坐标端点能量，关系版在同一解释内聚合 H1/H2 全部候选才混合解释。目标方差和离线 XY 读出均来自拟合记录。
- 同一关系权重、窗口和候选下，对比两次写入、都省略、仅 105、仅 110。原生冻结与微调另作对照。零作用定义为实际候选的物体 XY 恰等于同根同跨度保持候选。H1/H2 开发组分别有 384 个有效非保持端点，其中零作用 254/236，有作用 130/148。场景配对和 Bootstrap 使用整场景为单位。

## 数值入口和零更新

两个真实源的模式 0 与原生输出通过数值对照。H1/H2 候选上的零强度解释相对直接原生递推最大 latent 差 \(4.77\times10^{-7}\)。H2 目标经 105/110 两份实际似然回到关系方向的梯度范数分别为 \(2.85\times10^{-6}\)、\(7.03\times10^{-7}\)。全部 41 项此前测试通过。冻结状态下比较双方写入和省略，H1/H2 动作差预测的偏移 RMS 为 \(5.02\times10^{-6}/8.08\times10^{-6}\) 环境单位。真实动作差 RMS 为 14.13/26.63。写入和省略差与同一逐解释响应表的支持投影一致。跨作用端点的零作用判定与原始物理档案对齐。

## 固定拟合的结果

以下为 16 个历史开发场景的聚合欧氏 RMSE，单位为环境坐标。每格 H1 / H2。

| 物理量 | 原生冻结 | 原生微调 | 关系版，两次真实写入 |
| --- | ---: | ---: | ---: |
| 绝对保持 | 66.491 / 65.923 | 62.689 / 63.101 | 62.689 / 63.101 |
| 所有候选绝对位置 | 67.054 / 69.093 | 62.685 / 66.189 | 62.685 / 66.190 |
| 非保持候选相对保持的动作差 | 14.200 / 26.485 | 19.337 / 29.506 | 19.337 / 29.506 |
| 真实效果非零的动作差 | 24.333 / 42.542 | 28.999 / 45.013 | 28.999 / 45.012 |
| 真实效果为零时的预测动作差 | 1.341 / 2.528 | 11.613 / 12.079 | 11.614 / 12.082 |

原生微调的保持误差下降只发生于 8/16 个场景，两跨度的场景重采样区间均跨零。其相对动作误差在每个开发场景都上升，场景平均 RMSE 增量 H1 为 5.179，95% 场景区间 [4.795, 5.669]。H2 为 3.048，[2.236, 4.102]。关系版有几项相对原生微调的差位于 \(10^{-4}\) 至 \(10^{-3}\) 环境单位，远小于底模误差，且同检查点的写入对照解释不了这个差异。

关系版拟合后，两次写入相对同检查点全省略，H1/H2 的绝对保持预测移动 \(1.03\times10^{-6}/3.20\times10^{-7}\) RMS，动作差移动 \(1.02\times10^{-6}/9.98\times10^{-7}\) RMS。只在真实零作用项看，动作差移动 \(7.77\times10^{-7}/5.99\times10^{-7}\) RMS。两次写入相对只写 110，全部动作差移动 \(3.80\times10^{-7}/2.53\times10^{-7}\) RMS。因此零作用项上约 12 个单位的错误作用主要来自公共动作预测，两次观察几乎没有对此产生修订。

在同一公开观测、同一计分口径下，历史开发每维 NLL 如下。

| 到达 | 原生冻结 | 原生微调 | 关系版 | 训练集按通道拟合的无条件对角高斯 |
| --- | ---: | ---: | ---: | ---: |
| 105，全帧 | 1.78013 | 1.44354 | 1.44354 | 1.37084 |
| 110，全帧 | 0.81042 | 0.80320 | 0.80320 | 1.36992 |

步 105 的公共观测预测有所改善，仍劣于对应无条件参照。步 110 的公共预测优于对应参照。两点上，观察 NLL 的改善均可由原生微调解释，未显示模型借观察区别了有不同物理后果的解释。

## 从两条链定位失败

第一条是解释的物理后果。开发组每个非保持端点的最大模式间二维动作差，按端点聚合的 RMS 从初始化的 0.00576/0.00964 降到 0.00239/0.00169。真值的两维坐标都落在四模式各自坐标范围内的端点，拟合前后均为 0/384（各跨度）。这是精确真值可达的必要条件，未设预测容差，单独通过也不足以说明同一份支持可同时拟合所有候选。真实差与模式直径相差多个数量级，因此换一组支持无法在当前检查点得到有量级的真实预测修订。载荷记录在初始化 H1 有 24 个非原生关系槽由共同求解加载，拟合后各查询和两次源到达均未发现由原始不加载转为正对偶载荷。关系参数继续更新，但其宿主输出在本次学习中趋近共同预测。

第二条是实际证据的选择。写入相对省略的平均总变差由初始化 0.000574 降至 0.000357。拟合后 105/110 最大跨解释对数似然差为 0.00253/0.01428，源概率仍接近共同支持。对任一候选，证据造成动作差修订的范数满足
\[
\left\|\sum_s(p_s^+-p_s^-)D_s\right\|
\leq \operatorname{TV}(p^+,p^-)\max_{s,j}\|D_s-D_j\|.
\]
两边量都很小。根据逐端点记录，即使看这条上界在所有根中的最大值，H1/H2 也只有 \(8.66\times10^{-6}/1.08\times10^{-5}\)。这解释了为什么仅改观测尺度或重置率不足以让当前拟合输出具有实用修订量。

**我的解释。** 现有损失容许同一公共末块与预测头拟合绝对公共趋势，所有解释几乎重合时，整组未来损失对早期支持的梯度 \(p-r\) 也接近零。结果与这条学习捷径相符，仍不能单独确定由初始化、监督覆盖、当前接点还是优化导致。此次证据支持的具体裁定是：在当前训练契约下，算法没有形成足够不同的动作后果去使用历史。零作用处出现的大误差来自公共预测，并非旧证据写入过强。这个结论也只涉及重复动作的 H1/H2 和已经反复使用的历史开发组。
