## 全池错误的固定权重追踪

对四个根和两种物理条件，固定模型、真实帧、过去动作与支持，重放真实写入选中的计划以及两条物理最佳计划，共 24 条。用 C 表示真实轨迹编码再读出，L 表示每步读真实窗口的一步条件预测，F 表示自身窗口自由递推。使用同一官方代价。四个高遗憾首选都是名义绕行的变化候选，在真实物理中一道门也没过。

| 四条错误首选 | 官方 last-2 代价 |
| --- | ---: |
| 真实轨迹编码 C | 781–786 |
| 真实窗口一步 L | 781–807 |
| 自由递推 F，实际支持混合 | 121–160 |
| 对应真实最佳计划，自由递推 F | 199–213 |

以从西北出发、上门锁定的候选 115 为例，终点 C 为 (86.0, 104.0)，L 为 (84.3, 105.1)，F 为 (144.8, 146.1)。L 与 C 的 H12 距离约 2 px，F 与 L 约 73 px。四条错误首选的 F−L 在 H5 已到 19.8–31.2 px，H12 到 69.9–74.4 px。等窗的实际一步仍预测受阻，自由续推把受阻途径打成虚假低价。

Oracle 每根覆盖 8 个方案，无标签实验只有 2 个名义方案。覆盖差是一个明确的后续对照因素。两实验也同时改变了分支监督和拟合组，因此本轮不能单独归因。候选覆盖的后续对照应固定真实履历和无标签目标。跨方位的解释身份需要另用贯通相关方位、保持物理条件的实际履历约束。第一层没有建立全池决策收益，第二层随机瞬移未启动。 [24 条计划逐步溯源](fixed_regret_trace.json)
