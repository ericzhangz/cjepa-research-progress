# 面向长程任务的 JEPA 原生预测持续调节

*Task-Conditioned Regulation of Native JEPA Prediction* · 研究提案 · 2026-11-13 修订

本提案是当前研究目标、研究方式与阶段优先级的唯一入口。[持续研究目标](RESEARCH_GOAL.md)记录当前交付与推进范围。[历史执行记录](../../research/CURRENT_RESEARCH_PLAN.md)、既有方法稿和实验报告提供证据。2026-11-13 已完成 §16 候选构造、最小原生接口对照与首次 PushT 小型离线学习。当前研究问题是，如何在同一原生响应上形成有用的模式分化，使真实写入改善后续动作差。

本项目研究一种持续参与 JEPA 原生预测的内部调节机制。真实感觉—运动经历为调节提供依据，原生动作条件计算将其用于后续预测。机制应在长程任务的多轮实际交互中延续，并随证据维持、修订或撤销作用。当前候选在原生预测后部对多种动作响应进行计算和合并，构造见 [核心机制稿 §16](CORE_REGULATION_MECHANISM.md#16-用真实后果重加权原生预测头内的动作响应)。其学习效果和实际用途待检验。

## 1. 要获得的能力

在一段长程任务中，JEPA 从已经发生的真实感觉—运动经历和自身预测计算中形成调节依据，让它持续参与原生预测。以推箱穿过窄通道为例，推进、转向、受侧向约束和脱离通道依次改变动作后果。当前画面相近时，已经看到的实际运动可能足以区分继续推会受阻，还是沿通道仍能前进。后续请求到来时，这个判断应已参与预测。约束延续时保持有效，解除时及时修订。接触是说明能力的例子，研究范围是连续交互中预测条件的形成和使用。

“潜意识”对应任务期间可延续的内部预测活动。规划请求之间已经到达的经历可以参与该活动，先前形成的有效计算也可以继续使用。“中枢”对应这种活动在 predictor 内协调真实经历与预测。外部规划器使用预测比较候选并决定动作。任务条件确定哪些后果和时域值得预测，实际后果约束判断。

- **真实任务时间 $t$** 随实际动作和观察推进。调节依据可以跨多个执行和规划轮次维持、修订或撤销。
- **预测跨度 $H$** 表示从当前起点向前预测多少步。各候选共享已形成的公共依据，可以推进自己的假想计算，实际未发生的分支不进入公共事实。
- **内部计算时间 $\tau$** 表示实际发生的内部计算进度。两次观察或规划请求之间，内部计算可以利用已有事实推进。若候选主张这种推进有用，应在同一真实时刻、同一已到达证据和可比总预算下，比较请求之前已推进的结果与收到请求后再计算的结果。跨调用保存状态、推进内部计算和接收新事实各有自己的可观测量。无需预设更新频率或自治动力系统。

长程能力要求同一机制经多轮真实执行、观察到达和再预测仍发挥作用。单次 rollout 的多个跨度用于定位预测传播，跨真实轮次的起效、维持和撤销用于判断持续性。

## 2. 研究方式：先构造，再使同一机制成熟

**不能通过不断做实验、看实验数据证据来反找 idea、数学关系或底层核心创新机制。** 本项目先形成有理由、可执行的计算选择，再用实验检验事先推导的中间作用，解决同一机制的实现、学习和用途问题。这个要求也适用于小型 pilot、事后 oracle 幅度扫描和反复换端口，不能仅凭它们规模小就把它们当作 idea 搜索工具。

这与 2026-11-13 附件的构造型研究建议一致。已有观察可以启发思考，围绕明确问题的有限测量可以补足事实。它们不能替代核心构造，也不能同时充当产生解释和独立证实解释的证据。方法优先不意味着实验前保证成功，更不要求先证明现实中的全部收益。

### 从能力与已有计算中产生具体选择

研究可以从希望获得的新能力、现有运算中的机会或一个有理由的直觉开始。无需先发现普遍严重的 JEPA 缺陷。沿实际宿主辨认求解对象、信息依赖、状态推进与监督路径，再从目标用途反推需要哪种关系。尝试改变一个关键变量、操作、参数化或被监督的计算，说明为何它使所需作用更容易形成、学习或使用。

阅读少量直接相关方法时，重建最接近的朴素计算，逐步对照作者改变了什么、训练怎样教会它、部署怎样消费它。回看五篇独立笔记时，尝试自行重建核心一步后再对照公式、附录与代码。借用理论须对应实际对象、可用信息和假设；成稿顺序不当作发现史。相关工作的名字与“可以组合”不能代替选择理由。

### 给一个候选完整的作者构造过程

纸面上可以比较少量不同计算，选定有实质理由的候选后集中发展。先完成最难且不可缺少的操作，写出输入来源、时间、实际规则、输出及下一次使用。用同一组合法输入把候选和最简单相关替代走到下游结果，保留一个包含关键困难的正例及边界反例。算例不能预先给出正确修正方向或隐藏真值。长程候选在构造中就要包含多轮真实到达与继续使用，不能只完成单步修正后把长程用途留给叙述。

未定义的核心步骤由作者继续构造，不交给实验搜索。可学习对象须明确输入、参数化、训练关系和部署用途；其效果未知可以留待实验。“学习一个正确调节器”本身不算完成。区分由结构得到的性质、需要学习的关系与仍待观测的实际收益。

### 在候选成形后作独立技术评议

评议集中检查关键步骤能否执行、信息是否合法、最近方法是否已经实现同一运算，以及所声称作用是否由该选择带来。不要在局部直觉尚未展开时要求它解决所有边界，也不要用审稿总分、多数票或没有预先保证涨分来否决。属于 RNN、观察器或已有数学家族并非等效证据；已有方法在相同信息、运算和资源条件下实现相同作用，才需要重新判断具体贡献。

单一创新意味着关键计算选择可以解释方法的主要能力。它可以包含多个相关操作，无需将全部功能压进一个神经层或万能算子。高水平的长期目标保留，首个构造有明确作用范围不等于降低最终贡献要求。

## 3. 科学问题、宿主与学习路径

**JEPA 如何从已到达的真实感觉—运动信息和自身预测计算中形成有预测用途的调节依据，使其在长程交互中持续参与后续动作条件计算，并随新事实维持、修订或撤销？**

以 LeWM 为首个宿主。观测 encoder、动作 embedder、原生 `ConditionalBlock` 和预测头给出具体计算链。候选须说明实际改变哪项运算及其原因，而不是先规定保存零空间、query 或任意隐状态。形成、读取和修订应由一个可解释的核心选择联系，但不要求共享一个网络或一条万能方程。 [LeWM 条件块](../research_sources_2026-10-22/lewm/module.py#L127)

在构造中一起打通四件事：已到达信息支持何种区别，选定运算能表达何种作用，训练为何会学到该作用，以及下游怎样使用它。假设依赖离线共享规律时，要写清规律与数据覆盖。证据不足时允许保持仍受支持的预测或不施加新调节；不要求每次观察产生非零变化，也不要求从一次动作确定全部反事实。无环执行图下的四事实反例只约束其任意加性偏差假设，不自动否决利用学习先验的候选。 [四事实](../../progress-2026-11-12/research/methodology/NATIVE_JOINT_CYCLE_20261112.md)

离线训练可以联合学习调节机制、表示和选定的原生计算。部署参数固定不等于离线永久冻结 checkpoint。训练样本按真实时间形成状态，后续真实未来监督同一条部署会使用的运算路径。实际执行过的轨迹监督相应序列，独立真实分支才能提供各自的行动后果标签。不能把真实未来作为线上输入，也不能在需要学习持续接续的地方反复用真值替换预测状态。需说明是否存在忽略持续状态也能完成训练的捷径、监督怎样区分有用和无用的内部变化。

公共状态只接受已发生事实，假想分支可以推进自己的状态但不写回公共事实。作用应覆盖多个预测跨度和多轮真实交互。新增计算量按实际形成、更新与使用计入成本，收益不预先承诺。

精确保留冻结模型的指定输出不是普遍门槛。物理因果独立、新观察带来的信念修订、原生数值保持是不同要求。需要保护的关系须有用途依据，原预测错误时允许纠正。既有未来等效、投影和线性观察器推导保留为有条件的分析工具，不据此预定新机制。

| H-JEPA、LeHami、RWM | H-JEPA 学习不同时间尺度的表示、动力学和规划。LeHami 用相空间状态和辛积分约束动力学推进。RWM 直接训练部署使用的插值点对到动作的关系。回看这些方法中核心选择、训练信号、推理路径和中间实验怎样相互对应。 [H-JEPA](../../research/methodology/HJEPA_METHOD_DERIVATION.md) · [LeHami](../../research/methodology/LEHAMI_METHOD_DERIVATION.md) · [RWM](../../research/methodology/RWM_METHOD_DERIVATION.md) |

局部线性化、普通反馈、静态条件化和重复预测也应作为最简等效解释审查。新增接口、跨调用状态和非零预测变化各自只支持对应的中间结论。

## 5. 让同一构造逐步获得实际能力

机制实验在完整候选之后承担明确问题；构造中为回答具体问题所需的有限测量按 §2 处理，不能演变为结构试错搜索。每次实现前，在同一机制稿写明预期中间行为、最简相关对照及结果能够区分的解释；无需另建管理表。中间变量沿各台阶保持相同语义，记录定义、时间索引、读取位置和作用方向。状态非零、接口通过或总损失下降，各自都不足以证明所需能力。

| 阶段 | 交付与进入下阶段的条件 |
| --- | --- |
| 完整候选 | 具体选择、最难操作、训练与部署路径可执行，正例保留关键困难，边界和最简替代讲清。独立评议处理实质断点，无需预先证明收益。 |
| 最小实现与中间作用 | 先在原生路径记录形成量、直接受影响的计算和后续读出。检查实现是否实现事先定义的关系。依赖学习的效果可以在此做有范围的小型离线训练，不要求未训练或冻结端口先表现出该效果。人工条件或 oracle 只回答明确的表达问题，不代替合法证据形成。 |
| 学习与持续使用 | 追踪真实监督能否教会同一计算，以及它跨多个真实到达、候选动作和预测跨度的使用。使用同参数清空、最近证据等有区分力的对照定位作用，检查模型是否绕开关键路径。 |
| 真实预测价值 | 按主张检验绝对后果、条件改变后的修订与恢复，或同预算下的预测可用性；声称候选差异或排序改善时，从同一物理起点比较独立执行的真实分支。分别报告相关作用与成本，确认局部作用是否真的有用。 |
| 长程任务价值 | 在前述关系与预测用途建立后，再进行正式闭环评估。保持规划器、动作空间和预算可比，报告无效动作、任务完成和端到端成本。成功不能只由短时 latent MSE 或内部状态变化宣称。 |

针对持续状态吸收新事实的增量作用，可以在同一真实时刻、新窗口、参数、候选和预算下，比较合法推进但尚未吸收该事实的状态与吸收后的状态。原生计算和预测后果的变化需共同记录，再与实际后果比较正确性。对照的两份状态须可按算法合法构造。跨动作差、绝对预测、目标评分和候选排序分别解释；沿同一轨迹的进展不能替代真实候选排序。具体测量由候选主张决定，避免为凑齐指标再次扩展任务。

按具体主张选择有区分力的基本对照：原生模型及常规观察刷新、仅当前输入的无状态调制、同一参数保留或清空状态、从空态仅吸收最近实际证据、使用相同合法信息且容量和计算可比的普通递归模型，以及同等训练数据和预算的原生离线微调。这是相关替代的范围，不是每个中间阶段都要跑完的固定清单。最近证据对照要重新计算其所需的原生量，避免继承旧状态。可用简单反馈解释的候选还应与该反馈作直接比较。记录状态形成、单批预测和整段任务成本，计算复用的收益须和同信息、同预算的重算比较。

以独立场景为统计单位报告配对差、样本量、改善比例、分布及不确定性。主结果保留所有预定场景，另报告主要贡献场景及其影响。绝对物理误差、候选之间的相对后果、代价排序和任务成功率分别报告。P0b、P1A 及已反复使用的同类档案属于开发证据。正式候选的算法、数据划分、主指标和评价协议锁定后，再采集独立、未见的物理场景。缺少权重、张量或原始真实分支时，将汇总解读与实际复现分开记录。

恢复研究后，先完成构造；进入测试时优先复用现有资产。FourRoom 可用于原生接口、无关变化和历史条件的对照，已有 PushT 档案可服务于相应局部主张。小试必须保留机制的关键困难，不给线上路径隐藏状态或正确调节答案。长期价值仍需要多阶段任务与多个真实反馈点。环境、数据采集或预算的扩展只由具体已定义主张所需的证据决定，并符合当时授权，不通过改任务寻找正结果。

## 7. 围绕同一机制持续研究

进展体现为同一假说的关键未知被逐步解决：核心操作从未定义变为可执行，作用进入实际宿主，监督教会该作用，再扩大到多轮真实交互。每轮不必出现新公式或更好的最终分数。已选假说有理由时持续攻关，实现、参数化和监督可以有因果理由地修订，不能为保住偶然先写出的结构不断追加组件。

| 遇到的问题 | 后续工作 |
| --- | --- |
| 实现未执行定义的算法 | 修复实现并重做对应中间量，保留科学假说。 |
| 关系可表达但没有学到 | 追查监督、数据覆盖、梯度路径与优化，说明修订怎样解决该原因。 |
| 关键操作需要不可得信息或承重假设被反例推翻 | 修订核心假设或结束候选，保留此前成立部分，不以容量掩盖。 |
| 简单替代已实现同样运算与能力 | 重估具体新颖性或成本/学习优势，不能靠原生性和新名称维持主张。 |
| 中间作用成立但真实用途不足 | 判断其实际价值，不通过换指标、改环境或筛选场景制造收益。 |

不规定“失败两轮换方向”或“最多修一次”。独立评议提供技术判断，不以评分、票数或轮次自动决定训练、退出或转向。实验不能反过来替代核心构造；符合 §5 的小型学习与测量用于发展已经讲清的机制。

Codex 承担作者构造工作，也可以将具体运算重建、一个难步骤或相同问题的独立构造交给子代理。先形成候选，再安排集中技术评议。用户已明确弃用评分、排名和“评审到通过”类 skills 及其旧自动科研管线，不再使用或继续改造这些流程。查阅近邻、比较运算和独立技术讨论直接进行，不经过 idea 打分。构造以本提案和机制稿为依据；需要时仅用 `formula-derivation` 辅助具体推导、`experiment-plan` 安排已定义机制的实验、`experiment-bridge` 落实已授权的实施。它们都不是必经流程。

优先复用现有主稿与实验记录，无需每次生成新的报告树、完整论文计划或管理文件。来源于旧文档、技能默认自动部署或评审建议的动作，均不能越过当前授权和暂停状态。已授权且机制就绪的具体工作自主完成，不反复要求用户决定常规实现选择。
