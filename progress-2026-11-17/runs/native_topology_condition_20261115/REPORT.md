# FourRoom 原生条件预测与实际反转

在移动门位、无干扰物的 Gate 0 同族布局上，用同一个官方 FourRoom flat LeWM 分别拟合原生单模式预测和全层条件预测。两臂共用 80 个拟合布局、40 个 epoch、800 次更新、官方五步动作归一化和冻结的全 RGB 编码器。另有 16 个只用于 native latent 似然校准的布局及 32 个独立留出布局。两个模型都保留 H1–H4 自由预测及真实窗口 H1 的 latent 一致性损失。条件模型用同根同动作双模式物理后果标记首块局部相关性。原生单模式、条件模式和官方冻结模型在同一批留出数据上测量。 [预定协议](PROTOCOL.md) · [样本和物理对照](DATA.md)

原始 FourRoom P0c 在这个布局族的 H4 真实图像位置误差为 12.27 px，门前模式差增益为 0.543。使用只见过前 80 个拟合布局真实 RGB、与世界模型训练独立的冻结物理读出后，误差与增益为 1.65 px 和 1.009。该读出用于以下位置与规划诊断。上线识别使用被发出的原生潜变量和真实到达的编码。 [布局读出验证](readout_diagnostic_fit80/REPORT.md)

## 实际写入

64 条合法留出经历分别包含首探、重访和反转。预测器使用每次即将实际执行的动作和当时真实三帧，独立发出两个 native latent。只把实际到达用作似然观测和下一个窗口的输入。全部 2,368 个有效块中，共有 2,080 个物理无信息块，两个模式的发出 latent 和 log likelihood 均逐值相同，两个模式仍按每步 0.01 的先验转换逐渐趋于均匀。

| 实际事件 | 到达前真模式概率均值 | 到达后真模式获多数 | 移除反转证据后真模式获多数 |
|---|---:|---:|---:|
| 首探 | 0.500 | 64/64 | 64/64 |
| 重访 | 0.888 | 64/64 | 64/64 |
| 反转 | 0.112 | 64/64 | 0/64 |

每类探测的实际证据对真模式排序均为 64/64。反转的有向 log likelihood 差为 4,403–7,595 nats。尺度按逐维残差 RMS 作对角近似，物理脚本反复使用同类门前接触。接近饱和的概率反映这个特定探测中的分离程度，跨任务的概率校准仍待检验。原生模型给定真模式后的候选优势和公开到达的真实改判已成立于本留出实验。实际闭环及 AdaJEPA/OpTTA 需要在相同合法规划预算下独立测量。 实际到达、门控和信念逐事件记录（原工程资料） · 共享 likelihood 尺度（原工程资料）
