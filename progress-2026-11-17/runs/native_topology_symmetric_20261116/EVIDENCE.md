# 固定 XY 写入：削弱尖峰，未消除虚假证据

同一已发预测和真实到达下，二维似然大幅削弱了虚假的似然尖峰。原模型最坏归档中性事件由 −6110.63 变为 +6.91 nat，避免了该例的错误翻转，却仍在两模式物理后果完全相同的情况下抬高其中一个模式的支持。新训练的两臂在同一归档事件上仍错翻；在另一个固定短库上，二维评分也没有全面改善真实有差来源的双侧方向。保留潜变量评分为默认路径，不用该结果启动闭环。

每个检查点各用原训练档 16 个预留标定布局（2026111680–1695）的 1,184 个真实 H1 到达。固定的 `readout_diagnostic_fit80/layout_readout.pt` 同时读出真实 RGB latent 和该次实际动作预发的两个 latent。只取真实执行模式残差 `e = decode(z_arrived) − decode(z_issued,m)`，拟合一个共享的 `Σ = mean(e eᵀ)`，令各条件高斯中心仍是各自预发位置；不重拟合读出、不平移均值。写入使用 Cholesky 求解 `−½‖L⁻¹(decode(z_arrived)−decode(z_issued,m))‖²`，沿用 0.01 切换和原归一化。两个模式的高斯归一化常数相同。没有似然裁剪、额外门控、温度或物理标签参与实际写入。物理标签只用于训练档选择匹配残差和评估分组。

**真实归档尖峰。** 布局 2026111901、真模式 0、导航块 3 的两个模式五个原始步全同；记录的先验真支持为 .90035，旧记录有向似然差 −6110.475。按归档坐标重绘最后四个真实帧，并重发原控制。原检查点 CPU 复算 −6110.635，差 0.159 nat。原检查点 XY +6.913 把真支持推到 .999890，仍然不应有这一票。两新臂各自在归档真先验下评分：Arm1 −6359.032→−17.128，Arm2 −7607.057→−26.231 nat；两者都仍会错翻，在 XY 下分别得到真支持约 (3.29\times 10^{-7}) 和 (3.67\times 10^{-11})。同一情况表明，训练覆盖和测量降维都没有恢复物理中性不变量。

**独立固定短库。** 固定同源同控制、分别给两个合法到达打分；仅当每次都给各自真实模式更高似然才算双侧正确。去掉短库重复候选和重复 H1 源；3,129 个合法来源中 2,426 个无任何原始步差、63 个块内分开后末端合流、640 个末端有差。下表每格为原潜变量→XY。

Arm2 有差来源按实际到达模式分开：模式 0 正确 546→533，模式 1 正确 570→590；聚合双侧几乎相同掩盖了这一迁移。Arm1 的双侧正确下降 50 个，模式 0/1 分别 529→485 和 500→483。全块中性下，对相同到达打分产生的不同模式偏好同属假证据，无论当时真实模式是哪方。

**连续真实到达和固定行动库。** 在另一个 32 布局的生命周期档，Arm1 的 2,080 个全块中性真实到达在两种评分下均等分；Arm2 的 2,080 个仍全部非零，绝对值 P99 从 231.05 降至 1.069 nat，潜变量写入中有 371 次由真模式占多数翻成错误多数，XY 没有该类翻转。两臂各自全部 288 个物理有差来源在两种评分下双侧正确，64 个反转探测都将真实新模式置为多数。上轮 paired 的双侧正确由 261/288 降到 246/288，模式 0 出现 15 个反向投票。这套脚本生命周期比独立短库规整，两者分开报告。
