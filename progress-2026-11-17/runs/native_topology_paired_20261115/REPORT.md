# FourRoom H5 同根动作配对与真实写入

## 结论

配对训练降低了同一批候选上的首动作真实遗憾，并在新权重自己产生的候选上减少假进目标房间。优势主要来自对已有候选的评分，重新采样后的首选仍有一半误报。真实探测可以在之后十块交互中维持正确模式，但配对训练没有稳定增强真实写入对行动的额外收益。

## 配对采样和训练

32 个既有训练布局，每布局两门前根和两导航根。每个导航根用起始 `prefix` 权重做一次四轮 × 96 候选 CEM。受阻样本从模型低估代价的当前候选取，合法样本从同一真实位置、同一目标、同一模式下的原物理路线或精确物理 CEM 取得，要求其首动作和物理后果均不同。64/64 根配对，50 个负例在起始房间的末块发生碰撞。合法见证 50 条来自已有路线，14 条来自新物理 CEM。起始模型把 63 对的受阻方案排在绕行之前，物理 H5 代价均值为受阻 88.73、合法 48.73。选出的失败以模式 0 为主（60/64），每对仍保留两种模式的全部物理分支与真实前缀。 采样详情与失败定义（原工程资料） · 逐根采样（原工程资料）

两组从 §41.9 的同一个 `prefix/conditioned.pt` 继续训练，128 根、每根四条 H5 计划，两模式，以相同种子各用 20 轮、160 个 AdamW 更新。控制组保留原覆盖菜单，配对组只替换相应导航根的候选槽。一步监督源取两个实际前缀库的连接，两个训练臂均用同一个索引流取每批 8 个无块末模式差与 8 个有差的样本。共同训练源计 6747/1003 条记录，含两库共有的源。沿用原生 H1–H5 自由 MSE、真实窗一步 MSE、门控 BCE 及原学习率、正则和参数范围。 训练日志（原工程资料） · [拟合入口](../../research/p1a/native_topology_paired_fit.py)

## 预测和首动作

16 个优化外布局为已经用过的开发评价集。两组先对旧固定银行打分，再在同一真实根各自生成 384 条新 CEM 候选，并交叉打分。真模式给定，以同一模式的物理后果计算遗憾。首动作按其五个原始命令的完整值分组，所选组的最佳真实后续与全池最佳的代价差记作首动作遗憾。本批选中计划在同池没有更好的同首块后缀，因此该值与整条计划遗憾相同。

| 候选来源／模型打分 | 首动作真实 H5 遗憾 ↓ | 首选假进目标房间 | 候选对误排序率 ↓ |
|---|---:|---:|---:|
| 原固定池，原 `prefix` | 49.73 | 39/64 | 22.05% |
| 原固定池，对照 | 43.18 | 39/64 | 25.60% |
| 原固定池，配对 | 36.24 | 36/64 | 21.24% |
| 对照新提议，对照评分 | 42.31 | 44/64 | 26.83% |
| 对照新提议，配对评分 | 36.03 | 37/64 | 23.45% |
| 配对新提议，对照评分 | 40.38 | 39/64 | 25.87% |
| 配对新提议，配对评分 | 34.58 | 32/64 | 21.99% |

固定池配对减对照为 −6.94 地图单位，16 个布局中 12 个改善，布局配对百分位区间 [−10.89, −3.26]。仅固定配对组新提议，换配对评分器的收益为 −5.80 [−11.12, −0.53]。比较各自的新提议与各自评分，差为 −7.73 [−16.41, +0.66]。各自生成的池中，首选假进房减少 12/64，首选绝对代价仍高。区间按 16 个完整布局重采样 10,000 次。 全池中间量（原工程资料） · 交叉评分逐根结果（原工程资料） · 布局配对差（原工程资料）

固定池分层后，东南出发、真模式 0 的差最大，23.47→4.52。西北出发的两模式为 51.97→48.46、78.15→73.35，仍有较大遗憾。东南出发、真模式 1 为 19.13→18.64。配对训练收益的方向与模式偏斜仍应和训练样本分布一同理解。

| 固定诊断库 | 对照 H1→H5 | 配对 H1→H5 |
|---|---|---|
| 真实窗的一步预测跌落 `L−C` RMSE（px） | 2.80 / 3.67 / 4.66 / 3.70 / 4.12 | 2.70 / 3.35 / 4.26 / 3.52 / 4.13 |
| 自由预测 `F−Y` RMSE（px） | 3.07 / 4.07 / 6.53 / 9.34 / 12.56 | 2.90 / 3.72 / 6.52 / 9.32 / 12.47 |
| 自由模式差在真差方向上的增益 | 1.43 / 1.04 / 0.91 / 0.81 / 0.69 | 1.39 / 1.04 / 0.92 / 0.83 / 0.70 |

一步在 H1–H4 改善较明显，H5 自由位置误差及模式差增益相近。共同角点 H5 RMSE 从对照的 8.75 到配对的 9.90 px，合法绕行位移预测从 53.28 到 53.65 px（物理 61.80，训练前 56.14）。固定全池任一步错房间从 31.31% 到 29.51%，接近训练前 29.70%。配对改善了当前池的排序，未全面改善物理轨迹或恢复合法位移。真实窗 H5 门控漏报 34/148→33/148，误报两组均 4/512。块末有真差的 640 对中，两向似然均正确 456→460，至少一向错误 56→58。 诊断逐量（原工程资料）

同权重、同一短库强制 `r=1` 后，可见墙碰撞区端点的分支数 213→190，错房间分支仍为 148。预测模式差的 H5 增益 0.699→0.822，共同受阻末块的平均预测推进由 2.66 增至 3.94 px，合法绕行 H5 移动从 53.65 增至 54.02 px。强开门控在这批动作上改变了预测，但没有消除错房间。 固定动作门控干预（原工程资料）

## 真实写入与固定似然

32 个未参与本轮拟合的既有生命周期布局，每种初始模式分别复播已经到达的真实观测。三份权重在实际反转探测均给正确方向 64/64，2,080 个块末没有模式效应的实际到达均给同似然。三个规定探测在同布局中使用相同源窗，不能合并当作更多独立场景。十块返回和静默后，配对臂真实写入保持真模式多数 64/64，省略反转探测当次写入是 23/64，后续实际观察照常更新。

| 最终西北根的平均实际 H5 遗憾 ↓ | 原 `prefix` | 对照 | 配对 |
|---|---:|---:|---:|
| 真实写入 | 72.29 | 69.22 | 60.00 |
| 省略反转探测的写入 | 72.29 | 70.15 | 62.25 |
| 均匀支持 | 72.29 | 72.17 | 61.15 |
| 给定真模式 | 67.98 | 66.67 | 58.36 |

配对臂相对省略改动首动作 18/64，实际 H5 代价 5 个变好、2 个变差，其余相同。相对均匀平均改善 1.14，低于对照组的 2.95。只看有物理决策价值的 39 个最终根时，配对相对均匀平均改善 0.14，对照为 3.39。刚反转的门前根上，配对臂真实写入相对均匀反而多 0.45 遗憾。配对训练的绝对排序较好，持续证据额外影响选轨的收益仍不稳定。 同窗写入复播及分层（原工程资料）

对另一个固定开发短库的 3,129 个同源配对做似然分解。共享精度下实际对数比是标准化共同残差在预测差方向上的投影。配对组 2,489 个块末无差源中仍有 68 个非零。建议关注的小于 2 px 预测差、至少 10 px 中点偏差的切片里有 25 条，无一给非零。配对组最极端 8,879 nat 案例（布局 2026112009）预测差 14.56 px、中点偏差 7.17 px，属于块内分开后合流。原 `prefix` 在整个原始块过程均一致的最大尖峰 1,703 nat，其预测差和中点偏差分别为 2.84 与 4.50 px。大尖峰也出现在预测差本身虚大的组，不能用一个小差死区修掉。像素量仅供解释，分数用原 192 维固定尺度。 分组和缩放口径（原工程资料） · 配对模型逐源分解（原工程资料）

这次训练调整的是训练候选覆盖。结果支持保留成对的受阻与绕行监督，并将同池绝对预测能力和真实写入的增量分开报告。本轮开放计划的评价从固定真实根开始，自建换锁任务未执行新闭环。
