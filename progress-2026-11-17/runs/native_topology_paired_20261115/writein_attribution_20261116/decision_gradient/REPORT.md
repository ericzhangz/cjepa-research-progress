# 路径 A：配对预测器零更新梯度诊断

2026-11-16 · [原文核对及目标推导](../../../../research/methodology/DECISION_JEPA_UPGRADE_SOURCE_20261116.md) · [诊断脚本](../../../../research/p1a/native_topology_decision_gradient.py) · [完整梯度和逐例结果](summary.json)

**复现了真实冻结预测中的错房梯度。** 对首个满足规则的虚报进目标房案例，直接用硬地图代价做 D-JEPA 形式的排序，会把终点推得更深入错误房间。真实房间净空与成对代价间隔约束在该点给出相反梯度，并能通过当前固定读出到达原生 predictor、conditioner 和已打开的门控。关闭的门控逐步截断模式专有梯度；该约束不能绕开这个限制。

使用现有 paired checkpoint、部署同一固定坐标读出及原 32 个拟合布局。对每布局的两个导航根，保持原生三帧窗口、四条候选、两模式、五步自由预测，forecast 按现有拟合路径使用 eval、compact=False，关闭 TF32。原生分支与读出的输入反传保留；地图和真后果只提供离线标注。没有使用生命周期留出、生成候选、改网络、优化或执行新轨迹。

先遍历 64 个同根四槽的全部 384 对。严格首块见证要求五条原始首块命令不同、真首块终点不同、物理 H5 代价严格有序、两真终点离开地图中线。共同对限于已有标注的阻挡/绕行槽，要求被挡计划两模式均发生物理裁剪且留在源房，绕行两模式均无裁剪且离开源房，并且真实代价优劣同向。换序须两个模式都为严格见证且符号反向：60/384，其中 46 对恰有一个动作完全静默、14 对两个动作都有开启步；没有两个动作在两模式 H1–H5 都静默的真换序。共同见证 38 对，含真实严格见证且虚报进入目标房的 55 对；没有真终点恰落中线的对。每类只取按布局 seed、根号、槽号、模式号排出的第一例。

| 例 | 真实及预测结果 | 到达原生模式计算的证据 |
| --- | --- | --- |
| 1600，根 3，槽 1/2，共同受阻与绕行 | 绕行/受阻真实代价 51.12/106.24（两模式相同）；模型把受阻终点预测到墙上侧，给出 46.48/45.43，低于绕行 52.49 | 绕行槽两模式全程静默，终点对反对称条件方向的 Jacobian 范数严格为 0；受阻槽仅 H4 开启，两个模式的范数 1.68/1.37，H5 虽都关闭仍保留 1.87 px 的模式位置差 |

反对称方向是原 conditioner 两个已存在的 offset 去共同项后的 \((-\delta,+\delta)\)。计算终点两个像素坐标对该方向的 Jacobian，不由总 conditioner 梯度猜测其模式专有部分。记录逐步原 logit 的梯度：四例两种损失在所有零曝光位置均精确为零；已开启步可非零。原 H1 gate BCE 在四例都对 gate 有非零梯度，故保留独立的已有证据监督，但这不表明 BCE 已能正确学习所有分歧时刻。

两种术语统一为同一物理优先关系。硬代价 softplus 把 \(G\) 按图宽 224 归一化，固定使用原论文的 0.02 间隔和 0.05 温度；净空/间隔项用训练说明中固定的半量及 224² 标度。沿错房坐标朝真侧，用 ±0.01 px 差分与对应自动微分比较。实测反例对槽 3 朝左的导数：

| 目标 | 自动微分 / 中心差分 | 原生参数沿各自负梯度单位方向移动 0.001 后的终点 x |
| --- | ---: | ---: |
| 硬代价 softplus | +0.0092811 / +0.0092838 | 114.581，更深入错房 |
| 真实净空及配对间隔 | −0.00051785 / −0.00051797 | 112.889，向真侧移动但仍未跨过中线 |

同样的错房坐标检查在共同受阻例里，两损失均给正确纠正方向。上表说明的是实际反例，不能归纳为直接排序在每个错房处都给错梯度。

| 例 | 物理间隔项梯度范数：predictor / conditioner / gate | 物理间隔项目标的原生参数方向导数：自动微分 / 中心差分 |

两损失在四个案例的八个参数方向上，自动微分与中心差分方向全部相同；微扰均未切换室号或曝光状态。两个真换序例已有正确硬序，净空/间隔梯度比原 H1–H5 MSE 小，且一模式已满足约束（损失、梯度为零）；两动开启例正向微扰也触及该项零损失区间。所有微扰在内存恢复参数并逐张量检查相等，未保存或更新 checkpoint。

这一步通过的是可导性、错房反例和条件梯度的边界检查。它不表明配对监督能修复当前全部共同代价错误、把零曝光的模式分歧学出来，或将真实写入变为稳定首块收益。两个已抽查的真实换序也未检验误排序修复。更进一步要比较同数据同预算拟合后的冻结同池中间量，不能以零更新导数或排序损失本身当作 cJEPA 的贡献。
