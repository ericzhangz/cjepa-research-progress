# FourRoom 物理任务：首块可区分性、候选覆盖与完整完成

2026-11-16。只复算已有物理根和候选。没有执行新的闭环、模型前向、训练或参数搜索。

**任务有真实的延后决策价值；原 Gate 0 的联合通过条件仍未满足。** 西北共同根的第一个实际控制块尚未碰到会随锁切换的约束，知道锁态仍会改变通向两扇门的最优首块。H6 增强了这个可测信号，可以作为下一轮固定根的首选跨度；它没有提高完整往返的真模式绝对完成数。

H5 反转腿优势为 +24.22 [16.41, 31.25] 个百分点，但真模式 81/128 没达到额外预注册的 80% 门槛；H6 的 91/128 也未达到。H5/H6 真模式往返都为 54/128，但共同完成者只有 20；各有 34 个仅在一个跨度上完成。H6 较大的往返差来自均匀臂总完成数下降，不能据此宣布任务已修好。去程条件通过后真模式回程为 H5 54/81、H6 54/91，分母及回合构成不同。每个布局、每个方向和锁态都有第 10 块内到达的合法路线见证，既有 CEM 的失败不等于环境不可达。见 [Gate 0 协议](../../../physical_topology_gate_20261115/PROTOCOL.md) 和 逐场景归档（原工程资料）。

另一个 **8/64** 来自 16 个新布局的四个组合（西北/东南导航根 × 两模式），单次重播每根 388 条冻结计划（4 条原菜单 + 384 条冻结旧条件模型提议）。沿实际的 25 个原始步、任一步离目标 <16 才计命中；8 个组合有任何命中，8 个均被真实物理的原终点评分选到，物理均匀选到 5 个，历史自由预测只选到 1 个。其余 56 个组合在这份池和这个跨度内没有命中，无法把未命中分给跨度或提议预算之一。它不估计 Gate 0 的覆盖或反复重规划的完成率。见 原始任务归因（原工程资料） 和 [覆盖库定义](../../../native_topology_prefix_20261115/DATA.md)。

## 同一个实际首块的物理意义

对完全相同的根、目标及候选，按首块的五条原始命令完整分组，后缀可不同。令 \(Q_m(g)=\min_{a:a_1=g}J_m(a)\)，其中 \(J_m\) 是模式 \(m\) 的真实 H 末点代价。已知模式的最优首块集合由 \(Q_m\) 给出；均匀评分先按 \(\tfrac12(J_0(a)+J_1(a))\) 选**同一条计划**，再对其首块 \(g_U\) 量 \(R_m(g_U)=Q_m(g_U)-\min_gQ_m(g)\)。选中后缀的额外误差另计。盲选最小最坏遗憾 \(\min_g\max_m R_m(g)\) 评估两个最优首块集合之间的物理间隔。按原随机数和评分复原 Gate 0 已归档的共同首根，核对 2,304 条已记录的首选择、控制、逐原始步位置和整计划遗憾；没有复跑后续决策。

| Gate 0 西北同根 | 两物理最优首块集合不相交，/64 布局 | 均匀首块有正遗憾，/128 查询 | 均匀首块平均遗憾 [布局 95% 区间] | 有任一命中 / 真选命中 / 均匀选命中，/128 |
|---|---:|---:|---:|---:|
| H4 | 28 | 30 | 0.842 [0.393, 1.421] | 0 / 0 / 0 |
| H5 | 62 | 73 | 3.053 [2.274, 3.900] | 7 / 7 / 7 |
| H6 | 64 | 72 | 8.538 [7.663, 9.388] | 51 / 51 / 37 |

H6 按一个完整单轴原始步的地图尺度 2.5 衡量，58/64 布局的盲选最小最坏遗憾不小于该值，故 64/64 的严格换序不全是大间隔。西北出发时优势不对称：下门锁住时均匀首块 64/64 有正遗憾，均值 16.999；上门锁住时为 8/64、0.076。两种锁态都应独立报告，不能把这批布局当成平均对称的决策实验。

三个跨度中，所有西北根的候选首块逐原始步均**没有**同动作两模式位置差；到对应完整跨度，每个布局都有某候选发生物理分歧。把两种政策各自的首块实际执行后，仅用 H1 末点立刻计价，H6 的均匀减真模式均值为 −0.255 [−1.008, 0.534]。因此 H6 的首块价值来自其后可实现的后果；单看立即接近目标的距离测不到它。候选首次命中、首块续接价值、整腿完成不能相互替代。

冻结 8/64 银行的 H5 中，31/32 物理导航根的模式最优首块集合不相交；均匀首块 32/64 有正遗憾，平均 5.067 [3.764, 6.295]。固定同一银行只看到 H4 前缀时，对应计数是 22/32、23/64，且零候选命中。这解释了为什么稀疏的完整命中可以与实质首动作信号并存。

已有生命周期库中，最后西北静默根 64 次查询内，物理均匀首块 39 次有正遗憾，均值 3.589 [2.138, 5.263]，只有 3 个查询包含任何 H5 命中计划。上门受阻侧 96 次查询只有 12 次有正遗憾，均值 0.064；上门开启后门洞内的另 96 次查询虽有实际可见探测结果，但同一位置在锁住该门的反事实中占据实体墙，**不构成同根隐藏条件对照**。生命周期库没有下门根，不能把这些数字作上门/下门或两锁态的同一位置因果分解。保留门洞内记录用于证据读出，决策对照移到物理合法共点。

## 下一次固定根检验

协议只检验现有任务；此处没有采集或代替实际运行。用固定布局、两个方向和两种初始模式，主西北导航根固定为场景生成的西北站点、目标东南，主跨度 H6（每 5 条原始命令执行一块）。东南返向站点为预先指定的镜向检查；目前不能声称其 H6 条件已达标。以同一固定 H6 候选库切出 H4/H5 前缀判断跨度内输入何时开始受条件影响；另列原 Gate 0 的独立 CEM 结果。

1. **探测。** 保持现有合法门前坐标和控制：北西侧 `(100, y_top)` 向东，返向 `(124, y_bottom)` 向西，同一五步控制实际执行后有穿过/受阻两种 RGB。把写入只接在该实际到达；门洞中点不作共同决策根。
2. **静默。** 经合法退回、15 px 的往返和三块原零动作到站点；逐原始步验证所执行的安静块两模式相同。匹配站点的最近三帧、过去两块控制和目标在两锁态逐值相同，锁态分组平衡。最近窗口本身不能确定哪门开；完整实际历史和只看近期窗口在这里才是对照。安静期间无信息与当前更远候选能再次碰门可以同时成立。
3. **重入。** 在同一站点读取 H6 的远程首块选择，再沿既定控制实际到达门前；如需要测近根，分别固定在 `(100, y_top)` 或 `(124, y_bottom)`，保留共同三帧窗口后、在下一次碰撞结果到达之前查询。之后才执行真实重入探测，记录保留的支持与新事实各自贡献。
4. **反转。** 离墙站点换锁，成对执行 0→1、1→0；换锁时间与真值只用于离线评估，反证前不给策略相应标签。重新真实探测、合法退出并回同站点，在相同窗口、目标和候选下比较真实写入、仅省略反证、近期窗口/均匀、沿用旧事实、真模式。原端到端任务仍需执行模型选出的动作和再规划；此固定根阶段只建立可行动作的归因。

在看任何学习输出之前，用精确物理锁定并保存布局、根、目标、完整控制库和全部 12 块内的实际可达路线见证；每布局每方向、两种真实锁态都分别验一条。每个候选在两个模式中都用同一根和动作实际分支计算，银行内同时留下两类合法线路的见证计划，计入共同预算。根必须两模式可合法占据，最近窗口匹配，银行必须允许两模式不同的最优完整首块；主决策面板预先固定盲选最小最坏遗憾下限 2.5 地图单位（一条最大单轴原始命令的尺度；这是测量门槛，不修改任务、CEM 或训练）。同时分别列出均匀与旧模式的物理首块及实际逐步后果，注明哪一锁态的均匀臂已经接近物理最优、哪种对照仍能检验真实写入的增量。任一物理门槛未通过，把该根留在全样本流程并注明限制；可区分根面板用事前物理规则冻结，不用真实写入或模型选取结果筛选。若 H6 未达到固定检验，报告缺失的数据条件，不从学习结果挑跨度或根。
