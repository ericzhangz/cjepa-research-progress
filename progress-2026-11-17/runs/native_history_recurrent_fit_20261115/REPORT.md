# 联合历史的定额递推训练

2026-11-15。按[核心机制 §37](../../research/CORE_REGULATION_MECHANISM.md#37-沿真实观测递推训练同一组解释)，从同一冻结初始模型出发训练联合支持、省略祖先证据、先合成输入三个对照。每组只训练原有模式 conditioner 与预测投影头的 795,076 个参数，使用相同的 48 次 AdamW 更新和相同的每批两个场景。三组分别耗时 20.3、20.3、23.4 秒。三个版本每场景预发真实源后缀 36 次，并在各次训练的候选未来合计预发 96 次后缀。联合与省略祖先组各进行 156 次第一块注意力调用的窗口处理，输入均值组为 132 次。调度和计时均为训练步骤，读取资料和验证另计。次数不外推到在线推理延迟。

拟合组为 55840–55855。另用两个不参与这次拟合的归档场景组 55900–55915 和 55710–55725 验证。三组的实际动作与模式时序一致。每组在完整初帧后，实际递推只读九次横坐标观测和实际命令。两次反转根都有同根执行的六个候选和两个未来固定物理模式。源的两种真实后继及候选的物理标签仅进入损失。在三组训练启动前，未训练路径通过了 §36 的已存位置误差复现。57 项回归通过。

## 训练结果

固定真实短期模式读出预测，仅用它选择与已执行真实候选匹配的评分索引。下表每格是 H4 的「所有动作绝对 XY RMSE / 相对保持 XY RMSE」，单位为环境坐标。H1/H2、逐场景和完整源过程见原始记录。

| 计算方式 | 55900 解除制动 | 55900 恢复制动 | 55710 解除制动 | 55710 恢复制动 |
| --- | ---: | ---: | ---: | ---: |
| 冻结 §36 | 72.49 / 61.83 | 90.71 / 69.42 | 68.85 / 61.41 | 61.83 / 46.88 |
| 训练后联合支持 | 115.05 / 76.21 | 126.70 / 65.57 | 67.25 / 42.58 | 72.25 / 37.67 |
| 训练时也省略祖先证据 | 121.54 / 81.62 | 136.22 / 67.28 | 74.11 / 45.06 | 79.54 / 38.32 |
| 训练时也先合成输入 | 118.69 / 77.08 | 129.10 / 65.71 | 69.60 / 42.86 | 73.45 / 37.66 |

整个动作集的平均误差因场景和反转而异。联合组相对其他训练组通常更准，但相对冻结原生路径失去了大部分绝对位置精度，且 55710 的相对误差改进也出现在先合成输入组。在 55900 两次反转，联合组的实况模式判断分别由 10/16 提到 14/16，再由 6/16 降到 2/16，Brier 从 0.375 / 0.593 变成 0.113 / 0.648。在 55710 则由 6/16、14/16 变成 13/16、3/16。两组均未获得两次反转都更可靠的证据。恢复制动之后的真实标签仅用于事后评分。

## 证据是否还有原生效果可读

固定同一权重、窗口、候选、预测模式和当前模式的边缘支持，只撤去最后一次观测赋予同一模式内的历史证据。另单独读取四条已经存在的历史，计算对每个候选相对保持的纵向质心预测的最大与最小差，再对根和候选取 RMS。这是针对已学表示的有限干预，不把单条历史的条件权重当成新实况估计。

| 55900 反转 | 权重总变差，冻结 → 联合训练 | H4 历史读出的相对纵向跨度，冻结 → 联合训练 | H4 最近一次写入的实际相对纵向改变量，冻结 → 联合训练 |
| --- | ---: | ---: | ---: |
| 解除制动 | 0.04835 → 0.01226 | 5.994 → 0.01727 | 0.3901 → 0.000294 |
| 恢复制动 | 0.000054 → 0.04389 | 3.827 → 0.01299 | 0.000231 → 0.000305 |

第二次反转的历史支持已明显能动起来。失效主要表现在已经存下的四条历史经过同一原生查询后，几乎给出同样的动作差。两种未来物理模式之间的 H4 相对纵向作用也出现收缩。在 55900，真实 RMS 为 28.27 / 31.65，冻结预测为 6.07 / 4.67，训练后只有 0.146 / 0.203。训练后沿真值方向的投影系数分别约 0.00223、0.00145。联合组的条件差误差略降，主要来自幅度接近零，不能视为学会了物理条件的正确作用。训练集本身也出现相同收缩。

**阶段判断。** 这次定额训练未建立所需能力。应保留 §36 已验证的「先区分历史再更新」信息路径。用同一事实根的两个未来模式监督，可辨别未来模式作用，但并未规定在给定当前模式时不同真实父历史应当产生怎样不同的未来。下一段拟合需要把源观测对历史的辨别、以及同一当前模式下已独立执行的保持和候选物理差直接配对。已存锁定档案只能覆盖这一组合的一步源后果，完整中途动作组仍需要原有物理协议下的匹配执行。先确定这种监督能辨别的历史贡献，再开展后续学习和独立时序验证。
