# Reversible PushT delivery protocol

The physical question is whether a decision after an actual mode reversal benefits from knowing the new mode when the goal remains unfinished. The intervention, PushT dynamics, initial scene generator, five-command blocks, and native goal overlap retain their existing definitions. This protocol tests physical action value at one decision per scene.

## Fixed before collecting outcomes

- Use all 16 new scene seeds 55810–55825, with an actual braked-to-open change on even seeds and open-to-braked on odd seeds. Use the goal pose given by the scene's reset pose translated 180 units to the right. The distance equals twice the native 90-unit T stem length. Fix this pose and its rendered image before the first command.
- Execute the lifecycle prefix of push, retreat, three holds, return push, and recontact push in the initial mode. Switch once, then execute one more push to obtain five actual post-switch RGB arrivals before the decision. Check native success (strictly greater than 95% overlap) on reset and after every raw command. Record any achievement before the switch or during the probe, and retain the scene in the report. Verify that flipping the mode does not itself change RGB or visible physical motion state. Replay the true history ending at the switch and execute the same probe in the old mode to record the new physical and RGB evidence.
- From the post-probe state, independently replay the same actual prefix for every action in both modes. Verify exact root images and physical motion state of both dynamic bodies before each rollout. Execute five raw commands of each fixed action block. The ordered bank is hold, one-quarter push, one-half push, three-quarters push, full push, native rising push, and native falling push. The horizontal amplitudes give a one-quarter-step resolution on the existing push magnitude. The native steering actions allow a different angle of approach. All decision rules use the same seven candidates.

## Decision comparison

Use one minus native terminal overlap for the action cost. Compare the minimum for the actual mode, the minimum of the mean cost across the two modes, the minimum for the previous mode, and always-open and always-braked minima. Resolve numerical ties within \(10^{-12}\) by the declared action order. For each rule report all candidates within one absolute overlap percentage point of the minimum and their minimum and maximum regret under the actual mode. Regret is measured relative to the best terminal outcome in the actual mode. Also report regret averaged across both modes at the same root, where the known-mode optimum is calculated separately for each mode. This distinguishes a mode-sensitive choice from an advantage that only applies to the direction selected for the actual trajectory. Report disjoint mode-specific near-optimal sets and strict pairwise preference reversals with gaps exceeding one overlap percentage point in each mode. Report terminal success and any earlier success within the five-command block separately.

Use the paired scene as the unit. Report the full cohort and both balanced reversal directions, with the complete per-scene data, the number of positive regrets exceeding one percentage point and bootstrap intervals for mean regret. An achieved-before-reversal scene fails the unfinished-goal requirement. A visible source contrast without robust regret leaves the case for a changed action selection unresolved. The physical comparison excludes model forecasts and training, and a positive result supports this decision protocol for a later learned comparison.
