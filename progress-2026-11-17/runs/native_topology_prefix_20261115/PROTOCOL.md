# 匹配 H5 离线学习

从 §41.8 的现场失败出发，判断同一个原生预测器在固定查询上能否同时学到共同受阻、合法位移及局部模式差。全过程只对固定真实根作候选前向和实际物理后继采样，评价不做闭环。未参与前序优化的 2026112000–2026112015 用作独立评价布局。从原 80 个优化布局取确定的前 32 个 2026111600–2026111631 做小规模继续训练。

| 臂 | 根候选 | 同一原生一步损失和门控 BCE 的来源 |
|---|---|---|
| `old` | 原四候选完整保留前四块，按固定规则增加第五块 | 原实际脚本的一步样本 |
| `query` | 一次性冻结的原模型 H5 CEM 查询，每根仍四候选 | 同一批实际脚本的一步样本 |
| `prefix` | 与 `query` 逐值相同的根、动作及目标 | 从同一库已经到达的合法 H2–H5 窗口，固定同一个下一动作取得两模式实际块末目标 |

三臂均从 §41 的同一 `conditioned.pt` 继续训练，不串联加载中途训练臂。每臂 4 个真实根×32 个布局，四候选、双模式；每批 16 根、一步样本 8 个无块末差和 8 个有块末差。20 个 epoch 共 160 次更新，沿用 AdamW 1e−4、weight decay 1e−4、固定 seed 411115，eval 模式下优化原预测器、动作嵌入及既有 conditioner 和门控。冻结编码器、读出及似然尺度。相同随机索引用于根顺序，`old` 和 `query` 共享相同一步脚本索引。`query` 与 `prefix` 的多步路径数据完全相同。取最终更新后的模型，与冻结初始模型同时报告。

三臂使用相同自由 H1–H5 latent MSE 均值及实际窗一步 latent MSE，各权重 0.5。BCE 的两项分别为共同根首块与实际一步源，权重各 0.5。门控标签继续用同根同动作块末差。两条真实分支离开共同根之后，从每条各自的已到达完整历史和物理状态复制下一步反事实。关闭后占据墙内的非法源不产生配对标签。保留完整的真实分支作为自由预测监督。

独立布局在所有权重拟合前固定采集。报告共同受阻的假房间、沿真实动作的虚假推进及 `C/L/F` 分段误差；记录合法路径实际移动和方向保留程度，防止用抑制一切运动改善受阻指标；对同一组候选比较真实模式下的代价排序和遗憾量；对同根同动作的两真实块末分别计算似然方向，并记录物理无差时的虚假似然。记录样本量和逐布局成对差。不根据指标挑选权重、调整阈值或再扩充训练。
