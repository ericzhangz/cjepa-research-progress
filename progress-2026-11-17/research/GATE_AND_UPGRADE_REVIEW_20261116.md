# 同池门控归因与结构升级：本轮实际执行

2026-11-16。此报告回答“建议是否执行、执行后怎样决定”。原生模型、真实支持、候选及任务保持固定；本轮未训练或重跑自建换锁闭环，未使用哈希。论文结果与本地测量分别标注。

## 1. 之前做了什么，本轮补了什么

此前已完成 pre/post/omit/uniform/真模式的同池归因，以及共同项 B 与模式差 D 的离线替换。此前的强开门控来自另一套短库，**没有在这套生命周期库上做 r=1 和几何分层**。本轮已补齐，同一冻结权重分别使用原门控与 r=1，重算全部 H1–H5；真实支持仍用同一份已到达事实计算，不随候选门控干预一起改变。

固定对象为 32 个既有生命周期布局、96 个候选池，每池 384 条 H5 计划、256 次查询。完整首块含五条原始命令；按相同首块分组，将首块决策遗憾与后缀遗憾分开。布局是统计单位，不能把所有候选或重复查询当成独立样本。原门控重算的位置及代价与历史 H1–H5 数组逐值相同；强开暴露量均为 1，强开代价与同一读出重新评分相同。

**同时纠正了一个位置误读。** 三类实际根是：上门越过侧 (x=112.5,y=73–82)、同一上门受阻侧 (x=103,y=73–82)、西北导航根。前两类分别对应现有库中的模式 0 / 1，均有 96 次查询；西北根有 64 次查询。第二类此前被临时枚举名误称“下门后根”，实际没有下门根。因此现存库不能回答上下门、位置与模式完全对称的因果比较。

## 2. 强开门控没有救回首动作

以下均为实际物理首块遗憾，越低越好；候选、真实支持和根完全相同。

| 位置 / 支持 | 原门控 | r=1 |
|---|---:|---:|
| 上门越过侧，真模式 | 4.875 | 5.485 |
| 上门受阻侧，真模式 | 61.096 | 61.018 |
| 西北导航，写入前 | 59.816 | 63.242 |
| 西北导航，实际写入后 | 59.816 | 63.242 |
| 西北导航，仅省略反转事实 | 62.057 | 64.270 |
| 西北导航，均匀支持 | 60.958 | 65.551 |
| 西北导航，真模式 | 58.117 | 57.818 |

导航根没有新区分事实，pre/post 首选一致；过去事实的持续作用由 post 对 omit / uniform 判断。强开后相对均匀的差从 1.142 增至 2.308，但两者绝对质量都变差；相对省略反转的收益反而从 2.241 降至 1.028。不能只报告“相对均匀收益变大”。真模式近似不变的均值还掩盖两种模式的反向变化：模式 0 为 46.24→52.72，模式 1 为 69.99→62.91。

固定原“学习均匀首选—物理真模式最优”的候选对，不随 r=1 重挑对子。在西北根 62 个存在严格更优首块的对中，61 个真实跨动作模式差非零。其预测代价差方向同号由 42/61 增至 48/61，幅度中位比由 0.191 增至 0.595；物理方向同向仍为 49/61，物理幅度比由 0.213 增至 0.492。共同代价间隔误差中位仅从 77.21 降至 73.87，强开后仍有 46/62 对共同间隔方向错误。

这有明确的计算解释。对于固定动作 a，写作 J_k^r(a)=G(F_k^r(a))，B_r=(J_0^r+J_1^r)/2，D_r=J_1^r−J_0^r。调节强度 r 同时改变 B_r、D_r 以及后续递推状态；非线性预测和硬分房代价不保证 B_r 对 r 不变。强开既可能恢复条件作用，也可能移动两解释的共同后果。不能把 r=1 简化为只消除漏报的无副作用开关。

同池离线四格进一步区分这两项。西北 post 的原 B/D 首块遗憾为 59.82→63.24；只把 B 换成物理真值为 2.65→3.30；只把 D 换真值为 37.41→42.85；两者都真为 0.286。这些是决策敏感性实验，用了离线真值，不是可部署修复，也不能把各差值凑成失败百分比。

## 3. 失败类型已经按真实位置拆开

标签固定在**原门控、真模式的原 H5 首选**上，检查其所有块：预测端点占据可见静态墙体；或者从有效前一点执行完全相同原始动作，在所有可见门开放的原模拟器碰撞规则下受阻，而预测跨到了另一侧。隐藏锁冲突与无效前点另记。单纯预测进错目标房，不直接算作静态穿墙。

下表按“静态占据→静态跨越→仅锁门→无上述几何错且真模式有首块价值→其他”优先级互斥归类，重叠旗标另存原始文件。这是描述分层，不是可相加的原因占比。

| 原首选计划分层 | 上门越过侧 /96 | 上门受阻侧 /96 | 西北导航 /64 |
|---|---:|---:|---:|
| 出现静态墙占据 | 3 | 42 | 39 |
| 无占据，但有碰撞支持的静态跨越错误 | 3 | 18 | 10 |
| 无前两类，但有隐藏锁冲突 | 0 | 30 | 1 |
| 无上述几何错，且物理模式信息会改善首块 | 72 | 0 | 9 |
| 其他 | 18 | 6 | 5 |

西北原首选 49/64 有上述可见静态墙错误，但仍不能说“76.6% 失败因共同偏差”：这是选中计划的几何表征；同一计划也可能存在方向、幅度和证据问题。全 256 查询中静态占据 84、静态跨越 55，两者重叠 24；某块仅锁冲突 94，又可与别块静态错误共存。

还分别统计了 r=1 后重新选择，以及 r=1 作用于原先同一计划。强开作用于原计划时，H5 假报目标房从 144 降至 84，但 H5 静态墙占据由 1 升至 67。部分终点只是从错误目标房移进墙内，并未变合法。因此“假进房降低”必须与占墙、实际动作后果一起看。

60/64 的模式 0 负例选择偏斜，不能直接当作其造成失败的比例。原训练每条计划都包含两模式监督，完整四槽菜单也有真正的模式换序。这次没有进行匹配的对称采样训练干预，故未把训练偏斜单独定为根因。

## 4. 路径 A 与 B 的原论文、代码判断

**A：决策约束值得借鉴，但不能原样套到当前硬分房代价。** D-JEPA 的 87.89% 是 PushT 的 225/256，不是 FourRoom；作者的对比是经过规定筛选的固定候选池，且组合了关系选择和受限预测更新。其 softplus 间隔针对同池成功/失败候选，没有隐锁模式对称训练。[原文](https://arxiv.org/html/2609.24749v1#A3.T9)

当前 G 根据位置离散选择房间。对已经落入错误房间的预测，直接对 G 套排序损失可能沿该错误分支继续向目标推，反而加深物理错误。一个可沿原读出传回的修订是：真实同侧净空与同根真实间隔共同约束预测端点。若两端保持真房间，且位置误差和不超过真实代价间隔的一半，由房内 1-Lipschitz 可保证部署间隔至少保留一半。此为监督工具，不是本项目核心创新。完整推导及作者实现细节见[路径 A](methodology/DECISION_JEPA_UPGRADE_SOURCE_20261116.md)。

**真实模型的零优化步检查也已完成。** 只用原拟合库，按固定规则选共同受阻/绕行、两类真换序和虚进房四例。实际错房例的真 x=103，预测 x=113.896；沿两项目标各自的原生参数负梯度作同长度 0.001 的内存微扰，直接硬代价排序把 x 推到 114.581，净空/间隔监督推回 112.889。后者方向正确但尚未回到真侧，不能当作修复效果。两损失共八个参数方向的自动微分与中心差分同号；全部内存微扰恢复，checkpoint 未更新。新监督能经固定读出到达原生 predictor、conditioner 及已开门控；严格零曝光处对 logit 的梯度仍为零。不能认为加这一个 loss 就会自动学会遗漏分歧。详见[真实计算图报告](../runs/native_topology_paired_20261115/writein_attribution_20261116/decision_gradient/REPORT.md)。

**B：值得采用完整多尺度宿主，不能把发布成功率当成“不穿墙证明”。** HWM3 的 99.3%、H-JEPA3 的 96.0% 是作者官方静态 FourRoom 的到达率；T2G dense 的 81.3% 只更换冻结预测的评分。它们没有报告当前隐藏可逆门锁的成败，也没有证明所有候选不穿墙。本地目前只完成 flat seed42 的 19/50，不能说已经复现了这三个强基线。[官方结果](https://github.com/kevinghst/H-JEPA/blob/main/docs/RESULTS.md) · [T2G](https://arxiv.org/html/2611.05847v1#S3)

选择完整 HWM3 seed42 作为下一结构宿主候选。其原生步长为 5/10/20 个环境步，上层状态编码为恒等，便于把同一解释在粗细时间上的物理后果对齐。它仍有独立粗步 predictor 和学习的宏动作编码。不能只给现 flat 接上新宏步模块；两个 checkpoint 的底层参数也不同，旧读出、门控和似然尺度不能直接套用。

本轮已读取发布对象元信息、配套 normalizer，并比较一项真实底层参数，确认其与旧 flat 不同。完整约 86 MB 权重下载中断，**未完成完整 HWM 数值前向、方法移植或 50 任务复现**。元信息不是性能验证。[路径 B 的源码与接口报告](methodology/HIERARCHICAL_UPGRADE_SOURCE_20261116.md)

## 5. 我的研究决定与剩余工作

**以下是我的判断，不是数据已证明的唯一解决方案。** 不再把“原菜单换成对称菜单后再做一轮相同 MSE”当作当前充分的修订。优先推进 B 的同一宿主粗细计算对照；A 的决策监督作为可解释的训练工具检查，不把新增排序 loss 或层级模型加后验更新包装成创新。

移植必须保住同一计算对象：真实经历只更新一份公共支持 p_t(m)；同一解释 m 同时作用于原生细步和粗步预测。对一条实际命令序列，用官方动作编码聚合成宏动作，比较同物理时刻的细步续推、粗步预测及真实未来。各解释评价同一条可执行动作序列，再按公共支持加权；不能让每种模式先各选不同动作、然后混合成貌似低成本的虚构行动。真实到达前只预发证据，假想分支不写回公共事实。粗步端点相同也不能证明其内部过程不分歧。

下一台阶先是完整权重接口与同 checkpoint L1/L2/L3 的同根、同原始动作比较，随后才是将同一条件解释贯穿各层的学习。正式任务收益需随后独立建立。本轮不声称 HWM 必定解决共同可达性，也不承诺接回支持就会赢；本轮完成的是强开归因、真实位置分层、升级来源和计算接口的具体选择。
