# 原生联合项与四次实际执行的结果

保持 LeWM 原生第一块，精确分离最后 token 送入 attention 前的观测与动作联合项。真实写入使用两个已观察上下文中各自独立执行的零命令和 +60°。写入从四条实际到达的结果形成累计证据，读取只在独立的直推和 −60° 上评价。档案为旧 MSP 的 16 个拟合场景与 48 个回归场景。该流程需要重放两个上下文的真实执行，普通单轨迹缺少的事实无法用模型预测补齐。 [方法与协议](../../research/methodology/NATIVE_JOINT_CYCLE_20261112.md)

## 代数与原生中间量

32 个真实原生接口请求中，24 个处在原生参考边，完整预测逐元素等价。所有过去 token 的 Q/K/V 和输出精确相同。四角差的最大坐标误差为 3.95e−7。删除联合项后，attention 自身归一化后的最大变化为 1.156，最终 latent 最大变化为 0.01922。原生输出与两种非零模式中点的最大差为 0.00259，显示必须使用真实非线性原生曲线。测试过完整实际四格、缺一格拒绝写入、动作与上下文加性偏差精确抵消，以及后来更有信息的实际四格修订旧状态。与真实联合变化同形的外来偏差仍不可辨识。 [接口结果](pusht/interface.json)

## 实测成本

RTX 4060 Laptop GPU，单根两个候选，原生第一块钩子，动作嵌入和观测编码已完成。选择第一条读取非零模式的根 107000、世界 0。读取仍只执行一次原生 predictor。

| 操作 | 同步墙钟中位数，毫秒 |
|---|---:|
| 原生两候选 | 6.051 |
| 联合项读取 | 6.744 |
| 唯一活跃事实额外两种原生模式 | 12.408 |
| 已有四事实时写入 | 0.280 |

同轮读取增量中位数为 0.558 毫秒，p10–p90 为 −0.608 至 1.818 毫秒。每根累计的模式误差占 24 字节，参考编码占 768 字节。部分四格的临时缓存和获得额外真实执行的成本未计入。这个测量只覆盖当前一个跨度、两个动作的接口。 [原始计时](pusht_trained/cost.csv) · [测量范围与分位数](pusht_trained/cost.json)

现有设计已经建立原生可执行性、合法证据写入、未来监督、状态不随查询改变和单步运行开销。固定数据与当前联合项未给出可靠效果。本候选归档为机制参照。没有运行多时域或最终任务，普通单轨迹如何可靠形成联合证据仍待解决。
