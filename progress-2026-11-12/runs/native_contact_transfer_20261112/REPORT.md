# 真实位移传递关系的原生接口与物理前提

本阶段把同一次真实执行可观测的推手与 T 块位移写成一个局部传递关系，并沿冻结 LeWM 的原生最后仿射层施加这个关系。状态的形成与每次预测读取共享同一项物理含义。已有 PushT 轨迹未针对该关系设计同条件激励。本轮的状态来自解析流，真实 PushT 记录分别用于测试原生读取和单独检验物理前提。 [推导与协议](../../research/methodology/NATIVE_CONTACT_TRANSFER_20261112.md) · [主路径实现](../../research/p1a/native_response.py) · [实验入口](../../research/p1a/contact_transfer_stage.py)

## 解析写入

三个按时间到达的位移对消去任意仿射漂移。首段只支持一条轴，另一轴与参考动作原样通过。第二条独立段到达后，两个非参考动作的物体后果被旋转到不同方向，推手和角度保持。重复查询结果逐元素一致。显式解除后清空得到原生结果，解除后的新事实可形成零传递。把旧条件和新条件的相反事实混合，共享关系的残差平方和为 18。二次漂移反例使估计列恰好偏移 `(1, 1)`。这些是对计算式的确定性例子。 [逐事实位移及结果](analytic.json)

## 冻结 PushT LeWM 的接口

固定八个视觉起点，每个查询直推、两次转向和保持。双轴解析状态在每个跨度对 24/32 条请求生效，8 条实际零命令精确跳过。单轴解析状态没有覆盖本批真实模型产生的非零候选方向。清空与解除两臂输出逐元素相同。与直接批量原生预测比较，空态 H1 最大 latent 差为 `7.15e−7`，来源可包括额外参考改变的批量形状。

| 同窗口角度坐标最大修订 | 0.000000219 | 0.000000261 |
| 同窗口物体坐标最大修订，像素 | 60.11 | 71.52 |

H2 的保护性质以该分支的同一预测窗口为条件。第一步改变了第二步的输入，两个完整动作程序的 H2 推手差在双轴臂与清空臂之间最多相差 19.65 像素。这里的位移量是冻结读出和人工传递造成的作用范围，没有用来主张真实准确性。 [原生统计](native.json) · [逐起点、候选和跨度的条件差与程序差](native_responses.csv)

RTX 4060 Laptop GPU 上单根四候选同步墙钟中位数为原生 8.54 ms、调节 10.02 ms。同轮配对增量中位数为 0.87 ms，10%–90% 分位为 −1.85 至 4.65 ms。调节将一个参考与四个候选合批，未重新执行真实轨迹。计时从已经编码的动作和观测及已形成关系开始，未包括真实写入、识别条件或采集额外执行。 [原始计时](timing.csv)

## 物理关系的事后表达范围

192 个同起点均有四条独立执行的真实后果。以保持为参照时，三条非零候选的实际物体位移差平均范数在 H1/H2 为 20.09/40.98 像素。即使给关系真实推手位移、逐根使用该跨度的全部真实物体后果做平方误差拟合，平均残差范数仍为 4.38/12.06 像素。H1 拟合后在 H2 使用为 14.80 像素。三个非零动作在两块均有接触的 90 根仍有 H2 事后残差 9.95 像素，H1 到 H2 为 13.93 像素。改用直推参照后，同跨度 H2 仍为 12.06 像素，H1 到 H2 为 16.10 像素。接触子集只要求各块至少一次接触。共享接触位置、同一接触面和滑动条件没有由该标签确定。 [逐根与逐动作记录](physical_relation.csv) · [汇总](physical_relation.json)

**裁定。** 实际可实施的作用比前一轮固定方向的增益更明确。预测器能按不同的真实作用方向修订物体坐标，并保持同一窗口内的其他指定读出。但当前档案已显示，用推手终点位移及一个常矩阵解释物体的多步动作后果存在明显误差。现有证据不足以把这个全窗口关系用于下一阶段的真实学习或声称真实预测得到改善。保留原生接口及反例。后续构造需给出接触位置与转动在真实经历中怎样进入可辨认的关系，再判断单一局部关系适用的范围。九项现有 P1A 参照测试通过。本阶段未做最终闭环任务。
