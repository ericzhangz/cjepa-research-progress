# 源反馈的原生执行成本

设备为 NVIDIA GeForce RTX 4060 Laptop GPU。原始冻结宿主使用 FP32 与 MATH SDPA。固定环境步 25 的真实请求，使用 z3 至 z5 与第 3 至第 5 个动作块，兑现使用环境步 30 的实际 z6。M5 从持久性实验的源反馈 M6 取前五条记录。B=1 使用 episode 0，B=50 使用全部经历。

每项先预热 10 次，再按固定循环顺序独立测量 30 次。每次调用分别记录 CUDA event 间隔和同步墙钟。兑现重复使用计时前发出的请求，并在每次调用后丢弃新返回的 M6。源请求保留开关前后的 query、readout 和预测 latent 逐元素一致，空态预测与原生预测逐元素一致。观察编码、动作嵌入和数据传输在计时之外。

保留源时额外计算最后一个 query 对历史 key 的 log-partition，并保留原生头输出、log-partition 与请求的 shift、scale。兑现计算实际与预测后继的两组 K/V，随后追加一条记录。Canonical 对照使用同一 M5 上预发请求的输出，两次计算中性条件下的后继 value。

从发出到兑现，源专用待处理张量为每经历 3,616 字节，B=50 合计 180,800 字节。字节数按有效元素计算。源请求还紧凑复制了共同需要的 query。实测间隔反映当前实现的 hooks、张量复制和调度，CUDA event 间隔可含主机发射间隙，墙钟包含计时调用与逐次同步开销。这些数值对应这台设备上的固定三 token 请求和五记录状态。
