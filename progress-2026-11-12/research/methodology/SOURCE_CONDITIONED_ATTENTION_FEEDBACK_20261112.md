当前入口：[预测请求反馈方法稿](PREDICTION_QUERY_FEEDBACK_20261112.md)、[原生调用接口](../p1a/native_response.py)。本文仅构造反馈桥的一种明确替代，不增加第二套世界模型，不宣称已经取得预测收益或论文级新颖性。

## 1. 组织方法的一项计算选择

**让实际发出预测的同一个原生 query，在真实后果到达后对该后果重新作答；保存“预测后果被真实后果替换”所造成的回答变化。**

当前桥将两个后果独立送入固定参考条件下的 value 特征，再取差。本文候选保留当次原生请求及其上下文回答，让后果读回依赖这次已经发生的运算。

这一选择同时规定：源地址来自实际预测；回答基准来自实际 attention 上下文；后果到达后才能读回；回答变化仍进入原生 value 输出接口；离线训练建立这项变化与原生后缀作用之间的联系。attention 插入、差分目标和逆重构均为已有运算，不能分别作为创新声明。

## 2. 发出预测时已经形成哪些量

以下先对一个 head 推导。其他 head 分别计算，最后按原生方式拼接。当前宿主为 8 个 head，每 head 64 维。

原生首块在实际窗口和动作条件下形成

\[
u_j=N_A\!\left((1+s_A(c_j))\odot N_1(x_j)+b_A(c_j)\right),
\qquad q_j=W_Q u_j,\quad k_j=W_Ku_j,\quad v_j=W_Vu_j.
\]

其中 \(x_j\) 包括原生位置编码和 input projection，两个 LayerNorm 都属于实际路径。对当前待预测的最后一个 token，记请求为 \(q_i\)，允许被它读取的原生上下文集合为 \(\mathcal J_i\)。定义

\[
s_{ij}=q_i^\top k_j/\sqrt d,\qquad
Z_i=\sum_{j\in\mathcal J_i}\exp(s_{ij}),
\]

\[
N_i=\sum_{j\in\mathcal J_i}\exp(s_{ij})v_j,\qquad
o_i=N_i/Z_i,\qquad \ell_i=\log Z_i.
\]

\(o_i\) 是加记忆之前的原生 attention 回答。已有记忆实际提供的作用是 \(r_i\)，所以送入原生 \(W_O\) 的量是 \(o_i+r_i\)。最终发出预测 \(\hat z_{i+1}\)。

本候选的待兑现记录保存

\[
\Pi_i=(q_i,o_i,\ell_i,r_i,\hat z_{i+1},c_i,j_i),
\]

其中 \(c_i,j_i\) 是实际源动作条件与已有源 slot 编号。这些额外量只在兑现该次预测时使用，不是新的永久经历库。

实现直接捕获实际 \(c_i\) 产生的 AdaLN shift 和 scale，以这两个等价条件重建后果输入。发出时从实际 native K 和固定最后 query 计算 log 配分量，捕获投影前最后 token 的原生回答。实际兑现只计算两组后果 K/V。纯查询调用可设 `retain_source=False`，此时跳过配分量与源条件的缓存。若需要在纯查询后兑现选中的请求，必须在执行前保留或重新发出该请求的源量。

在当前 \(H=8,d=64,D=192,T=3\) 配置下，待兑现请求相对固定特征差多保存 904 个浮点值和一个 slot 编号。保存量来自 512 维回答、8 个 log 配分值与两组 192 维调制量。源发出时增加 \(THd\) 个 query-key 点积乘加项及 logsumexp。兑现用原有线性投影的 K/V 行，两组共约 393,216 次投影乘加。固定特征差的两组 V 为 196,608 次。此处给出运算量，实际耗时由分阶段记录提供。

### 2.1 固定源 query 的充分统计

对固定的 \(q_i\)，既有上下文的全部加权和由 \((N_i,Z_i)\) 给出，等价地由 \((o_i,\ell_i)\) 给出。往上下文加入一条新 K/V 时，可以据此精确计算同一个 query 的新回答，无需为这项操作保留全部原始 K/V。

**充分性仅针对这个固定源 query。** 换成另一个 \(q\)，需要重新计算由 \(\exp(q^\top k_j/\sqrt d)\) 加权的分子、分母，一般不能从源请求的 \((o_i,\ell_i)\) 恢复。本文不将它们解释为对任意未来 query 充分的压缩，也不据此声称跨 query 精确闭合。

## 3. 后果 slot 的语义与精确回答

真实后果 \(y\) 到达后，构造一条用于回答源请求的 hindsight 后果 K/V：

\[
\kappa_i(y)=W_K\eta_i(y),\qquad
\nu_i(y)=W_V\eta_i(y).
\]

本候选明确选择

\[
\eta_i(y)=N_A\!\left(
(1+s_A(c_i))\odot
N_1\!\left(\operatorname{input\_proj}(y+p_{j_i})\right)
+b_A(c_i)
\right).
\]

它使用**源请求已有的 slot 与实际动作条件**。后果来自该动作执行之后，反馈操作围绕这个已经发出的请求组织。这是新增的事后回答语义：

- 不假装宿主已经训练过完备的“未来后果输入接口”。
- 不使用训练长度之外的第 4 个位置编码；源 slot 来自已有原生位置。
- 不把后果 slot 当作真实时间的下一 token，因此不需要尚未发生的下一动作。
- 复用投影和张量形状不代表已有相应语义，这个角色必须由离线学习建立。

令 \(w_i(y)=\exp(q_i^\top\kappa_i(y)/\sqrt d)\)。同一源 query 在既有上下文加入该后果 K/V 后，回答为

\[
I_i(y)=\frac{Z_i o_i+w_i(y)\nu_i(y)}{Z_i+w_i(y)}.
\]

整理得到

\[
\boxed{
\alpha_i(y)=\operatorname{sigmoid}
\left(q_i^\top\kappa_i(y)/\sqrt d-\ell_i\right),\qquad
I_i(y)=o_i+\alpha_i(y)[\nu_i(y)-o_i].
}
\tag{1}
\]

式 (1) 是有限 attention 运算的精确结果，没有 Taylor 截断。它同时使用源请求、该请求当时的上下文竞争和后果内容。\(\alpha\) 是 attention 份额，**不是已经校准的可靠性概率或置信度**。

对固定源请求，\(I_i(y)\) 位于 \(o_i\) 与 \(\nu_i(y)\) 的线段上；后果权重趋于零时，回答回到 \(o_i\)。这些性质定义了允许怎样作答，不保证回答已经具有正确的世界模型修订作用。

### 3.1 一次回答修订包含哪两项变化

简记 \(\alpha_y=\alpha_i(y)\)、\(\alpha_{\hat y}=\alpha_i(\hat y)\)、\(\nu_y=\nu_i(y)\)、\(\nu_{\hat y}=\nu_i(\hat y)\)，则

\[
\boxed{
I_i(y)-I_i(\hat y)
=
\alpha_y(\nu_y-\nu_{\hat y})
+(\alpha_y-\alpha_{\hat y})(\nu_{\hat y}-o_i).
}
\tag{2}
\]

第一项是后果 value 内容的变化；第二项是同一个源请求下，后果相对于已有上下文所占份额的变化。第二项以“预测后果 value 与原回答的差”为作用方向。两项都是原生 attention 的有限运算，不是另加两条学习分支，也不是新的 attention 代数。

即使 \((y,\hat y)\) 完全相同，不同的源 \(q_i,o_i,\ell_i\) 也可以产生不同修订。因此它不再只是固定 \(\phi(y)-\phi(\hat y)\)。这项源条件依赖是本候选正面规定的计算角色；它是否有用仍需要相应学习和证据，不能由依赖存在本身推出。

## 4. 写入什么，什么关系仍沿用当前方法

数值运行定义为

\[
\Delta I_i=I_i(y_i)-I_i(\hat z_{i+1}),\qquad
\boxed{v_i^\star=r_i+\Delta I_i.}
\tag{3}
\]

两次回答使用同一份发出时的 \(q_i,o_i,\ell_i,c_i,j_i\)。不能在观察到达后重算源请求，替换为事后才形成的地址。

加回 \(r_i\) 的意义与当前方法一致：保存已有作用经后果修订后的目标，而非仅保存剩余误差。两个后果完全相同时 \(\Delta I_i=0\) 精确成立；反之不成立，后果编码可能无法区分某些 latent 差异。

永久 memory 仍只保存 \((q_i,v_i^\star)\)。本文没有改变当前的归一化 query 检索。无淘汰时，追加记录造成

\[
r_{M+i}(q)-r_M(q)
=\beta_i(q)[r_i-r_M(q)+\Delta I_i].
\tag{4}
\]

源 query 上退化为 \(\beta_i\Delta I_i\)，仍要求发出与兑现之间 memory 未改变。一般延迟必须保留 \(r_i-r_M(q_i)\)，不能用事后读取替换发出时的 \(r_i\)。真实写入、候选只读、最后 token 注入等运行语义沿用当前方法。

持续状态在两个实际后果到达事件之间满足 \(M(\tau)=M(\tau_i^+)\)。每个假想动作序列有自己的预测 latent 历史，所有序列都从同一已存在的 M 读取。在一个序列内，第 \(h\) 步随该步 query 重新读取同一份 M。用户强调的持续存在在此体现为跨请求保留的内部状态，以及其对后续每一步的直接作用。 无新观察的固定对照（原项目文件 `runs/query_feedback_20261112/intermediates/source_persistence/REPORT.md`）

## 5. 同属 value 空间不等于具有正确内部作用

固定当次原生上下文，记

\[
G_i(r)=\text{在原生接口送入 }o_i+r
\text{ 后，经同一 }W_O\text{、动作 gate 和后缀得到的 latent}.
\]

因此 \(\hat z_{i+1}=G_i(r_i)\)。\(G_i\) 包含原生残差流、历史 token 及全部非线性后缀，不是只取 \(W_O\) 的线性近似。

式 (3) 要具有反馈修订的意义，需要在相关可实现后果范围内学习

\[
G_i\!\left(r_i+I_i(y)-I_i(\hat z_{i+1})\right)\approx y.
\tag{5}
\]

式 (1) 本身没有证明式 (5)。这就是候选桥需要明确承担的学习任务。

### 5.1 恢复响应等价，而非逐坐标逆

512 维内部作用经 \(W_O\) 与非线性后缀映射到 192 维输出，一般不可唯一反演。对源条件定义

\[
u\sim_i u'\quad\Longleftrightarrow\quad
G_i(r_i+u)=G_i(r_i+u').
\]

这只是当前作用对象的等价定义，不是新的预测状态理论。反馈桥需要恢复相应的原生输出作用，不需要恢复任意选定的一组内部坐标。

因此不能把已知干预 \(u\) 当作唯一内部标签，要求读回的每个 head、每个坐标都复现它。那会惩罚等效内部实现，并把不可辨识自由度伪装成监督误差。

### 5.2 同一对后果需要相反作用的标量例子

考虑两个固定源请求，在各自已使用的读出附近，原生响应分别为 \(G_+(r_++u)=u\) 与 \(G_-(r_-+u)=-u\)。两者都从预测 0 修订到后果 1。精确恢复这项响应要求内部变化分别为 \(+1\) 与 \(-1\)。只依赖两端后果的固定特征差在两个请求中取相同值，因而无法同时满足这两个等式。

在单 head 标量 attention 例子中，共享后果 key 和 value，并取相同的源 query 与原生配分函数，使两个源都满足 \(\alpha(0)=1/2\)、\(\alpha(1)=2/3\)。这两项由后果相对原生配分函数的 logits 0 与 \(\log 2\) 产生。令 \(\nu(0)=0,\nu(1)=2\)。若两个原生回答为 \(o_+=2,o_-=14\)，则式 (2) 给出

\[
\Delta I_i=\tfrac{4}{3}-\tfrac{o_i}{6},\qquad
\Delta I_+=1,\quad \Delta I_-=-1.
\]

这对源请求的差异由已经形成的原生回答承载。只保留内容项会在两个源都给出 \(4/3\)，无法给出相反响应。该例只使用 attention 回答代数和给定的标量后缀，说明竞争份额项在一种源依赖任务中能表达什么。实际 LeWM 是否能学到对应关系，由固定原生响应实验和离线监督分别研究。

## 6. 以原生作用往返建立桥的含义

离线固定一次源运算，选一个预先规定的已知内部位移 \(u\)，实际调用同一原生后缀得到

\[
\bar y_i^u=G_i(\bar r_i+u),\qquad
\bar y_i^0=G_i(\bar r_i).
\]

这里横线表示该次校准案例固定的源作用和后果条件。读回

\[
\Delta I_i^u=I_i(\bar y_i^u)-I_i(\bar y_i^0),
\]

再将读回作用送回同一接口：

\[
\boxed{
\mathcal L_{\mathrm{return}}
=
\left\|G_i(\bar r_i+\Delta I_i^u)
-\operatorname{sg}\bar y_i^u\right\|^2.
}
\tag{6}
\]

该台阶中，生成 teacher 与重放响应算子 \(G_i\) 的源数值条件固定；读回函数 \(I_\theta\) 使用同一源输入形成的可导 \(q_i,o_i,\ell_i\)。两者数值来自同一次源计算，但梯度边界不同，不能把整份源缓存全部 detach。下节给出不需要第二个 model 的精确定义。它与后文未来主损失的完整状态求导也不同。

这是有限原生响应的往返关系。目标是已知内部干预真正产生的后果，不是新网络编造的内部最优标签；部署也不求解投影梯度、最小二乘或在线参数更新。

位移集合及来源应在实施前固定，不能看见结果后只保留容易复现的方向。无输出作用的位移单独记录，不能把它们当成功反演。本文尚未启动该学习。

### 6.1 该台阶训练什么

本候选在这项语义台阶中选择：固定原生 \(W_O\)、动作 gate 及预测后缀，由原生 Q/K/V 学习后果读回。需要明确区分两份用途不同的源量：

- **响应重放与 teacher 的固定条件。** 源真实 latent、动作以及实际已施加作用 \(\bar r_i=\operatorname{sg}r_i\) 固定；原生 attention 各 token 输出的数值副本固定。
- **读回函数的可导源条件。** 同一源前向形成的 \(q_i,o_i,\ell_i\) 保留计算图，供 \(I_\theta\) 使用；后果 K/V 分支也保留梯度。这里的源 latent 与动作是常量，不等于由它们计算的 Q/K/V 输出也停止梯度。

一个无需第二个 model 的精确响应定义如下。先调用现有原生 predictor，在首个 attention 的 \(W_O\) 之前、任何 memory 注入之前，捕获全部 token 的原生 head 拼接输出

\[
O_i\in\mathbb R^{T\times Hd},\qquad
\bar O_i=\operatorname{sg}O_i.
\]

源前向同时保留可导的 \(q_i,o_i,\ell_i\)；其中 \(o_i\) 是 \(O_i\) 的最后 token，**供读回使用的 \(o_i\) 不 detach**。重放仍调用同一个原生 model，在同一接口将全部 token 的原生 head 输出替换为 \(\bar O_i\)，然后只给最后 token 加入指定作用：

\[
O_{\mathrm{replay}}(w)=\bar O_i+e_{\mathrm{last}}w,\qquad
G_i(w)=\operatorname{HostForward}
\bigl(z_i,a_i;\ O\leftarrow O_{\mathrm{replay}}(w)\bigr).
\]

这里 \(e_{\mathrm{last}}w\) 表示仅最后 token 的 \(Hd\) 维增量。该次重放不再运行原 operator 的额外 memory 注入，避免把 \(\bar r_i\) 加两次；\(w\) 分别取 \(\bar r_i\)、\(\bar r_i+u\) 或 \(\bar r_i+\Delta I_i^u\)。

**必须替换全部 token 的原生 head 输出，而非只替换最后 token。** 否则历史 token 仍可能通过受训 Q/K/V 改变，经过后续 causal attention 产生绕过读回桥的直接参数梯度。

当前接入的是首个 attention：它以前的视觉输入、位置、动作条件和归一化都不含受训 Q/K/V 的依赖；\(W_O\) 和其余宿主权重又固定。因此上述重放对 Q/K/V 参数没有直接梯度，但对注入变量 \(w\) 有梯度。原生 Q/K/V 虽可能在重放调用中照常计算，其输出在该接口被固定数值替换，不参与 \(G_i\) 的参数求导。

teacher 生成通路及 \(\bar r_i\) 停止梯度；响应重放的 \(G_i(\bar r_i+\Delta I_i^u)\) 不包在全局 no-grad 中，否则会同时丢掉对 \(\Delta I_i^u\) 的必要导数。于是校准损失的参数路径为

\[
\nabla_\theta\mathcal L_{\mathrm{return}}
=
(D_\theta\Delta I_i^u)^\top
(D_wG_i)^\top
\nabla_{G_i}\mathcal L_{\mathrm{return}},
\]

其中 \(D_\theta\Delta I_i^u\) 包含可导源 \(q_i,o_i,\ell_i\) 和两侧后果 K/V 的依赖。若把这些源量也全部 detach，就不能再声称 Q 经源请求路径接受了校准监督。

这样读回要适应既定的内部作用坐标，而非同时改写 decoder、靠消除内部干预的作用降低往返损失。只对 decoder 参数停止梯度，不等于它在训练期间保持固定；此处选择这些权重本身不更新。

Q 决定请求；K 决定后果对该请求回答的份额；V 提供进入既定后缀的内容。它们是同一个原生 attention 的已有参数，不额外建立 inverse MLP。Q/K/V 仍会改变原生前向的相应部分，因此真实前缀的一步监督需要保留，往返训练不能取代世界预测训练。

每个新 batch 及参数更新后的源缓存由当时参数重新形成。每次校准案例固定 \(G_i\) 的数值条件，保留 \(I_\theta\) 源请求的学习通路。未来主损失走完整真实 operator，并按第 7 节对状态链完整求导。两条路径已通过原生梯度对照。 原始梯度记录（原项目文件 `runs/query_feedback_20261112/intermediates/source_gradients/REPORT.md`）

### 6.2 回答的局部梯度

对式 (1) 暂固定其他输入，令
\(s=q_i^\top\kappa_i(y)/\sqrt d-\ell_i\)，则

\[
\frac{\partial I_i}{\partial\nu_i}=\alpha_i\,\mathrm I,
\qquad
\frac{\partial I_i}{\partial s}
=\alpha_i(1-\alpha_i)(\nu_i-o_i).
\]

式 (6) 的梯度经固定源数值条件下的 \(G_i\) 回到读回作用，再进入这两条路径。供 \(I_\theta\) 使用的源 \(q_i,o_i,\ell_i\) 保留计算图，因此总梯度还包含它们与共享 Q/K/V 的其他依赖，不能把以上局部导数当全部学习过程。响应重放所用的 \(\bar O_i\) 则没有这条源参数梯度；两条用途必须分开。

真实未来监督是另一个必要用途：只有兑现 memory 被合法未来查询读取，其输出接受真实未来目标，才训练跨请求使用关系。原生干预往返只说明“内部作用怎样读回”，不说明世界预测已经准确，也不说明一次反馈已经会正确迁移到其他动作。

## 7. 数值递推、校准停目标与未来状态求导必须分开

当前 operator 在写入时对旧预测使用 stop-gradient。它不改变运行数值，却改变离线训练的导数，不能仅以“防止捷径”自动沿袭到新候选。

取一个说明性标量例子：

\[
G(r)=b+r,\qquad \phi(x)=x,\qquad
v=r+y-G(r)=y-b.
\]

数值函数对 \(r\) 的导数是零。但写成
\(v=r+y-\operatorname{sg}G(r)\) 后，autograd 返回的导数是 1。这是有偏替代梯度，不是同一数值递推的完整导数。

**本候选的未来主损失选择完整反向传播式 (3)：不在旧预测分支插入 stop-gradient。** 历史 \(q_i,r_i,I_i,\hat z_i\) 及其状态形成通路保留到合法未来损失的梯度；真实 latent 标签和固定 synthetic teacher 后果作为停止梯度的目标。

这项选择允许学习过程考虑“旧预测改变以后，后来写入的回答差也随之改变”的真实依赖。它不保证没有其他编码捷径，也不保证比有偏替代梯度更易优化；它首先明确我们正在训练哪一个实际数值递推。真实前缀的一步监督继续约束预测本身。

式 (6) 中固定 teacher 案例、停止 teacher 生成通路，是条件化逆学习的定义；未来主损失中是否切断跨状态依赖，是另一项训练定义。二者必须分别记录，不能共用一个含糊的 detach 开关。对整个回答 \(I_i\) 或整个 memory value detach，会连桥本身的学习也切掉。

固定梯度阶段用可解析例子区分完整导数与替代导数，并在实际事实兑现和后续查询中确认旧预测的梯度。 梯度阶段（原项目文件 `runs/query_feedback_20261112/intermediates/source_gradients/REPORT.md`）

## 8. 与 Difference Target Propagation 的确切关系

Difference Target Propagation 已有

\[
\hat h=h+g(\hat y)-g(y)
\]

这类差分目标及训练反向映射的重构思想。式 (3)、式 (6) 没有发明新的逆学习原理，也不能因为 inverse 用 attention 表达就宣称原创。[DTP 原文](https://arxiv.org/abs/1412.7525)；相关阅读范围见[当前方法稿](PREDICTION_QUERY_FEEDBACK_20261112.md#8-与已有计算的具体关系)。

候选的具体结构增量是：

1. 读回不是一个独立、任意的逆网络，而由实际 forward 已经发出的 query 及其 \((o_i,\ell_i)\) 确定。
2. 读回使用同一原生 K/V，把真实后果解释为该请求事后收到的回答；式 (2) 明确内容变化和源条件竞争份额变化的作用。
3. 回答变化经真实兑现后保存，后续世界模型请求通过原生接口使用；离线仍用普通反向传播训练其用途。

这是整体计算结构的候选差异，不是原创基础算子。如果源请求与原生上下文的绑定没有独立作用，应按一种条件 inverse 反馈记忆解释，不能靠“原生”、后验术语或重构损失升级贡献。

## 9. 两类坐标界限

### 9.1 后果编码与后缀不保证完整可逆

后果 slot 若使用上述原生 LayerNorm 链，信息盲区仍然存在。当前 input projection 为恒等时，给 \(y\) 全部坐标加同一常数会被第一处 LayerNorm 消去；后续 K/V 无法恢复这项变化。源动作与上下文条件化不会自动修复它。

此外，\((q_i,o_i,\ell_i,c_i,j_i)\) 对固定 query 的 attention 增补充分，不等于它对整个 \(G_i\) 充分。不同原生上下文仍可能需要不同的后果逆作用。式 (6) 是所选作用域上的学习要求，不是全 latent、全上下文的右逆定理。

### 9.2 原生 Q/K 对偶变换与 Q·Q memory 度量不同

对一个 head 采用列向量记法。任意可逆矩阵 \(A\) 下，令

\[
q'=Aq,\qquad k'=A^{-\top}k.
\]

则

\[
q'^\top k'=q^\top k.
\]

在 V 不变时，原生 attention 的 logits、\(o_i\)、\(Z_i\) 均保持不变。若后果 K 同样对偶变换，\(q_i^\top\kappa_i(y)\) 也保持，式 (1) 的后果回答不变。

但当前永久 memory 使用 \(q^\top q_i\)，该量变为

\[
q'^\top q_i'=q^\top A^\top A q_i,
\]

一般不保持。正交变换等特殊情形才保持原点积。因此原生预测函数没有唯一确定 Q·Q 的记忆度量；它是方法另外施加、需要未来用途训练的结构。

**新桥在原生 Q/K 对偶坐标下成立，并未自动修好 Q·Q 检索的坐标问题。** 不能把式 (1) 的性质外推为整个 memory 机制的重参数化不变性；本文也没有另加度量模块掩盖这个界限。

## 10. 固定中间台阶

已形成的四级中间变量作为同一实现的参照。源读回复用固定请求和干预，按原生 attention 数值对照、响应重放、梯度路径和离线学习顺序推进。 [中间变量协议](QUERY_FEEDBACK_INTERMEDIATES_20261112.md)

### 台阶一：已知内部作用经原生计算产生了什么

固定源上下文、注入接口和 \(r_i\)，给定预先规定的 \(u\)，记录

\[
e_i^u=G_i(r_i+u)-G_i(r_i).
\]

保存内部位移和完整响应向量，区分无下游作用与有下游作用的干预。它回答内部变量控制了哪项原生响应，不是模型能否预测真实轨迹更准。

### 台阶二：后果被怎样读回

将 \(y_i^u\) 和原预测分别送入桥。当前 operator 记录固定 \(\phi\) 特征差；若以后实施本文候选，则记录

\[
q_i,o_i,\ell_i,\alpha_y,\alpha_{\hat y},\nu_y,\nu_{\hat y},
\]

以及两个有限分解项

\[
\Delta_{\mathrm{content},i}=\alpha_y(\nu_y-\nu_{\hat y}),\qquad
\Delta_{\mathrm{share},i}=(\alpha_y-\alpha_{\hat y})(\nu_{\hat y}-o_i),
\qquad \Delta I_i=\Delta_{\mathrm{content},i}+\Delta_{\mathrm{share},i}.
\]

需要明确：使用的是发出时的源量；两侧使用同一个反馈定义；固定源 q 的充分统计没有被误用为另一个 q 的统计；同一对后果在不同源请求下如何改变内容项与份额项。份额变化不能直接被解释为可靠性概率。

### 台阶三：读回量是否复现同一原生作用

将读回量放回同一 \(G_i\)，比较

\[
\hat e_i^u=G_i(r_i+\Delta I_i^u)-G_i(r_i)
\]

与 \(e_i^u\) 的完整响应。可以报告

\[
\rho_i=\frac{\|\hat e_i^u-e_i^u\|}{\|e_i^u\|},
\]

同时保留分子、分母和响应向量。分母为零时单列为无作用干预，不能算成功反演。不同 \(u\) 若产生相同后果，只要求输出作用等价，不追求唯一内部标签。

这三层是“已知内部干预—后果—读回—原生响应”的承接，独立于最终任务成功率和长轨迹平均 MSE。另有第 7 节规定的中间梯度阶段，区分固定 teacher 校准与未来主损失完整求导；不能把数值往返成立等同于梯度定义正确。

上述语义明确以后，才研究兑现记录在另一个 query 中的读取及动作条件后缀作用，随后才进入自由多步预测。跨请求、跨时域能力不能由源请求往返直接承接。
