# 预测请求的延迟兑现：原生 attention 内部反馈方法稿

2026-11-12。本文先确定计算设计及其学习方式，再实现对应机制。不是从三档增益实验的涨跌选择新公式，也没有要求未经训练的构造先获得预测收益。持续 goal 未完成，以下是一个完整、可实现的候选，尚未确立论文级新颖性或效果。

## 1. 一个组织整个方法的计算选择

**让原生预测发出的 query 同时成为该次预测的反馈地址。真实后果到达后，修订这次预测实际使用的内部作用；后续预测通过同一原生 query 路径调用这些已经兑现的作用。**

原生世界模型仍负责产生动作条件预测，规划器仍选择动作。新增运行对象不保存整段图像或所有候选未来，而保存“哪个预测请求，已经得到怎样的内部反馈目标”。它在 attention 的 value 输出位置参与计算，不另外预测 latent，也不直接选择行动。

这一选择同时决定了地址从哪里来、何时可以写入、写入什么、下一次在哪里读取，以及离线训练应当优化哪条链。softmax、关联记忆和差分目标都不是本文发明；候选贡献只能落在这次对原生预测计算角色的具体改变及其学习用途，不能靠名称取得。

五篇方法笔记在这里提供的是组织方式：一次明确设计决定其余环节的职责；训练参与建立能力；部署使用训练所塑造的同一计算。没有移植它们的 Hamiltonian、分层、扩散或插值方案，也不将论文的缺陷叙事作为本构造的发现程序。

## 2. 精确接入 LeWM 的哪个运算

当前实际宿主为 ARPredictor、四个 ConditionalBlock、原生 predictor projector。选第一个 attention。动作已经通过该 block 的 AdaLN 参与 query/key/value 形成：

\[
u=N_A\big((1+s_A(c))\odot N_1(x)+b_A(c)\big),
\quad q=W_Q u,\ k=W_Ku,\ v=W_Vu.
\]

这里有两次 LayerNorm，不能省略；当前 checkpoint 为 8 个 head，每 head 64 维。原生 attention 结果为 o，经过原生 W_O、动作 gate、MLP 及剩余 predictor 后形成预测。

仅对当前待预测的最后一个 token，把每个 head 的输出从 o 改为

\[
\boxed{o^+=o+r(q,M).}
\tag{1}
\]

之后继续原有 W_O、动作 gate 及全部下游计算。历史 token 不注入这次记忆，不给它们使用后来才到达的反馈。训练也只监督这次当前 token 对应的未来。整个原生 model.predict 仍被实际调用，不复制 attention、Transformer 或输出头。

## 3. 工作对象及读取

每个 episode 持有已兑现记录 M={(q_i,v_i)}。q_i 是实际发出预测时形成的 query；v_i 是该次实际内部作用经真实后果修订后的目标。每个 head 分别读取：

\[
r(q,M)=\frac{\sum_i\exp(q^\top q_i/\sqrt d)\,v_i}
{1+\sum_i\exp(q^\top q_i/\sqrt d)},\qquad d=64.
\tag{2}
\]

分母中的 1 是固定零 key、零 value 所贡献的项；空态得到精确的零读取。于是空态返回同一组当前参数下的原生 predictor，不是保证离线训练后仍等于最初 checkpoint。

q·q_i 是有意重新定义的共享请求度量，不是原生 q·k。两个向量维度相同不意味着原预训练已赋予这种语义。离线真实未来将训练：哪些请求能够借用彼此的内部反馈。

**代码语义补充。** 当前取的是首块、attention 聚合之前的最后 token query；固定真实输入时，它仅依赖当前 latent、动作与位置，尚未整合之前 token 的历史，也不依赖 M。原生 attention 回答与后续 block 才完成进一步上下文整合，不能把这个 query 描述成完整预测活动的摘要。精确因果展开见代数补充（原项目文件 `QUERY_FEEDBACK_ALGEBRA_20261112.md`）。

运行容量固定为最近 64 个真实转移，FP32 的 key/value 合计每条轨迹 256 KiB；这是显式空间上限，不是学习出的遗忘或长期稳定性机制。默认 64，不以开发分数调容量。阶段仅研究满容量边界的写入行为。淘汰最旧记录会产生额外作用，不能继续套用无淘汰时的恒等式。

## 4. 真实后果修订的对象

实际预测发出时，保留

\[
\Pi_i=(q_i,r_i,\hat z_{i+1}),\qquad r_i=r(q_i,M_i).
\]

这只是待兑现记录，尚未入库。只有对应实际动作执行完毕、真实 y=z_{i+1} 到达之后，才写入

\[
\boxed{v_i=r_i+\phi_\theta(y)-\phi_\theta(\operatorname{sg}\hat z_{i+1}).}
\tag{3}
\]

其中 phi 是已有首块在固定参考条件下的 value 特征：给输入 z 加原生 p0，使用经官方 normalizer 与 action embedder 得到的物理零动作条件，经过该块原有两次归一化，再调用原有 W_V。它只规定一个一致的反馈特征坐标，不把未来动作或隐藏真值送进写入。

phi 不是原生预测后缀的已知逆映射，也不是 W_V 直接乘最终残差；两次独立的非线性特征计算不能被省成 phi(y−z_hat)。其数值含义需要与实际下游作用共同训练。

**加回 r_i 是计算语义所必需的。** 写入目标是“今后可用的完整内部作用”，而当前预测误差只表示“已用作用之后还剩什么”。在简单线性桥精确的例子中，需要补偿 b、已经使用 r_i 时，剩余误差为 b−r_i，故新目标 r_i+(b−r_i)=b。只记剩余误差，会把成功补偿后的零误差误读成以后应该撤销原补偿。这个例子解释目标对象，不是 LeWM 的正确性定理。

部署参数固定，仅 M 变化。sg 只用于离线求导：它截断通过故意改变旧预测数值而改变反馈差的直接梯度通路，不保证排除所有潜在编码捷径。训练仍监督真实前缀的一步预测，未来用途也监督同一 predictor。

这个截断也使未来损失使用的梯度成为特定替代梯度，不等于对全部前向数值递推作普通微分。比如 G(r)=b+r、phi 为恒等映射时，前向 v=r+y−G(r)=y−b 对 r 的导数为 0，代码经 sg(G(r)) 得到的导数却为 1。不能把接口测试中“梯度非零”解释成正确恢复了实际扰动响应。后续按固定中间台阶单独处理这个训练定义，不从上一轮分数决定保留或移除 sg。

## 5. 一次真实反馈怎样改变其他动作和时域

记某查询当前读出为 r_M(q)，新记录的相对权重为

\[
\beta_i(q)=\frac{\exp(q^\top q_i/\sqrt d)}
{1+\sum_{j\in M}\exp(q^\top q_j/\sqrt d)+\exp(q^\top q_i/\sqrt d)}.
\]

无淘汰时由分式直接得到精确关系

\[
\boxed{r_{M+i}(q)-r_M(q)
=\beta_i(q)[r_i-r_M(q)+\delta_i],\quad
\delta_i=\phi(z_{i+1})-\phi(\hat z_{i+1}).}
\tag{4}
\]

标准运行采用单个已执行、待兑现预测的顺序协议；发出与接收之间 M 不变。在同一源 query 上，此时 r_M(q_i)=r_i，因而变化为 beta_i delta_i。若真实结果与预测一致，delta_i=0，该源请求的有效内部作用保持不变。这个性质不要求 phi 是精确逆。

反向推论不成立：phi 含 LayerNorm，可能把不同 latent 映为相同反馈特征。例如第一处 LayerNorm 消去所有坐标的共同平移，此方向不能靠随后训练 W_V 恢复。因此 delta_i=0 不证明预测正确，只说明该反馈特征未区分两者。式 (4) 对各 head 分别成立，各 head 有自己的 beta。

**两个限定不能省略。** 第一，其他 query 即使 delta_i=0 也可能因 r_i−r_M(q) 而改变，这是对内部作用的重新分配；不能宣称所有预测不变。第二，若有延迟且期间其他记录已写入，源 query 上也保留 r_i−r_current(q_i) 项；必须使用发出时的 r_i，不能事后重算以制造上述简化。容量淘汰另有删除项。

后续动作 b 改变原生 q、动作 gate 和非线性后缀。设 G_b 为从此 attention 位置到最终 latent 的原生剩余计算，那么实际输出变化是

\[
G_b(o_b+r_M(q_b)+\Delta r_b)-G_b(o_b+r_M(q_b)).
\tag{5}
\]

这是有限原生计算的差，不执行投影梯度或 Jacobian 反馈。不同动作既可读到不同内部作用，也可通过不同 gate/后缀使用同一个作用。

多时域使用同一个 M，按原生步长连续预测。每一步的预测输入和 query 都随所想象的动作与状态变化；不额外训练 horizon 头，不给整段轨迹选一个恒定增益。多步关联来自同一预测映射的组合，尚不提供宏步、时间抽象或净加速。

## 6. 真实观察、行动分支和两个时间阶段

一段实际运行按如下顺序执行：

1. 由已到达观察与已执行动作组成原生短窗口；M 只含此前已兑现反馈。
2. 对候选动作展开预测。每个候选从相同窗口与 M 出发，全部只读 M。
3. 选定并实际执行一个动作块；保存该次预测的 Pi。不能把其他候选的预测终点当真值写入。
4. 对应真实观察到达后，用式 (3) 形成记录，并正常更新原生真实观察窗口。
5. 后续预测读取更新后的 M。真实起点刷新与内部反馈写入是两个清楚的操作。

没有观察时可以继续查询，但不能凭内部输出增加真实证据。一个候选的想象步不会改变其他候选或公共状态。该构造延续的是已经完成、经真实后果修订的计算内容，不声称自主振荡、在线权重学习或存储完整经历。

## 7. 训练是方法的一部分

冻结视觉 encoder、动作 embedder、所有归一化统计及其余 predictor；离线更新首个原生 attention 的 qkv Linear 与输出 Linear。共 393,408 个原生参数，没有新预测网络。部署时这些参数固定。使用 eval 模式关闭宿主 dropout、固定 BN，梯度仍穿过被冻结的下游运算。

每个训练片段以空态启动，按真实时间依次执行“发出预测—接收下一观察—写入”。真实前缀的一步预测以及从合法前缀启动的自由后缀预测，统一接受冻结 encoder 的真实未来目标：

\[
\mathcal L=\operatorname{mean}_{(t,h)\in\mathcal Q}
\|\hat z_{t+h}(M_t)-\operatorname{sg}E(o_{t+h})\|^2.
\tag{6}
\]

Q 包含真实前缀的一步调用与后缀的 h=1,2,4,8；后缀内部不使用真实未来写入 M。不生成“最佳调节”伪标签，不以历史拟合误差直接选择调节器。每次参数更新后重建片段状态，不能沿用上一次参数坐标下的缓存。

读取的学习关系可以精确展开。对一个 head，令 alpha_i 是含零值地址的 softmax 权重，s_i=q·q_i/sqrt(d)，g_r 为真实后缀损失经过原生下游传回该次读取的导数，则

\[
\frac{\partial\mathcal L}{\partial s_i}
=\alpha_i\,g_r^\top(v_i-r).
\tag{7}
\]

因此，地址分数直接接受所存内部作用对未来预测是否有用的监督；这不保证最终学到的相似性完全对应这种用途。式 (7) 是固定其他输入时的局部偏导，共享参数的总梯度还包含其他路径。梯度同时经过 v_i 中已用的 r_i、phi 的两个分支和历史 q_i，塑造反馈形成与后来使用之间的关系。式 (7) 是标准 attention 求导，不作为新定理。

直接的记忆地址梯度作用于 W_Q；W_K 仍属于原生 q·k 路径，不直接参与新记忆地址。T1 原生只有一个 key 时，K 的这条梯度为零；T3 可有非零梯度。训练合并的 qkv 权重不意味着三块参数都由记忆读取直接监督。

这一学习依赖真实动作覆盖，不能保证未见动作或任意长时域的正确迁移。原生 q 和 phi 的预训练语义不足以替代这项训练，因此本方法不会以冻结权重加随机记忆的预测分数作为是否值得构造的裁判。

## 8. 与已有计算的具体关系

| 参照 | 相同或已有部分 | 本候选实际改变的部分 |
|---|---|---|
| 普通递归/长上下文 | 都让后续计算使用历史 | 状态为已兑现的原生预测请求及其内部作用目标；形成、读取不交给独立自由 RNN |
| 输出反馈 observer | 都使用实际预测误差 | 反馈修订已施加的内部作用，随后由动作条件 query 与原生后缀使用，不给所有候选加同一输出残差 |
| 线性化适配/投影梯度 | 局部都可写成误差迁移 | 部署不求导、不改参数；执行有限特征差、存储和原生 attention；线性极限仍可能退化为残差核回归 |
| Difference Target Propagation | 式 (3) 的差分目标形式已有 | 不用层级目标来替代参数反传；将一个已执行预测的内部作用目标留给后续世界模型查询，离线仍用反传 |
| EMWM / FAR | 世界模型的经历检索、未来用途训练均已有 | 不检索历史图像或替代整条状态转移；预测时的原生 query 是兑现地址，值为已用内部作用的后果修订，复用同一 attention 的输出路径 |
| H-JEPA / 多时域 predictor | 都研究较远未来 | 本候选仍用原生一步模型；不学习独立尺度坐标或宏步，不借用它们的长跨度加速主张 |

接近工作已作定向原文阅读：[Difference Target Propagation](https://arxiv.org/abs/1412.7525)及[递归版本的式 (6)](https://jmlr.org/papers/volume21/18-141/18-141.pdf)；[EMWM 方法 §3](https://memari-workshop.github.io/papers/paper_3.pdf)；[FAR 正文 §3 与相关工作](https://arxiv.org/html/2609.34677)。这里只比较方法接口和计算对象，没有声称完整复现或穷尽相关文献。

若把原生后缀设为线性、反馈桥设为其精确逆，本候选可退化为学习核上的残差回归。这是明确包含的已有情形。需要建立的贡献是原生动作条件计算中的反馈目标形成、跨请求调用与真实未来学习这条具体关系具有独立作用；“内部”“不更新参数”及单行差分式各自都不够。

## 9. 实现和阶段安排

继续沿 research/p1a/native_response.py 的原生调用入口实现，不另建 world model。旧静态增益类仅供已经归档的阶段重放；当前新接口明确接收 M，返回预测及待兑现记录，真实观察操作返回更新后的 M。旧的一个 gain 参数不可能表达一组随请求读取、由真实后果兑现的作用目标，因此替换当前运行接口，而不是用兼容参数掩盖机制变化。

通过原生 to_qkv 的输出捕获 q，在原生 to_out 的输入加入 r；其余 model.predict 原样执行。只在原生 value 坐标添加反馈，不重复执行完整 predictor。每次真实写入需额外两次轻量 phi 特征计算；每次查询需与最多 64 条记录计算相似度及加权和。T3 时仅最后 token读取，因此满容量约 2×64×512=65,536 个乘加量，另有 softmax；不是 FLOPs 完整计数。未来仍按原生步长展开。

先实现方法已规定的性质：空态原生一致、写入的时间顺序、想象只读、顺序兑现的源请求固定点、有限延迟的一般式、容量边界和未来梯度通路。本次随后进行的小型离线学习按预定协议比较同参数清空/错配状态，以及相同参数范围和监督次数的原生微调；两臂计算量不同。普通历史 KV、输出残差检索仍是尚未实施的参照，不能提前承接其比较结论。实验研究这个预先写明的设计，不用各项涨跌反选新的数学对象。

计算链、训练链与已有边界先于实验写定。现已实现原生入口并完成接口与固定学习阶段（原项目文件 `runs/query_feedback_20261112/RESULTS.md`）：运算性质和梯度通路成立，拟合集能够学习使用状态，但本次开发留出没有收益。没有继续调参，也未主张精度、稳定性或论文创新已经成立。后续方法工作继续区分整条绑定的具体作用与已知差分目标/核读取，不从本次分数反选新对象。
