# 固定的中间变量台阶：预测 query 反馈

2026-11-12。在新增测试运行之前确定。用户明确要求稳定的中途变量测试；本轮沿已经实现的同一 operator 逐级展开，不启动训练、自由 rollout、轨迹 MSE 或最终任务。

这里“稳定”指对象、输入和比较口径固定，并不预先保证状态动态稳定。接口正确、变量有变化、变量有用分别是不同结论。实验研究这份已写明的构造，不通过数据分布反找下一核心机制。

## 固定对象和输入

使用全部 50 条既有 P0b 轨迹，只读取 z_0..z_6 和已执行 a_0..a_5（环境步 0..30）。两组参数固定为原始 checkpoint 和上一固定学习阶段最终的 query_feedback 参数。不开新优化器，不选择其他 epoch。各自从空态重放六个已完成真实转移；不使用自由预测替代后续真实输入。

当前代码的首块 query 在 attention 聚合与记忆注入之前产生。因而固定真实输入时，它只依赖当前 token 的 latent、动作和位置，不包含此前 token 已被 attention 整合后的结果，也不读取 M。把它称为“完整预测上下文的摘要”是不准确的。实际历史作用需要分别观察原生 attention 输出和反馈 value，不能从 query 名称推定。

原生接口调用及模型计算保持在 `research/p1a/native_response.py`。测试仪器可以用只读 hook 取得原有中间量；不得重写一个替代 predictor 来获得更容易通过的结果。运行接口阶段已有的空态、源请求兑现及梯度连通记录作为第 0 级，后续不以非零梯度直接跳到预测性能。

## 第 1 级：真实写入形成了什么

对每个 episode、每个真实转移 i、每个 head，固定保存：

- q_i：发出时的原生 query。
- r_i：发出时实际读取的内部作用。
- phi_actual、phi_predicted 和 delta_i = phi_actual − phi_predicted。
- v_i = r_i + delta_i：写入的完整内部作用目标。
- 读取旧记录的 alpha_i（含零地址）、累计下三角权重 L，以及最新 memory 的全部 q/v。

先确认这些量逐项对应实际 `predict/observe`：真实后继到达以前不能写入，写入后恰好多一条；记录实际作用与创新分量，不能只记 v 的范数。

对于固定参数和顺序兑现，在每个 head 内有精确条件展开：

\[
V=LV+\Delta,\qquad V=(I-L)^{-1}\Delta.
\]

L 严格下三角，只用于展开已经形成的计算；不把整个 predictor 说成线性系统。实际 delta 仍依赖含 r_i 的预测。记录逐样本数值差，使用 FP32 运算精度判断是否实现了所写代数。完整推导见 代数补充（原项目文件 `QUERY_FEEDBACK_ALGEBRA_20261112.md`）。

这一级回答值如何形成、旧作用继承了多少，不回答它对世界预测是否正确。全部 50 条均保留，不按有利样本筛选。

## 第 2 级：同观察下，不同动作怎样读取

输入固定为各 episode 的真实 z_4,z_5,z_6 及已执行 a_4,a_5。候选当前动作使用已有 `runs/p1a_v1/development/branches.npz` 第 0 个 root 的 32 个候选的第一个动作块；通过当前官方 normalizer 和 action embedding。这里只使用这些动作块，不读取候选未来图像、真实分支终点或其后动作。

32 个完整行动程序的首块有重复，不能冒称 32 个不同即时动作。保存候选 ID、名称、原始首块和等价分组：首块相同、当前观察相同的查询，其本次 q、alpha、r 必须相同，未来转弯安排不能提前影响本次计算。

固定保存当前 q、各历史地址分数、包含零地址的 alpha、null 权重、读取 r，以及两项追加作用分解。以第 6 条反馈的发出读出 r_5 和创新 delta_5 为例：

\[
r_{M_6}(q)-r_{M_5}(q)
=\beta_5(q)\,[r_5-r_{M_5}(q)]+\beta_5(q)\delta_5.
\]

逐 head、逐候选记录两个右侧项和真实左侧变化。地址范数、夹角、权重熵只描述检索行为，不能由其大小宣布“理解了动作”或“正确共享反馈”。

另保留一个明确标记的合成依赖对照：替换当前窗口前两个 token，保持最后 token、当前位置索引及当前动作不变。首块最后 query 应不变；原生 attention 的回答可以改变。这不是一段真实世界经历，不能写入公共记忆；它用来落实 query 和已整合上下文的回答是两个不同中间对象。

在第 2 级运行之前进一步固定位置对照：对同一个 z_6 和同一个已有候选 `constant_0` 的动作首块，分别提供 T1/T2/T3 原生窗口，并读取同一 M_6。当前 query 形成是逐 token 的，三种窗口的最后 query 输入仅位置 p_0/p_1/p_2 不同，因此它们的差异可用于隔离地址对位置的依赖；不能把原生完整 attention 回答的差异也全部归因于位置。保存三组 q、分数、alpha 和读出，连同每条记忆的发出 slot，不设置有利阈值。这个对照解释 query 的既有定义，不改变方法、数据或训练目标。

第 1 级记录及实际代数含义先读完，再运行第 2 级。不能把第 2 级的权重变化直接当成后续预测有效。

## 第 3 级：读取量经过哪个原生运算产生作用

保持第 2 级相同上下文和候选首块，分别读取 M_5 与 M_6。通过原生 hook 固定保存以下链条：

1. attention 的原生 head 输出 o；
2. 反馈读取 r 和 o+r；
3. 原生输出投影 W_O 后的结果；
4. 动作 gate；
5. attention 残差完成、进入首块 norm2 之前的值；
6. 首块 MLP 完成后的 block 输出。

记两种 memory 下读出之差为 Delta r，则 attention 残差处的差应为

\[
\Delta x_{attn}=g(a)\odot W_O\Delta r.
\]

偏置在作差中抵消，不能重复加进 W_O Delta r。接着记录 MLP 之后的实际有限变化；不把一个 gate 的绝对值当成最终响应方向。各级范数、夹角和完整向量都保留，零响应的夹角记为未定义，不能添加 epsilon 后伪造方向。

动作比较沿用第二级的 16 个不同首块及其 120 个动作对。令 \(p_a=W_O\Delta r_a\)、\(x_a=g_a\odot p_a\)，分别用动作对中点 \(\bar g=(g_b+g_a)/2\) 和 \(\bar p=(p_b+p_a)/2\) 作精确分解：

\[
x_b-x_a=\bar g\odot(p_b-p_a)+(g_b-g_a)\odot\bar p.
\]

第一项衡量不同动作读回的投影差，第二项衡量同一位置上的动作门差。对每个 episode 和动作对保留计算向量或其直接重建量，并报告两项范数和合成后的范数。该分解针对加入第六条记录在首块 attention 残差处的作用。

第 2 级完成并解释后才运行第 3 级。该级只确认“哪一个计算环节用了什么”，没有真实未来质量、候选排序或任务成功结论。

## 第 4 级：已知内部作用的响应复现

第三级完成并读完记录后，才运行以下事先写定的局部响应实验。它给原生内部位置一个已知有限干预，再用当前的固定参考特征差读回干预造成的后果，测读回量能否产生相应的原生作用。模型生成的后果标为局部计算参照，运行状态只使用先前形成的真实记录。

1. 两个既有参数快照都用全部 50 个 episode 在环境步 25 发出的第六个真实请求。固定窗口 z3:z6、动作 a3:a6 和 M5，重发时比较保存的 q、r 和输出。用原生 `to_out` 前置 hook 捕获注入前的全部 token 输出 O。在相同 host、窗口和动作的响应重放中，替换 `to_out` 的输入为固定 O 加上最后 token 的指定作用 w。重放 G(r) 应复现已发出的预测。
2. 在运行前取原始输出投影矩阵第一行的单位向量 u。取两个快照的输出投影矩阵竖向拼接，对其转置作 CPU FP64 完整 QR，以最后一列单位向量作公共零空间方向 n。固定干预为 0、+u、−u、n、u+n，两个快照使用同一组向量。FP64 投影和 FP32 实际响应分别记录。n 与 0、u+n 与 u 构成内部向量不同而原生投影相同的两组对照，其小数值差用原始记录呈现。
3. 对每个干预计算参考后果 y_u=G(r+u)，取当前实际 `feedback_features(y_u)−feedback_features(G(r))`，重放 G(r+δ)。保存干预向量、投影差、动作门后的差、首块输出差、完整末端响应、两个特征及其差。比较重放响应与已知干预响应的范数、方向和差向量。相对差和夹角仅在相应响应大于该请求的零空间数值差及基准复现差时定义。原始向量和绝对差保留在所有样本中。

中间状态的等价性由原生计算的实际响应体现。该实验评价固定参考特征差所产生的作用。后果不对应真实未来标签，所有调用停在同一个固定请求的局部响应。

后续候选在同样的请求、干预和响应比较上增加源 attention 读回量。先用显式增加一条 K/V 的同一 query 回答对照解析公式，再记录后果内容项、竞争份额项以及通过原生后缀的响应。源历史替换只研究同一对后果如何改变读回，保留原参考后果的来源。完整候选公式与学习路径见 [源请求条件化的后果读回](SOURCE_CONDITIONED_ATTENTION_FEEDBACK_20261112.md)。

训练链还需要区分自动求导与数值响应：当前 sg(predicted) 会切断反馈创新经旧预测的导数，却不消除前向数值依赖。非零梯度不等于完整前向递推的精确导数。这个问题先由公式说明，再采用固定中间变量测试，不直接启动下一次微调。

第 4 级保留两个参数快照的固定公式。若后续构造改变反馈形成量，使用同一响应比较，并在记录中标明变量的新定义。

## 第 5 级 源请求读回与显式增补 attention

复用第 4 级归档的两个参数快照、50 个请求、M5 和五个干预。M5 来自旧桥的真实写入，作为两种反馈形成量的共同输入。每次用原生 Q/K/V 和 `to_out` 输入记录发出时的最后 query、上下文 log 配分函数和回答。分别把后果代入同 slot 和同动作条件，比较实际首块 K/V 与候选代码的后果 K/V。再对固定源 query 运行显式增补 K/V 的单 query attention，比较解析式和两个修订分项。

重放通过同一个原生预测后缀。保存原生参考响应、读回复现向量、两个修订项及其范数和角度。报告完整原始样本、两组快照和归档固定特征差的配对差值。固定后果的历史对照沿用第 2 级的跨 episode 前两对 (z,a) 置换，末项和原后果对保持相同。该对照测源上下文的作用，局部干预的参考后果仍归属于原请求。

另用实际到达的 z6 兑现一次。在同一后续真实窗口和实际 a6 下对照写入前后读出，检验第六条记录的追加公式。这个对照的前五条记录来自旧桥，只有新增记录使用源条件化反馈。

## 第 6 级 原生响应和事实状态的梯度

先用标量例子区分完整数值递推与停旧预测的导数，再用原始快照的 episode 0、1 记录两条不同的梯度路径。第一条使用第 4 级的固定 +u，固定全部 token 的原生输出和 teacher，检查重放自身到 QKV 的直接边以及读回复现经源统计量和后果 K/V 的间接边。第二条对真实 z6 作一次兑现，由实际后续请求预测 z7，检查真实未来损失能否沿旧预测、兑现和后续读取回传。数值相同的停旧预测对照保持其他发出量的梯度，单独区分被切断的路径。所有参数值在此级保持固定。

## 第 7 级 无新观察时的持续状态

沿原始固定参数从空态开始，用全部 50 个 episode 的前六个真实视觉—行动转移形成源读回 M6。随后的两种已定行动程序取既有第 0 个 root 的 `stop` 与 `constant_0` 的前四个动作块。预测从共同的真实 z4、z5、z6 开始。每个程序中的后续请求只使用各自预测出的 latent 和给定动作。M6 在这些预测期间保持同一份状态，各预测完成后仍可继续读取。实际后果的更新与无新观察的预测使用分别对应追加和恒等状态变换。

在 H=1、2、4 记录两种差异。完整 M6 分支相对从同一起点全程清空状态的分支给出累计差。同一个完整分支的当前 latent 窗口分别有状态和清空状态调用，给出该时刻的直接差。直接差使历史预测改变导致的传播效应与本次持续状态读取的作用可分别观察。保存预测、query、读出、状态内容及读取前后的逐元素关系。时域调用期间只有两种程序的给定动作和各自预测历史进入 native predictor。这一级测持续作用的实际计算，效果判定使用后续固定真实后果实验。
