# PRBD Phase 1 · 同一真实轨迹上的原生响应容量与观测核对照

本报告记录 Phase 1 结束时的设计和结论。后续无标签训练及独立切换结果见[Phase 2 实测报告](../prbd_phase2_20261121/REPORT.md)。

2026-11-21。研究问题是，已知 TwoRoom 的动力学条件时，原生预测器究竟能生成多大的、方向正确的跨动作差异；固定这些预测，只换似然时，一次真实到达又会给出怎样的证据。这两项使用不同的信息权限。容量诊断可以读取真速度。观测核对照只读取已经签发的均值、实际后继和旧支持。

## 1. 先复核三个历史前提

* 在回合内条件固定、转移为恒等、H1 签发密度独立于先验且支持保留计算图时，整轨边缘似然与逐次预测似然乘积相等。已存数值检查的损失差为 \(1.11\times10^{-16}\)，梯度最大绝对差为 \(1.39\times10^{-16}\)。旧 G3 采用整回合目标本身不构成漏掉 H1 梯度的证据。
* 旧 G3 主臂在开发种子 2026112128 的慢速实际返回处，有 \(\max_k\|b_k\|_2=1.9029217\)，其中 \(b_k=L^{-1}(f_k-\bar f)\)。这是该步四列的最大范数。该模型全部开发 H1 因子记录的最大值为 11.9446。
* 在 39 个同窗且具有物理差的开发根，对每个根、跨度固定四个真实发出的未来。令 \(Y_k\) 为同一原型的移动减停止，\(d\) 为真实慢、快条件各自动停之差的差。每个速度可用任何概率向量，但对移动与停止共用它。准确的事后最大有向分子为 \(\max_kY_k^\top d-\min_kY_k^\top d\)。它允许读取真实未来。按根合计分子再除以 \(\sum\|d\|^2\)，旧主模型 H1/H4 为 **2.08275% / 1.53975%**，旧 H1 对照为 **2.03595% / 1.69617%**。这些是特定检查点的潜表示投影界。物理坐标需要另行评分。

## 2. 已固定的实验设计

训练输入复用既有 64 个重置中完成的 62 条实际轨迹。对每条轨迹，取有三帧真实历史、且有完整四块后继的 11 个起点。共 682 个起点，慢速 330、快速 352。A 为宿主冻结时的 3 × 6 × 192 个条件偏移。B 在相同入口增加秩 4 动作调制并联合学习最后两块，通过同窗同动作的有条件/零条件原生计算差保住名义宿主。两臂均移除零命令特化。固定分支 0 为原宿主，1 为慢速，2 为快速，3 在两种条件上接受同一批真实目标。测量真条件容量时只选 1 或 2。原型 3 单列为合并两种速度训练的单支参照。

两个训练臂都最小化同一根上自由续推的 H1、H4 端点 latent MSE，两跨度等权。真条件预测与分支 3 的损失也各占一半。每次同序抽取 16 个训练起点。Adam 初始学习率为 \(3\times10^{-4}\)，第 2048 和 3072 次各降为原来的十分之一。第 62 次保存早期对照。自第 3072 次起每 128 次测量全部 682 个训练根，若相对 512 次更新前的训练损失下降介于 0 与 0.1% 则按预定规则停止，否则运行至第 4096 次并记录未达到停止标准。评估只读指定检查点。

旧开发集为 48 个重置、42 个同窗、39 个有非零物理交互。本轮另外固定 48 个新重置（2026112400–2026112447），使用相同动作时序。规划预算剪枝独立用历史完整响应检验。阈值在看覆盖前固定为 0.95，只有某一原型支持达到该值时才近似为它的单支未来。该近似仅用于规划，公共支持和下一次实际签发保留所有原型。旧 G3 两个检查点各自的 39 根 × 2 种速度 × 3 种写入历程共 234 个读点；两者触发数均为 **0/234**。这是支持分布上的可剪枝比例，本轮没有规划器时延测量。

## 3. 在完全相同的原生预测上替换观测核

原核用 185 个节点逼近白化条件协方差 \(I+\xi P(B)\) 的连续高斯混合。另一核取完整 192 维共享白化 Student-t，自由度 3，尺度矩阵 \(LL^\top\)，协方差 \(3LL^\top\)。两者使用相同的均匀响应中心、标定 \(L\)、源预测、候选路径和起始支持。对同一到达，另把两个核放在相同的到达前支持上计算 log BF；做完整时间线时，各自沿真实到达递推。不拟合温度。以下均为 39 根旧开发面板的 latent 有向恢复率。

| 旧主模型，读出 − 对照 | 185 节点 H1 / H4 | 闭式 t H1 / H4 |
|---|---:|---:|
| 只吸收首次探测 − 均匀 | +0.0574% / +0.0518% | +0.7131% / +0.6741% |
| 完整实际到达 − 均匀 | −0.0650% / −0.0284% | +0.7237% / +0.8018% |
| 完整 − 省略首次 | +0.0582% / +0.0526% | +0.5295% / +0.5205% |

旧主模型开发根 2026112128 可以区分“面板平均转正”和“原返回案例得到修复”。固定该根的四条未来，185 节点法的 H4 有向分子从首次探测的 +0.1004 变为完整写入的 −2.6538 latent²；换用闭式核后为 +2.4067 到 −0.1059 latent²。两次静止的增量均为零。闭式核缩小了这个返回案例的负值，仍留下反向修订。

闭式密度与独立 Student-t 参考值在 1、2、7、192 维的最大绝对 log 密度差为 \(1.14\times10^{-13}\)。修改观测核也改变了证据的几何意义。对于双原型均值 \(\pm e_1\)，观测 \(2e_1+n e_2\)，当 \(n\) 从 0 增至 3000，185 节点法的 log BF 保持 1.88034，闭式核从 107.115 降至 0.0000867。同一根上可同时出现更强的轴向证据和更弱的带正交扰动证据。

以两原型先验 (0.1, 0.9) 接受一次支持原型 0 的受控观察 \(-e_1\)，185 节点法给原型 0 的后验为 0.2412，闭式核约为 1。若先吸收 \(+e_1\)，再依次吸收 \(-e_1,-e_1,+e_1\)，闭式核在第三次到达后首次翻到原型 0，185 节点在这四次内始终维持原型 1 多数。两者对同一反证的强度有实测差异。真实 TwoRoom 速度在该面板中始终恒定，返回仅改变动作方向。

按相同的 0.95 门槛在旧主模型闭式 t 后验上重算，**24/234** 个读点可仅保留一个分支，固定两候选 H1–H4 的最大实际端点差为 **0.02091 latent L2**，相应跨读点最大直径界为 0.02554。H1 对照为 30/234，最大端点差 0.00820。两者均用已有四条完整路径计算误差；没有把理论减少的路径数换算成规划加速比。

## 4. 物理坐标如何从预测中读出

LeWM 的原生输出是 latent。实际参考位置来自模拟器，在每个候选的真实根与 H1/H4 端点有独立记录。对每条预测，先用冻结的 \(D(z)=Wz+b\) 计算位移 \(\widehat{\Delta x}=D(\hat z_h)-D(z_{\rm root})\)，再与 \(x_h-x_{\rm root}\) 比较。报告的位移 RMSE 对两个坐标、两个速度和合格起点取平均再开根，分别列移动、停止两个候选。物理有向恢复采用速度与动作的双重差，分母为模拟器双重差的平方范数之和；latent 有向恢复采用真实画面编码在同一对照下的双重差。两种恢复率的 100% 都表示沿真值方向的总投影等于真实值；预测还可能有正交误差，所以另列端点量。

| 读出（FP64 最小二乘，均含截距） | 拟合记录 | 拟合外对**真实编码**读出的误差（地图单位） |
|---|---|---|
| 原 62 条有效轨迹所在的训练档 | 64 个重置共 1,056 个有效帧，坐标拟合 RMSE 0.489 | 39 个开发根 H1 绝对位置 RMSE 20.55，移动位移 RMSE 17.81 |
| 扩大位置覆盖，同一线性模型 | 作者 TwoRoom 训练归档中前 2,048 回合，每回合固定取四个时间位置，共 8,192 帧；训练 RMSE 4.319。随后 256 个官方回合单独检查，RMSE 4.581 | 开发 / 新起点 H1 绝对位置 RMSE 4.663 / 5.200，实际编码的移动位移 RMSE 3.993 / 4.817，停止位移误差均为零 |

原读出的拟合外误差在首轮检查时已经暴露。扩大标定覆盖后对**同一批已保存的分支预测**重新评分；两套读数均保存，latent 指标逐根相同。后文表明示采用扩大覆盖的坐标读出。输入真实端点编码时，这个读出在开发 / 新起点的物理有向恢复分别为 80.87% / 82.92%，这些数度量读出失真，不能当成真实动力学上界。

新采集 48 个重置、192 条实际轨迹，45 个根返回同一公开窗口，44 个具有非零物理交互。首次 CPU 编码中，逐像素相同的 RGB 因批内位置产生浮点差，只有 13 根满足旧协议要求的逐值同窗。固定原批形、恢复原开发归档的 CUDA FP32 编码且关闭 TF32 后，45 个匹配根的同窗差为零。校正前后使用同一份图像、实际动作、物理轨迹和种子，保留最初的排除记录；正式新面板以 44 个物理非零根评分。单图复制到 32 个批位置的复核中，CPU 最大差为 \(1.91\times10^{-6}\)，CUDA 为零。

## 6. 去掉零命令参考后，一次真实静止观察写了多少

在 39 个旧开发根、两种实际速度上逐步送入探测、真实返回、两块静止。每组共 156 次不同的实际静止到达。固定旧噪声标定和闭式 t，逐次记录写入前后支持。真速度只用于容量训练及离线分层，不输入本次的概率更新。TV 取更新前后四个概率绝对差之和的一半。

| 已训练响应 | 真实静止到达中的非零写入 | 按实际前缀写入的 TV 均值 / 最大值 | 两个已标定速度分支之间的绝对 log BF 均值 |
|---|---:|---:|---:|
| A | 156/156 | 0.03839 / 0.99904 | 5.93 nat |
| B | 156/156 | 0.06937 / 0.999999993 | 11.07 nat |

旧 TwoRoom 构造对静止到达的精确保持来自模型强制四分支输出一致。新构造保留了等似然时的赔率恒等式；两份容量检查点在实际静止窗口并没有产生相同预测。这里用的仍是旧宿主的固定噪声尺度，两臂的拟合目标仅监督后继，没有用概率目标训练静止写入。156 次属于 39 个配对根的连续事件。

## 7. Phase 1 能回答到哪一步

1. **2.08% / 1.54% 可定位到旧响应族。** 同一 A 参数化、相同真条件端点目标下，第 62 次到最终的独立 H4 恢复从 2.02% 升到 31.98%。存在远超旧上界的常偏移实例。旧 G3 与本轮还改变了监督权限、目标与零命令处理，旧结果中各项因素的单独贡献不能从这组比较反推。
2. **B 额外恢复了 latent 跨动作差，并降低了多数端点误差。** 独立 H4 的物理有向恢复并未出现可分辨的 B 优势。B 的合并条件单支也改善了一部分位移误差；仅降低绝对位移误差不能证明模型学到了两个速度之间的差。B 的 4096 步结果是可实现的响应实例，不是该参数化的收敛上界。
3. **A 和 B 均有跨方向恢复的实测数据。** A 使用 3,456 个偏移，B 另加入秩 4 动作调制和末两块可训练参数。Phase 1 的真条件测试只测量给定正确条件时的预测能力。真实经历形成支持、返回后的跨动作读出与回合内改判在后续无标签独立训练中评价。
