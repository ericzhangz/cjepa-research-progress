# 原 Phase 2 检查点的固定响应归因

原 NLL 改善不能单凭总梯度范数归因为均值学习。固定旧检查点、同一组签发均值和同一冻结白化尺度后，改变 G1 响应协方差会显著改变名义分支的密度；对前四条训练轨迹的精确局部导数分解，协方差通道也占主导。这些是固定点的数值与局部梯度事实，不识别过去训练过程的因果贡献，也不说明合法的协方差拟合本身不正确。

## 范围与口径

读取原 `runs/prbd_phase2_20261121/A/initial.pt`、`final.pt`，保持原来 3,456 个偏移、冻结宿主、G1 185 节点、固定尺度 L、转移矩阵及死区。前四条可用实际训练轨迹的种子为 2026113000–2026113003，共 120 个实际读根、456 个合法自由后缀目标。静态部分另复算原面板，严格同窗的 39 个重置共享前缀只计一次；两次静止共 156 次实际到达。只用 CPU 两线程；没有优化器更新、训练或参数扫描。旧数据与检查点未改写。

原全训练库的 0.0742733774 → −0.2698387699（变化 −0.3441121473）是按轨迹、读根、跨度平均的固定原型后缀混合 NLL / 维数。它同时含分支均值、共享响应协方差、混合责任及实际前缀信念的作用。它不是名义分支单独的 NLL。

## 同一均值，只替换协方差

对原始签发使用 `P(B)=B(I+BᵀB)⁻¹Bᵀ`。固定 P=0 的对照使用同一均值、同一 L 和共享高斯残差；该密度归一化，不重新标定尺度。P 初态/末态交换逐个对齐同一个读根和后缀步，随后按被交换的密度重新计算实际前缀和原混合目标。以下均为前四条轨迹，不能冒充全训练库的分解：

| 固定分支均值 | P 初态 | P 末态 | 固定 P=0 |
|---|---:|---:|---:|
| 初态均值 | −0.3384747784 | −0.4796337751 | −0.0202761914 |
| 末态均值 | −0.3400782124 | −0.4797940512 | −0.0637252846 |

这张表明确区分了均值与密度几何，但交换后的密度只是反事实重评分；没有重新训练，因此不能将表中差值当作训练消融收益。

名义分支初末均值在全部 456 个目标上最大差为 **0**。在这些完全固定的名义均值上，平均 log 密度为 P=0 **−28.9764**、P 初态 **51.1135**、P 末态 **85.9863** nat。只看实际 H1 的 120 个到达，G1 相对 P=0 的名义 log 密度增量均值为初态 **43.6369**、末态 **62.6825** nat。名义预测不变，并不保证名义密度不变：其共享协方差由全部分支决定。

严格同窗的两次真实静止到达，G1 相对 P=0 的名义 log 密度增量平均约为初态 **9.1063**、末态 **23.5582** nat。逐到达值、掩码及两种密度保存在 `original_{initial,final}_static_density.pt`；这些绝对密度增量不等于分支之间的似然比。

## 原 NLL 的精确局部梯度

以白化实际残差 r 和协方差基 B 为两个独立输入计算同一个 G1 密度。对每个高斯节点，令 A=I+BBᵀ、C=I+ξ(I−A⁻¹)、s=C⁻¹r，使用

`∂ log N / ∂r = −s`

`∂ log N / ∂B = ξ A⁻¹(ssᵀ−C⁻¹)A⁻¹B`。

节点责任加权后，保留完整混合目标及实际前缀的下游导数，再分别沿 r 和 B 回传到同一原生偏移。于是 `g_total = g_mean + g_covariance`。下表的 L2 不能相加；括号为与总梯度的内积除以总梯度平方范数，是带符号的局部投影，不能解释成训练收益百分比。

| 原 NLL 梯度 | 初态 L2 | 末态 L2 |
|---|---:|---:|
| 总梯度 | 4.142004 | 1.568346 |
| 均值残差 | 0.031504（0.2715%） | 0.006827（0.0927%） |
| 响应协方差 | 4.130863（99.7285%） | 1.566906（99.9073%） |
| 协方差奇异值幅度 | 0.377278（4.5387%） | 0.369650（−12.7565%） |
| 协方差方向 | 3.955885（95.1898%） | 1.794105（112.6638%） |
| 协方差整体径向尺度 | 0.588297（8.5722%） | 0.054319（−0.4292%） |

奇异值幅度项是 B 的固定局部 SVD 中对角分量；余量为方向项。整体径向尺度另定义为每次签发的 B 方向上的 Frobenius 投影，与逐奇异值幅度不是同一种分解。末态方向项与幅度项有抵消；因此只固定谱值并没有消除整个协方差学习通道。若非零奇异值完全重合，逐奇异值拆分不唯一；本报告同时保留不需要谱间隔的整体径向拆分及实际奇异值统计。

保持前缀取值但断开前缀反传，再与完整梯度相减，得到历史写入介导的均值/协方差梯度 L2：初态 0.002893 / 0.003762，末态 0.001454 / 0.005569。该拆分仍是局部路径分解。旧末态的 NLL 梯度 1.568346 与加权最小偏离梯度 9.427e−6 只是两个完整损失项的梯度比较；这两个数本身不能将 NLL 拆成均值与协方差。

## 5.22 对应哪个事件

原静态最大 TV 写入为种子 **2026114037**、速度 **7.5**、第 **4** 根：TV=**0.6793561**，白化响应最大两两距离 **5.2192439**。5.22 是这个最大写入事件的响应距离。全部严格同窗静止到达的响应距离最大值另为 **6.6963026**。

它也不是 log 似然差的最大值。原存档四次到达 t=2,3,4,5 的 `max_k logℓ_k−min_k logℓ_k` 最大值分别为 **2.06513、1.39193、4.62497、4.02892** nat。CPU 复算与原 GPU 签发存在约 1e−4 的 FP32 前向差，报告保留各自口径。

## 数值验证与实现审查

- 分离后的完整密度与原归档核最大差不超过 2.28e−13；原生梯度 `g_mean+g_covariance` 的重组最大误差为初态 5.96e−8、末态 3.82e−8。
- 独立的 D 维协方差直接求解和 `slogdet` 加普通自动微分，对随机、重复列、全零 B 的最大密度/一阶导数误差为 1.78e−15 / 1.11e−15。
- 在旧初末两个检查点，修订核的固定谱值梯度等于本审计独立分离的均值加协方差方向梯度，最大误差 5.96e−8 / 2.98e−8。其 L2 为 3.967517 / 1.795521；这是导数实现一致性检查，尚非修订训练效果。
- 新共享原生末部的代码独立阅读确认名义支直调冻结宿主，三个条件支使用同一末部和原偏移；没有发现额外的名义锚来源。容量拟合效果及修订后的无标签效果须由各自终态实验报告回答。
