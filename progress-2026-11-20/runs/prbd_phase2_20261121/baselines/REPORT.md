# Phase 2 共同实际前缀上的四种基线

本轮仅评价给定实际动作序列上的预测。影子规划不执行动作；没有启动 Phase 3，没有统计任务成功率。预测评分由上级统一评价脚本读取本目录的预测张量后完成；本报告记录算法、信息边界及实际计算量。

## 实现与输入

统一入口为 [prbd_phase2_baselines.py](../../../research/p1a/prbd_phase2_baselines.py)。冻结宿主、AdaJEPA、OpTTA 均复用作者 TwoRoom LeWM 权重、动作归一化、三帧窗口及冻结的视觉/动作编码器。普通 GRU 复用已有 `stage_a_baselines.GRUDynamics`，固定 hidden=192，共 369,984 个参数，从随机初始化开始训练；其权重在部署期固定。

训练种子为 2026113000–2026113191。仅白名单 `z/a/seed/lengths` 进入训练；192 条记录中，长度不足3块的6条不进入任何方法的学习，保留186条可用实际轨迹，包括合法短尾。GRU 与 PRBD 使用相同顺序、同一 CPU 随机生成器 seed=20261121、每次 `randperm(186)[:4]` 的4条轨迹、2048次 Adam 更新、初始学习率3e-4，并在第1024、1536次更新前各降10倍。GRU 损失按轨迹、所有合法 root、各合法 H1–H4 等权；每个 H 是该 H 个未来 latent 的平均 MSE。GRU 具有完整真实前缀的隐状态；未读取物理状态、速度、条件标签、切换时刻、容量 oracle 检查点或裁判后继。

各模型的离线先验与参数量并不相同：LeWM 系列保留作者预训练先验，GRU 仅使用本轮186条单轨；这里匹配真实训练回合、更新次数及评价输入，不声称预训练数据、参数或 FLOP 匹配。GRU 的维度在评价前固定，未按评价结果调整。

根据执行所用的确定性采样器重放，GRU 与 A 的训练目标覆盖均为8,192个抽样轨迹、243,039个合法读点、923,004个最大合法后缀目标步；每个读点的各 H 前缀仍按上述规则评分。学习率按1-based更新号，在第1,024和1,536次优化之前衰减。

## 作者在线方法

适配器使用[本快照的作者源码](../../../research/p1a/lewm_optta/adapter.py)，对应[作者 LeWM 实现](https://github.com/akshaymete/optta/blob/main/lewm/code/lewm_optta/adapter.py)。AdaJEPA 是这份作者 LeWM 适配版的 rho=0 分支，OpTTA 是 rho=1 分支；不是把新写的近似称作作者实现。这里不声称复现 AdaJEPA 原论文默认的编码器联合适配或原论文完整规划预算。

两种在线方法各更新作者选择的末 Transformer 块、最终归一化与 pred_proj，共2,591,552个参数。使用作者 LeWM 设置：每次到达一步 Adam，lr=5e-5，保留最近5个实际块，编码器固定。最初两块各以一个真实 segment 初始化缓存；source root=2 首次签发，在真实 z3 到达后第一次更新。静态完整前缀至 z6 共4次更新，切换流完整32块共30次更新。每个 seed/起速 stream 恢复权重并清空 buffer 和更新计数；优化器按作者实现每次更新重新建立。两种未来候选共享同一已经形成的模型状态，候选预测不触发适配。

OpTTA 正项调用未修改的作者梯度范数平衡和递增规则 `rho*sqrt(k/30)`。其目标来自环境 reset 时公开给出的 goal_state 所对应的目标图，经同一冻结编码器得到；没有把被预测的真实未来当作目标。每个实际 source 窗先影子规划并保存最后一轮候选池，随后才提供该实际后继并更新，不能在后继到达后反向构造执行前计划。

影子 CEM 直接调用既有公开 `stable_worldmodel.planning.solver.cem.CEMSolver` 源码。共同预算固定为16条候选、3次迭代、4个精英、H4、初始方差1、无 warm start。代价调用作者 `Objective(base=2)`：前4次重规划只计终点，之后按指数权重计当前帧及未来4帧。桥接仅把已见三帧、过去两块和归一化的未来命令转换到 LeWM 原生预测接口。作者 CEM 的 Gaussian proposal 不在模型前向前裁剪；本轮保留该原生提议分布，影子动作没有实际执行。实际记录里的动作始终来自原定合法执行。

Frozen、AdaJEPA、OpTTA 都运行上述共同影子预算。影子结果对 Frozen 和 AdaJEPA 的预测权重没有作用；只有 OpTTA 的正项消费已缓存计划池。普通 GRU 无需影子规划，单列预测和真实状态推进成本。在线两方法的配对起速流使用相同的 seed 初始化随机计算；每个独立环境种子仍独立。最先执行的 Frozen 计时使用 `2*seed+stream` 作为 CEM seed；冻结预测完全不受影子采样随机数影响，其候选预算与其他两方法相同。

## 共同输出与校验

`static_{method}.pt` 包含 `seed[48]` 与 `predictions[48,2,2,4,192]`，轴为种子、慢/快实际前缀、移动/停止候选、H1–H4、latent。查询 root=6，只看到 z0–z6。静态独立种子为2026114000–2026114047。候选在真实截断前的合法跨度逐个保留，其余为 NaN。

`switch_{method}.pt` 包含 `seed[48]` 与 `predictions[48,2,32,192]`，每个 t>=2 的条目是在只看到 z0–zt 时对实际下一块后继 z[t+1] 的预测。t<2 为 NaN。切换独立种子为2026114100–2026114147。所有96条流完整32块；方法不读取切点或速度。物理识别对照、真实后果及位置读出均留给同一评价脚本，不进入基线前向。

[codechecks.json](codechecks.json) 记录以下实测：GRU 向量化目标与已有慢速逐轨/逐root/逐H API 的损失逐值相同（2.1566367149353027）；39个完整 matched 静态根上的冻结慢/快预测逐值相同；作者 OpTTA 确实执行正项（第二次 alpha=0.000145213），并改变了所选权重；reset 后所有所选张量逐值恢复，buffer 和计数清空；五段缓存的合并内容严格等于最近五个实际 transition，最多6帧。90条可用静态前缀的两个候选在查询前的实际 z/a 也逐值相同。

方法没有 PRBD 原型支持或等似然写入变量，因此这些字段为 N/A；不为基线杜撰支持概率、静默门或切换标签。统一评价只比较其真实预测。

## 运行命令

从本快照目录使用已配置的 Python 环境：

```powershell
& python -m research.p1a.prbd_phase2_baselines fit_gru
& python -m research.p1a.prbd_phase2_baselines frozen --shadow-frozen
& python -m research.p1a.prbd_phase2_baselines gru
& python -m research.p1a.prbd_phase2_baselines adajepa
& python -m research.p1a.prbd_phase2_baselines optta
```

实际执行关闭 TF32，PyTorch CPU 线程数2。所有方法消费同一缓存的冻结编码，所列预测/状态推进/适配/影子规划时间不含公共 RGB 与目标编码、数据收集或每轨权重恢复。所有时延来自共享 GPU 当时的真实负载：与 PRBD 训练及短暂数据编码/验证有并行争用，因此不能把这些墙钟差异当作隔离条件下的算法加速比。逐轨时延、实际优化步数及作者损失记录在 `timing_{method}.json`；统一预测分数不采用作者内部的日志 loss 代替。
