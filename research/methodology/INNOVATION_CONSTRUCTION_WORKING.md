# 从原生预测计算形成宏步：一项尚未闭合的解析构造

2026-11-07。工作推演，保留推导及其后续实验判断。已在现有 P1A 原生调用路径上实现小型机制实验，没有训练新模型，也没有替换宿主 operator。

当前判断：下面给出了宏步如何由原生 predictor 的实际调用形成的具体计算关系，以及固定证据下继续计算的明确作用。它比“另学一个 horizon-conditioned 调用”更直接地回答了宏步来源。但它尚未解决连续动作下的规模与真实观察到来后的低成本迁移，因此不能作为已经完成的新方法。展开、有限实现与矩阵组合均有已有理论来源。

**实验后更新：固定低阶、零尾项截断已退出当前长时域方法候选，以下内容保留为解析参照。** [阶段实验](../../runs/method_mechanism_20261107/RESULTS.md)显示可闭合解析系统及 FourRoom 短前缀精确，但 FourRoom 长跨度失效，加阶数没有改善；只换当前 latent 也不能正确迁移全部坐标。固定动作下 T=I+S 且 S^(r+1)=0，强制预测为时间跨度的有限次多项式，这是构造本身的限制。下一步必须修订闭合与观察迁移，不能沿当前截断扩大实验来寻找正结果。

## 1. 现稿真正还没有推出的东西

[现行方法构造](../METHOD_CONSTRUCTION.md)已经定义了完整算法：一个 memory token、动作片段编码、同核观察写入和续算蒸馏。其粗步仍是让神经网络重新学习 T_h(W,α)。共享细步权重与粗步权重没有从原生细步运算中导出 T_h；续算损失规定了它应当产生什么行为，也没有给出怎样复用已经执行的内部计算。

这使“持续计算”仍主要表现为流式递归，“多时域”仍主要表现为跳步学习。这里继续构造一个不同的计算选择：**把原生预测器已经算出的有限差分组织成可继续使用的运算坐标，以组合运算生成宏步。** 不再先增加宏步回归器。

本笔记保留原目标：利用现有 JEPA 原生预测能力，形成可持续维护、可被多个时域使用的中间预测计算。它不转为目标评分、行动关系库或固定端点答案缓存。

## 2. 结构原则：区分未来时间与展开阶数

设 x 是原生 predictor 的完整输入状态，包括所需 latent 历史与动作上下文；不能只取当前 z 然后假装原模型已经是一阶 Markov。原生一步计算与窗口推进合为 F_a(x)。g(x) 返回当前原生 latent，维数为 d。

先在有限动作字母表 A 上推导。a 是已归一化的一个原生动作块，不是未经说明的动作平均值。定义作用在函数上的算子

\[
(K_a f)(x)=f(F_a(x)),\qquad Δ_a=K_a-I. \tag{1}
\]

K_a 和 Δ_a 都由已有 F_a 定义，没有新神经网络。函数上的线性不表示 x 的动力学线性。

一段动作 α=(a_0,…,a_{H-1}) 的原生终点输出是

\[
g(x_H)=(K_{a_0}K_{a_1}\cdots K_{a_{H-1}}g)(x_0)
=\big(I+Δ_{a_0})\cdots(I+Δ_{a_{H-1}})g\big（原工程资料）. \tag{2}
\]

乘积保留动作次序，不能交换。H 是真实预测跨度；乘积展开中包含多少个 Δ 是另一个量。这个区别允许先研究：一个较低阶的原生运算展开能否表达较长跨度，而不把“多做一次内部计算”等同于“世界又前进一步”。

式 (2) 是代数恒等式。它本身不提供近似误差小或计算便宜的保证。

## 3. 工作态：原生未来差分的有限坐标

对动作字 w=(b_1,…,b_k)，记

\[
Δ_w=Δ_{b_1}\cdots Δ_{b_k},\qquad
m_w(x)=(Δ_w g)(x),\qquad m_∅(x)=g(x). \tag{3}
\]

保留 |w|≤r 的坐标：

\[
M_r(x)=\{m_w(x):|w|≤r\}. \tag{4}
\]

这份工作态有直接的计算含义。m_a 是原生一步相对当前输出的变化；m_ab 是在动作 a 之后，动作 b 所产生变化如何不同于当前的 b 变化。它们来自 predictor 已做的计算，而不是由某个无语义 hidden state 的范数或寿命定义。

例如

\[
m_a(x)=g(F_a(x))-g(x),
\]

\[
m_{ab}(x)=g(F_b(F_a(x)))-g(F_a(x))-g(F_b(x))+g(x). \tag{5}
\]

这里 m_ab 与 m_ba 通常不同。式 (5) 不需要训练新 predictor，也不需要真实未来作为输入；它计算的是原生模型对合法假设动作的响应。

## 4. 动作推进从同一工作态直接导出

执行或假设执行动作 a 后，每项坐标满足

\[
m_w(F_a(x))
=(K_aΔ_wg)(x)
=m_w(x)+m_{aw}(x). \tag{6}
\]

这是精确关系。它给出当前工作态应该怎样推进，而非重新定义一个待学习的 U(M,a)。

有限阶构造将 |w|=r 的缺失项 m_aw 暂时置零。因此

\[
\hat m'_w=
\begin{cases}
m_w+m_{aw},&|w|<r,\\
m_w,&|w|=r.
\end{cases} \tag{7}
\]

记此稀疏移位运算为 R_a。任意动作段的预测为

\[
\hat M_H=R_{a_{H-1}}\cdots R_{a_0}M_r(x_t),
\qquad \hat z_{t+H}=\pi_∅\hat M_H. \tag{8}
\]

不同 h 的结果来自同一个 M_r 和同一种移位计算，继续一个动作段仍返回同类型工作态。没有单独的 horizon 网络或各时域输出头。

若所有长度 r+1 及更长的相关差分为零，则式 (7) 在该作用域中精确闭合。这是一项强结构条件，不能由“JEPA 训练过短时预测”推得。一般情形下式 (7) 是截断近似。

## 5. 固定证据下继续计算实际改变什么

在真实时间 t 不变时，继续调用原生 F，计算尚未获得的长度 r+1 差分，可以把 M_r 扩为 M_{r+1}。这增加了一类此前被置零的原生作用项，并改变所有后续宏步的计算。

这一 compute 操作与普通 rollout 不同：产物可以供同一动作字母表内的多个候选、多个跨度共享，不只保存某条候选的终点。它也与在线 TTT 不同：此处没有更新原生网络参数，增加的是由原生计算得到的系数。

不过，增加展开阶数并不普遍保证误差单调下降。式 (2) 的项可能相消，大阶数还可能放大数值误差。只有加上特定系数衰减或闭合条件，才能给出相应近似结论。

展开式的精确截断差为

\[
e_{H,r}(x)=
\sum_{k=r+1}^{H}
\sum_{0≤i_1<\cdots<i_k<H}
(Δ_{a_{i_1}}\cdots Δ_{a_{i_k}}g)(x). \tag{9}
\]

若在所讨论的动作段上额外假设每项范数不超过 C ε^k，则

\[
\|e_{H,r}(x)\|
≤C\sum_{k=r+1}^{H}\binom Hk ε^k. \tag{10}
\]

这个条件性上界明确显示：H 增长时，固定 r 并不会自动保持准确。它没有证明 FourRoom 满足所需的系数衰减，也没有证明模型误差小于原生 rollout。

## 6. 真实观察迁移是核心未解部分

真实观察到来后，原生输入状态从预测的 x^- 变成以已到达观察更新的 x^+。正确的新工作态是

\[
M_r(x^+)=\{(Δ_w g)(x^+):|w|≤r\}. \tag{11}
\]

仅更新 m_∅=E(o_t) 而保留旧的其余差分，不满足式 (11)。即便是完全可观测的标量例子 F(z)=z²，也有 m_a(z)=z²-z。旧锚点 z=1 时 m_a=0；真实观察改为 z=2 后应有 m_a=2。只替换零阶坐标会预测 2，而原生一步结果为 4。

可以从 x^+ 重新调用原生 predictor 构造全部差分，算法是明确的，但这会重做大量内部计算，削弱本项目要求的持续复用。另设网络把旧 M 与新观察映射为新 M，又会回到尚未推导的学习更新器。用在线 DMD 拟合这一步则进入已有在线降阶路线，不能把缺口藏起来。

因此，低成本观察迁移不是一个待补的小工程函数，而是该候选的中心科学问题。需要某项可说明适用范围的结构，使原生未来作用坐标随真实观察改变时能被重新定位，并保留此前已经形成的有效计算。当前尚未得到这一结构。

信息与计算两种困难也应分开：如果 x^+ 是合法且完整的原生输入，式 (11) 在信息上已被确定；困难是怎样少调用 F 得到它。如果只保留了不完整的当前 z，则还可能存在历史条件不可辨识的问题。

## 7. 编译与查询的真实成本

若动作字母表大小为 q，完整保留至 r 阶的坐标数为

\[
S_r=\sum_{k=0}^{r}q^k.
\]

从同一锚点构造全部原生前缀树，至少需要对相应树边执行 F；朴素完整构造的调用数为 S_r-1，存储规模为 d S_r。由这些终点可计算式 (3) 的差分。

单个候选的稀疏移位总工作量为 O(H d S_{r-1})，需要仍然读取 H 个动作。并没有获得普遍的 O(log H) 总成本。优势只能来自昂贵的 F 调用被多个候选、跨度及后续使用共同摊销。

作为纯算术示例，q=9、r=2 时有91个坐标与90次原生树边调用；q=160、r=2 时已有25761个坐标及25760次调用。这不是实验结果，说明连续动作不能通过“把所有用过的动作都列为字母”轻易处理。

本地候选包含连续变化的 wandering 动作，不能把9个固定方向的例子冒充当前完整候选集。若把连续动作算子近似为少量生成元的组合，还需要单独说明原生动作条件为什么允许这种近似、近似项怎样影响式 (9)。当前没有从原生 AdaLN 结构直接导出这种有限生成关系。

若每次新观察都重做完整树，维护成本同样为 O((S_r-1) C_F)，必须计入。若需要 r 接近 H 才准确，或者连续动作使 q 很大，则编译成本可能远高于原生 rollout。

## 8. 与原生计算接口的关系

该候选所有系数的来源都是原生 F，宏步输出也仍在原生 latent 坐标中，可以继续输入 F；它不以外部评分器替代预测。相较现稿，宏步由明确的原生运算展开产生，没有重新训练 T_h。

但执行式 (8) 时，预测路径确实绕过了 F 内部的 attention/MLP，改用已编译的坐标运算。它更准确地属于原生 predictor 的运行时近似编译，而不是已经实现了“一个持久中间层在每次原生 forward 内部继续工作”。二者不能因为都使用同一 latent 就混称。

若目标坚持后者，尚需找到可在原生实际中间计算上形成并迁移的闭合坐标；当前差分坐标尚未完成这个接入。把式 (8) 当作另一套小型动力学接口长期运行，也会失去对原生中间机制的直接解释。

## 9. 已有理论与这次实际推进的边界

本笔记借用的是已有的算子与非交换级数思想。下列工作使“动作字、迭代和、有限状态实现、在线系数更新”不能作为本项目原创点：

- [Gray 等：Discrete-Time Approximations of Fliess Operators](https://arxiv.org/abs/1510.07901)：研究非线性输入输出展开、迭代和与有限实现。
- [Gray 等：Nonlinear system identification via discrete-time Chen–Fliess series](https://www.sciencedirect.com/science/article/abs/pii/S0005109820302831)：已将截断非交换展开用于递归辨识与控制。
- [Mezić：On Numerical Approximations of the Koopman Operator](https://arxiv.org/abs/2009.05883)：研究有限截面与 Krylov 近似，亦说明有限近似并非普遍可靠。
- [Zhang 等：Online Dynamic Mode Decomposition](https://arxiv.org/abs/1707.02876)：已有无需保存全部历史的在线算子更新。

本次具体推进是：将“宏步来自原生计算”变成了式 (2)—(8) 的可执行关系；将固定证据下继续计算变成了补足缺失的原生作用项；同时把真正尚未解决的部分定位为原生坐标在观察后的低成本迁移和连续动作下的紧凑生成。

这些推进足以排除“增加 token 和 loss 就自然具有持续计算”的说法，但不足以宣称新的会议论文方法已经形成。

## 10. 目前应怎样使用这份推演

保留为当前主方案旁的解析构造参照，不自动替换代码路径。它提供了一项明确要求：拟议工作态应当保存能够产生宏运算的计算内容，而不只是让一个新网络有更多条件可用。

真正尚未跨过的创新点，是找到轻量、可执行的原生多时域坐标，并给出真实观察到来后继续使用这些坐标的低成本规律。如果后续只能加一个 learned macro predictor 或一个独立 observer 来补齐，就需要承认回到了已有模型组合，不能将这份展开的名称当作新方法的依据。

本轮未改模型、未训练、未执行实验，也未建立核验流程。
