# ID-WM：从长程规划问题到隐式动作的构造脉络

阅读版本：Zhou 等，*Hierarchical World Models with Implicit Dynamics*，arXiv:2610.42146v1，2026-10-30。已逐段阅读正文 §1–5、附录 §6.1–6.13，以及公式、算法和表格。本文把方法重新组织成因果推导，**不推断作者实际研发的时间顺序**。

原文：[HTML](https://arxiv.org/html/2610.42146v1) · [PDF](https://arxiv.org/pdf/2610.42146v1)。下文标为“重建”的公式用于解释机制，不冒充原文定理或原文公式。

## 1. 它首先决定要解决什么

目标是：从没有任务奖励标签的离线转移中学习模型，在新起点、新目标和较长执行时域上规划。需要复用局部动力学，不要求训练数据已经包含完整的目标实现轨迹。原文将主要困难放在长动作链的搜索与预测上，而非直接学习一个端到端目标策略。[§1](https://arxiv.org/html/2610.42146v1#S1)、[§3](https://arxiv.org/html/2610.42146v1#S3)

用以下统一记号重建问题：

| 符号 | 含义及维度 |
| --- | --- |
| o_t | 真实观察，可以是状态向量或图像 |
| s_t∈R^{d_s} | 用于当前模型的状态表示 |
| a_t∈R^{d_a} | 一个低层时间步的动作；若使用 frameskip，它包含对应的原始动作块 |
| g | 目标在相应模型中的表示 |
| c | 低层 predictor 使用的历史状态数量 |
| Δ | 高层预测的时间跨度，按低层时间单位表达 |
| H_hi、H_lo | 高层子目标数量、每个低层动作规划的长度 |
| K、j | 扩散训练步数和扩散索引；不同于真实环境时间 |
| z_i∈R^{d_z} | 第 i 个高层决策的初始噪声，形状与被生成的状态相同 |

平坦规划的典型形式是

\[
\min_{a_{0:H-1}}d\bigl(F^{a_{0:H-1}}(s_0),g\bigr). \tag{R1}
\]

一次候选评价要把局部模型递推 H 次；优化变量有 H d_a 个标量。H 增大时，状态误差和优化困难同时出现。这不等于所有连续优化算法的运行时间都能证明为指数；它说明长动作链将更多控制自由度和更多模型递推放进同一次求解。

直接将 H 个动作压成一个 latent skill，也没有自动解决问题：这个 latent 必须既表达长跨度变化，又容易搜索，还要能恢复为有效动作。仅把输入维度压小，并不能保证其几何结构适合规划。

## 2. 决定方法形态的选择：高层先决定到哪里

ID-WM 把高层决策改为局部未来状态，用生成模型参数化这个选择；动作实现交给原有前向模型的局部优化。高层搜索不再要求每个自由变量直接对应一串电机命令。[§3.1](https://arxiv.org/html/2610.42146v1#S3.SS1)

这个选择可以用一个分布分解理解。设真正的 Δ 步转移为 P_Δ(s'|s,α)，α 是长度 Δ 的动作序列。离线数据中的条件未来分布为

\[
q_{\mathcal D,\Delta}(s'|s)
=\int P_\Delta(s'|s,\alpha)\,\mu_{\mathcal D}(\alpha|s)\,d\alpha. \tag{R2}
\]

式 (R2) 是本文的概率解释：高层学习将动作边缘化后的短距未来分布，低层再为选择出来的端点求动作。它解释了为什么高层不需要直接编码一个确定动作序列。

同时，q_D 的支持受数据行为 μ_D 影响。它可以覆盖局部多种后果，却不是所有真实可达状态的完整集合。将它称为“可达状态生成器”是一种模型用途；有限数据训练不能把真实可达性变成硬保证。

## 3. 高层训练：把未来状态分布变成可搜索映射

### 3.1 预测目标不是全局成功轨迹

训练样本是当前状态 s 与一个 Δ 步后的目标状态 x_0。这里 x_0 是扩散过程的干净样本，不是环境第 0 帧。对每个给定 s，可以有多个合适的未来状态，因而高层需要表达分布。

原文用条件 DDPM。其公式 (1) 的单步加噪可展开为

\[
x_j=\sqrt{\bar\alpha_j}\,x_0+
\sqrt{1-\bar\alpha_j}\,\epsilon,
\quad \epsilon\sim\mathcal N(0,I),
\quad\bar\alpha_j=\prod_{u=1}^{j}(1-\beta_u). \tag{R3}
\]

x_j、x_0、ε 的维度一致。β_j 是噪声日程；它不是环境动作，也不是高层规划代价的正则权重。

以 ε 为目标，学习

\[
\mathcal L_{diff}
=\mathbb E\|\epsilon-\epsilon_\theta(x_j,j,s)\|^2. \tag{R4}
\]

这对应原文公式 (2)。其基础是成熟的噪声预测训练：不需要为每个离线片段知道“正确高层 latent action”，也不需要任务奖励。高层条件分布由状态配对提供监督。[ID-WM §3.1.1，式 (1)–(2)](https://arxiv.org/html/2610.42146v1#S3.SS1.SSS1)；[DDPM 的训练推导与算法](https://arxiv.org/html/2006.11239v2#S3)

原文问题形式写有 Δ 条件，而具体 ε 网络公式省略它。主实验使用固定 Δ=5。不能仅据省略后的公式断言作者实现了一个对任意 Δ 连续外推的单一模型；“时间半径”和固定偏移样本之间也不应被解释为严格的最短可达步数监督。

### 3.2 为什么需要确定性的 DDIM

若生成过程在每次调用中重新注入独立噪声，同一个高层决策会对应不同预测结果，给搜索评价增加额外随机性。确定性 DDIM 将整次生成所需的自由度集中到初始 x_K=z。

先用当前噪声预测得到干净样本估计：

\[
\hat x_0=\frac{x_j-\sqrt{1-\bar\alpha_j}\,
\epsilon_\theta(x_j,j,s)}{\sqrt{\bar\alpha_j}}.
\]

再做确定性一步：

\[
x_{j-1}=\sqrt{\bar\alpha_{j-1}}\,\hat x_0+
\sqrt{1-\bar\alpha_{j-1}}\,\epsilon_\theta(x_j,j,s). \tag{R5}
\]

这对应原文公式 (3)。将有限个去噪步骤合起来，得到

\[
\mathcal G_\theta:\;(s,z)\mapsto\hat s_{+\Delta}. \tag{R6}
\]

条件固定时，同一个 z 得到同一个结果。因此 z 可以成为规划器优化的变量，作用类似高层动作。训练时它是生成噪声，推理时它是搜索坐标；这项重新解释是方法的关键。[ID-WM 式 (3)](https://arxiv.org/html/2610.42146v1#S3.E3)；[DDIM 原文 §4](https://arxiv.org/html/2010.02502v4#S4)

高斯先验的坐标空间是规则的，不代表学习映射的像必然没有畸变，也不代表映射是单射、保距或始终物理可达。不能从噪声空间的性质直接推出真实世界的性质。

## 4. 低层为何仍然使用前向模型

低层输入历史状态和动作，预测下一状态：

\[
\hat s_{t+1}=f_{lo}(s_{t-c+1:t},a_{t-c+1:t}). \tag{R7}
\]

动作经 MLP 编码后进入 Transformer。训练对准真实下一状态。原文公式 (4) 写的是 L2 范数；这里不把它擅自改成另一个已报告的目标。[§3.1.2、式 (4)](https://arxiv.org/html/2610.42146v1#S3.SS1.SSS2)

给定高层子目标 s*，低层求解

\[
a^*_{0:H_{lo}-1}
=\arg\min_\alpha
\|\operatorname{Roll}_{f_{lo}}(s,\alpha)-s^*\|_2. \tag{R8}
\]

式 (R8) 是对原文推理过程的展开。“inverse dynamics”在这里是**求解用途**：优化前向模型的动作输入，得到实现目标转移的动作。它没有要求额外训练一个从 (s,s*) 直接输出动作的逆网络。

这一选择保留了对不同动作的评价能力，也避免让逆模型只模仿数据中某一种动作实现。不过它仍可能利用前向模型误差，且搜索结果的物理有效性不由优化问题本身保证。[DINO-WM 原始方法](https://proceedings.mlr.press/v267/zhou25t.html)

## 5. 规划：两次搜索怎样组成一条实际路径

### 5.1 高层搜索的变量与代价

给定当前 s_0，搜索 Z=(z_0,…,z_{H_hi-1})。每个候选按

\[
\hat s_{i+1}=\mathcal G_\theta(\hat s_i,z_i)
\]

生成子目标链，再最小化

\[
J_{hi}(Z)=\|\hat s_{H_{hi}}-g\|_2+
\lambda_{reg}\operatorname{Reg}(Z). \tag{R9}
\]

λ_reg 对应原文公式 (5) 的 α。终点匹配是软代价，不能把原文说明中的 s*_{H_hi}=g 读成训练或求解中已经强制满足的等式约束。

原文公式 (6) 的正则对超过阈值的噪声坐标施加惩罚。标准高斯在所有有限 z 上都有正密度；这里限制的是偏离典型高密度区域的程度，并非数学上有限的“先验支持边界”。[§3.2、式 (5)–(6)](https://arxiv.org/html/2610.42146v1#S3.SS2)

### 5.2 CEM 做了什么

下列是算法 2 的标准统计解释，不增加一个新的神经模块。

1. 为整段决策初始化一个搜索分布 q_ψ；高层变量是 Z，低层变量是动作序列 α。
2. 从 q_ψ 采样 N 个候选，逐个生成状态序列并计算代价。
3. 保留代价最低的 K_elite 个样本，用它们更新 ψ。
4. 重复若干次，返回最低代价候选。

若采用对角高斯参数化，标准矩匹配写法是

\[
\mu^+=\frac1{K_{elite}}\sum_{n\in\mathcal E}v_n,
\qquad
(\sigma^2)^+=\frac1{K_{elite}}\sum_{n\in\mathcal E}(v_n-\mu^+)^{\odot2}.
\]

这里 v_n 是展平的候选变量；原文算法以“根据 elites 更新分布”表达，并未由该式引出新的方法贡献。[附录 §6.5，算法 2](https://arxiv.org/html/2610.42146v1#S6.SS5)

### 5.3 真正的执行顺序

```text
从真实当前观察构造状态
高层 CEM：搜索噪声序列，生成一串子目标
依次处理子目标：
    低层 CEM：用前向模型搜索能接近该子目标的动作序列
    在环境中执行这段动作
    接收真实观察，更新低层起点
完成当前子目标链后，从真实当前状态重新作高层规划
```

观察在动作执行之后到达，不被预先喂给候选预测。整个流程具有反馈，但没有学习一个跨规划轮持续积累的中间工作态；重新规划与任务内持续计算状态是不同设计问题。

视觉实验还要区分表示空间。原文使用 VAE 表示生成视觉子目标，并在定量设置中使用 DINO-WM 作为低层模型。不能仅因为二者都叫 latent，就默认它们坐标相同并直接互传张量；文章中对这条接口的说明不应被扩写成未经给出的实现细节。[§4.6](https://arxiv.org/html/2610.42146v1#S4.SS6)

## 6. 从构造推导复杂度，而不是从“层级”推导加速

下面为方法流程的运算量重建。设 I 为 CEM 迭代数、N 为候选数、K_D 为一次 DDIM 生成的网络调用数，C_D、C_lo 为两种网络单次成本。

一次高层规划约为

\[
I N H_{hi}K_D C_D.
\]

为每个子目标进行低层规划，合计约为

\[
H_{hi} I N H_{lo}C_{lo}.
\]

在 H≈H_hi H_lo 的对应下，平坦规划的前向调用量约为 I N H C_lo。可见分层并没有凭定义消除所有低层计算，还增加了高层生成成本。它希望把难以一次优化的长控制问题，改成若干有局部目标的优化。

搜索维数同样要具体比较：高层为 H_hi d_z，平坦为 H_hi H_lo d_a；只有 d_z<H_lo d_a 时，前者才更低。视觉状态维度较大时不一定成立。**改变搜索几何、减短每个优化问题承担的预测跨度，与降低总 FLOPs 是不同论点。**

附录的计时也表明 ID-WM 比对应的平坦 WM 更慢；额外重规划预算的平坦对照仍未抹平任务收益。这里支持的是在所测设置中的质量—计算取舍，不是一个普遍的速度定理。[附录 §6.9](https://arxiv.org/html/2610.42146v1#S6.SS9)

## 8. 删除核心选择，方法会变成什么

以下是对构造的思想实验，不声称作者已逐项运行。

- 若高层直接优化原始动作串，就恢复了长动作链搜索，局部可达生成器失去决策变量的作用。
- 若保留 diffusion，但直接生成整个目标轨迹，局部条件分布的组合就变成对整条轨迹的生成建模；需要学习的统计对象不同。
- 若高层自由优化任意 s'，则失去生成分布对候选空间的约束，必须另想办法处理不现实的子目标。
- 若去掉低层动作求解，只生成子目标，得到的是未来状态提案而非可执行控制。
- 若仅保留常规两层网络但不改变高层搜索坐标，“层级”这个名称无法解释其相对普通宏动作模型的特点。

所以最值得借鉴的并非网络数量，而是**一个决策变量的改变，同时规定了训练目标、推理输入和与已有模型的分工**。

## 9. 对我们当前方法构造的一条具体建议

当前 [METHOD_CONSTRUCTION.md](../METHOD_CONSTRUCTION.md) 已把实现写完整，但其核心论证仍有一处跳跃：从“端点相同不保证后续相同”的反例，直接走到“增加一个 192 维 token，再用续算损失定义其意义”。反例证明的是端点监督不足，没有导出这个 token 为什么能成为紧凑且可更新的计算坐标。

建议把后续构造集中于一个对象：**原生预测程序在后续运算中的可替代状态**。先精确规定允许的后续运算集合，再定义压缩必须保存的区别；token 是这个对象的一个实现选择。

例如令 S 为原生增强程序的内部状态，𝒞 为允许的动作推进与观察写入的后续程序集合。可定义

\[
S\sim S'\quad\Longleftrightarrow\quad
\pi_z C(S)=\pi_z C(S')\quad\text{对所有 }C\in\mathcal C.
\]

如果 𝒞 对在前面接上合法操作 U 封闭，那么 S∼S' 可推出 U(S)∼U(S')：因为任意 C∘U 仍是被比较的后续程序。这解释了为何“后续可替代”能够定义可继续更新的对象，而端点距离不能。

这只是明确设计语义，不是新的行为等价理论，更不证明存在 192 维的紧凑表示。需要作出的实质方法假设是：在指定的动作与观测范围内，这种可替代性能够由小状态近似表达，并允许比原程序更便宜的宏步。当前续算损失是这种性质的一个有限采样代理；应当说明它覆盖了什么、遗漏了什么。

这个调整不要求增加模块。它要求将论文的主要主张从“共享 core 加记忆和一致性”移到**哪种原生计算可以被压缩、为何压缩后的对象仍能接收新观察并继续预测**，再由这一对象决定参数化。最终若仍与普通带状态的多时域蒸馏等价，就应承认该等价，而不能依靠“原生”“持续”等名称制造区别。

本建议不将项目改回旧 OIC 的行动关系库，也不把完整世界的预测状态重建设为目标；对象始终是当前 JEPA 主计算路径的可替代中间状态。
