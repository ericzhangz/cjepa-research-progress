\[
\hat z_{t+1}=F_\theta(z_t,a_t)+V D_\sigma(q_\theta(z_t,a_t))Q R\tilde m_t.

## 历史实现：把原生读出丢弃的激活送回同一个预测头

FourRoom LeWM 的 predictor 每一步先产生 2048 维 GELU 激活，最后线性读出 192 维预测。下一步只接收这 192 维。真实观察替换当前 latent 时，此前计算里具有同一读出的一整族激活也无法继续区分。若其中一些区别与未来动作响应有关，单纯增加观察刷新次数不会使它们恢复。

核心选择是**将原生读出矩阵的零空间作为回边的来源，并把回边接到同一个原生 GELU 之前**。原生读出决定什么可以跨观察保留，同一个非线性决定这些内容何时重新影响输出。这里选择的是已有计算里的自由度，并由预测头结构限定它的去向。

### 从观察替换推到状态和回边

令 \(q_a(z)\) 是冻结的 Transformer、projector 首层线性映射和 eval BatchNorm 得到的 preactivation。原生一步为 \(F_a(z)=V\sigma(q_a(z))+b\)，其中 \(V\in\mathbb R^{192\times2048}\) 是最终线性读出，\(\sigma\) 为原生 GELU。模型此处没有最终 LayerNorm。

收到观测编码 \(y\) 时，若要求 \(Vh^++b=y\)，并最小化 \(\|h^+-h^-\|_2^2\)，满行秩的 \(V\) 给出唯一解 \(h^+=h^-+V^\dagger(y-Vh^--b)\)。令 \(N=I-V^\dagger V\)，则 \(Nh^+=Nh^-\)。所以状态可以直接存为 \((z,m)\)，其中 \(m=Nh\)。观察到达只做 \((z,m)\mapsto(y,m)\)，无需构造 \(h^+\) 或保存旧图像。

若继续将 \(z\) 单独送回 predictor，\(m\) 永远无法影响预测。若将 \(m\) 加在 GELU 之后，\(Vm=0\) 又会把它消去。因此选用同一预测头已有的非线性混合：

\[
\begin{aligned}
g(a)&=\tanh(w^\top e(a)+\beta),\\
h_{t+1}&=\sigma\big(q_{a_t}(z_t)+g(a_t)m_t\big),\\
\hat z_{t+1}&=Vh_{t+1}+b,\qquad m_{t+1}=Nh_{t+1}.
\end{aligned}
\]

\(e(a)\) 是冻结的原生动作 embedding，增量只有标量回边强度，共 193 个可学习参数。零初始化使原生预测可直接恢复，\(m_0=0\)。\(N\) 在加载时用 \(V^\top\) 的薄 QR 形成正交行空间基 \(Q\)，每步实际计算 \(h-Q(Q^\top h)\)，无需构造 2048×2048 矩阵。

在同一个 \(z,a\) 下，\(g\) 很小时，回边对预测的首阶影响为 \(gV\operatorname{diag}(\sigma'(q_a(z)))m\)。如果这个向量的系数非零，足够小的非零回边必定改变预测。不同通道的 GELU 斜率由当下动作条件与 latent 共同决定，因此当前读出不可见的历史可以在下一步变得可见。若激活是线性的，所有 \(m\in\ker V\) 的作用都消失。这也是可证伪的结构判断。历史作用的方向是否对，要看它和真实预测误差的对齐程度。零空间的维数不能回答这一点。

该反馈有可计算的记忆边界。两条路径从某时刻起接收相同真实 \(z\) 和动作 \(a\)，由于 \(\|N\|_2=1\)，下一步的保留量差满足 \(\|\Delta m'\|_2\leq |g(a)|L_\sigma\|\Delta m\|_2\)，其中 GELU 的全局斜率上界约为 1.129。当前 FourRoom 留出分支中 \(|g|\) 最大约 .083，因此每个相同真实输入步对历史差异的直接传播上界约为 .094。自由 rollout 还会通过预测 \(z\) 传播差异，这个界只适用于固定真实输入时的回边。

### 真实未来如何进入计算

训练只优化 \(w,\beta\)，宿主参数和 BN 统计固定。真实观察序列按时间接入，观测间隔里的 \(m\) 用上述递推形成。给定最后一帧真实观察后，将同一个状态复制给各候选动作段，查询沿各自的 \(\hat z,m\) 自由展开。离线目标是多个到达时刻的真实 \(E(o_{t+h})\)，损失为坐标均方误差。观测替换阻断了旧 \(\hat z_t\) 的传播，但后继损失仍能沿 \(m_t\) 回传到之前的反馈强度。训练用的未来标签只在算损失时读取。执行期间每一步参数固定，假想分支的中间态不提交到真实流。

一次观察替换只更新 \(z\) 的 192 个坐标，继承已算的 \(m\)。后续每个模型步仍调用一次原生 core 和读出，并为零空间投影增加约 \(2\times2048\times192\) MAC。可以从同一递推取得多个跨度的结果。结构目前没有宏步、独立时域空间或更少的串行预测调用，贡献范围是跨观察继续使用原生中间计算。

### 实质区别和文献边界

- LeHami 从失败模式推出可从更新式证明的性质。本构造借用了这一推导方式，由 \(VN=0\) 推出观察替换性质，由 GELU 的坐标斜率推出后继可见性。AdaJEPA 说明反馈必须有具体作用位置，这里落在后继 predictor 的输入和同一非线性，而参数适配由离线真实未来完成。[LeHami](https://arxiv.org/html/2610.15267v1) · [AdaJEPA](https://arxiv.org/html/2606.32026v1)
- ID-WM 改的是计算对象的角色，本构造将原先一次性输出的宽层激活变成可续用的量。RWM 将训练信号施加到实际用到的构造上，本构造的真实未来误差直接反传经回边的 rollout。H-JEPA 的长时域表示与动作信息问题仍单独成立，本构造使用原本的预测坐标，对各跨度没有独立 predictor。[ID-WM](https://arxiv.org/html/2610.42146v1) · [RWM](https://arxiv.org/pdf/2609.29171v1) · [H-JEPA](https://arxiv.org/html/2610.06805v2)
- RSSM 和动作条件 RKN 已有观测更新与持续状态。DDNM 也已有同形的测量投影。这里的区别是用预训练 JEPA 的既有读出矩阵确定持续成分，再用同一个预测头的非线性让它在后继动作下可见。它属于受约束递归模型，投影和零空间可观测性已有先例。普通激活回灌与同帧校准是对应的直接参照。[PlaNet](https://proceedings.mlr.press/v97/hafner19a.html) · [ac-RKN](https://arxiv.org/abs/2010.10201) · [DDNM 式 (13)](https://arxiv.org/html/2212.00490v2#S3.SS1) · [输出零空间的递归动力学](https://pmc.ncbi.nlm.nih.gov/articles/PMC11421851/)

解析例、延迟执行器和原生 FourRoom 均已运行。延迟执行器中，同一观察、同一查询动作下，回边恢复了由先前执行动作决定的预测区别。FourRoom 中因果影响可测，但盲目继承全部零空间方向的标量回边未提高开发根的预测精度。完整结果和代价边界见[实验报告](../runs/readout_feedback_20261107/RESULTS.md)，代码见[实现](p1a/readout_feedback.py)。

## 1. 一项核心选择

**把一段原生预测计算压缩成一次调用时，同时保留该段结束后的可继续执行状态。用相同后续运算的输出，约束压缩前后的状态能够互相替代。**

方法围绕这一项选择构造。新增一个持久 token，让原生 predictor 同时更新当前 latent 与计算工作态；同一个 predictor 接受不同长度的动作块，也接受已经到达的观察。所有跨度共用权重与状态坐标。

所研究的贡献是“原生预测计算的时间压缩与持续接续如何共同学习”。记忆 token、仿射扫描、递归 Transformer 和一致性目标分别都有先例，本文不将它们单独作为原创点。最近的强参照包括带记忆的共享多时域 predictor、TD-VAE 与 Shortcut World Models，不能只比较无记忆的单步模型。

Mori–Zwanzig 为上一轮提供了“压缩后可能仍有未表达作用”的分析视角。本构造不实现一般 MZ 求解器，也不另外建立 Koopman 世界模型、观测器或层级规划系统。

## 2. 为什么端点预测不足以约束这件事

设一个可继续执行的状态为 W=(z,m)，当前可见输出为 z，下一步规则为 z'=m。两个状态 (z,m_1)、(z,m_2) 的当前输出完全相同，下一步输出仍可不同。如果观察写入只把 z 改成 y，这一区别也可以在之后重新出现。

这是一个反例，不是 FourRoom 的动力学模型。它说明：

\[
\hat z^{\rm coarse}_{t+h}\approx\hat z^{\rm fine}_{t+h}
\quad\not\Rightarrow\quad
\text{两者在随后动作或观察到来后仍然给出相近预测。}
\]

由此选择训练对象：压缩段应返回整个 W，并在相同后续计算中被使用。仅学习“当前状态到远端 latent”的读出没有施加这个约束。

这种后续可替代性是学习目标，不是由增加 token 自动保证的定理，也不意味着普通递归模型无法表达同一机制。

## 3. 工作态的具体定义

\[
W_t=(z_t,m_t),\qquad z_t,m_t\in\mathbb R^{192}.
\]

- z_t 保留 LeWM 的原生编码坐标。真实观察到达后取 E(o_t)；预测分支中取原生输出头的预测。
- m_t 是一个独立的持久残差流 token。它保存已经消费的视觉—行动经历对后续 predictor 运算仍有用的条件。
- m_t 的语义由后续预测作用定义，不提前命名为地图、速度、接触或慢变量。它不承诺包含完整世界状态。
- 任务开始时 m_0=0，再通过观察写入形成第一个工作态。各候选动作从同一个 W_t 分叉。

这里的 m 不是当前 z 的投影前副本。若从同一个 token 既读出 z 又直接拿其投影前激活当 m，二者可能高度冗余。本文使用两个不同 token 的输出。

真实时间 t、查询跨度 h、执行查询花费的计算量分别记录。工作态不会因为计算了一个假设未来，就被提交到那个真实时间。

## 4. 如何接入当前原生 predictor

当前实际宿主是 FourRoom flat LeWM：192 维 latent、4 个 ConditionalBlock、8 个 attention heads、MLP width 1024；每个模型动作块覆盖 5 个环境动作。已阅读当前运行使用的源码与配置：

- ARPredictor（原工程资料）
- ConditionalBlock 与 Transformer（原工程资料）
- ProjectedPredictor（原工程资料）
- FourRoom 配置（原工程资料）

令 G_θ 是原生 Transformer，N_θ 为其末端归一化与输出映射，P_θ 为原生 latent projector。扩展后的单次调用定义为

\[
(h_z,h_m)=G_\theta\left(
[z+p_0,\ m+p_m],\ [c,c]\right),
\qquad
\mathcal G(W,c)=\left(P_\theta(N_\theta h_z),\ N_\theta h_m\right). \tag{1}
\]

p_0 使用原生当前帧位置，p_m 是一个学习的 token 类型向量。两个 token 表示同一时刻的不同计算内容，允许双向注意；它们不是两个真实时间帧。未来信息仍由外层时间展开限制。

原生 ConditionalBlock 的实际运算保持为

\[
x\leftarrow x+g_A(c)\odot\mathrm{Attn}(\mathrm{LN}(x)\odot(1+s_A(c))+b_A(c)),
\]
\[
x\leftarrow x+g_M(c)\odot\mathrm{MLP}(\mathrm{LN}(x)\odot(1+s_M(c))+b_M(c)). \tag{2}
\]

状态 token 与 memory token 在同一组 attention/MLP 中交互；条件 c 经现有 adaLN_modulation 产生 shift、scale、gate。z 输出仍经过原生 projector；m 输出不另设预测网络。

实现时在当前主路径扩展为显式的“双 token 状态调用”，不要继续把它传给原来的历史窗口接口并冒充真实帧。原生 Attention 支持 causal 参数，但现有 ConditionalBlock 默认调用因果注意，需要在这个明确入口传入双 token 的完整 attention mask。原先保存的冻结运行保持为历史结果。

**学习范围已明确：**冻结视觉 encoder、原生动作 embedder 和原生输出 projector；以预训练权重初始化并微调 predictor 的 Transformer，学习 p_m 和下节的小动作块编码器。推理期所有参数固定，只有 W 更新。双 token 和观察模式需要离线学习，不能未经训练直接插入冻结 checkpoint。

这增加了一个持久 token，没有独立 GRU、观测更新网络、粗层 predictor 或新的物理状态解码器。微调的是已有 predictor，不是新增一套世界模型。

## 5. 一个具体的动作块编码器

需要保留动作顺序，不能只取动作平均值。给出如下小型、可组合的标准实现；这个编码器是工程原语，不是方法创新。

每个已归一化的原生动作块 a_i∈R^10，经冻结原生 embedder 得到 e_i∈R^192。用宽度 r=32 的仿射扫描：

\[
d_i=\sigma(D e_i+b_D),\qquad v_i=V e_i+b_V,
\]
\[
b_0=0,\qquad b_{i+1}=d_i\odot b_i+v_i.
\]

长度为 h 的片段 α 的条件为

\[
c_h(\alpha)=e_{h-1}+R b_h+u\log h,\qquad h\geq1. \tag{3}
\]

初始化 R=0、u=0，短步条件从已有动作嵌入起步。训练后所有跨度都使用式 (3)，不为不同 h 建立不同预测头。宽度 r 控制动作顺序摘要的容量；32 是初始实现选择，不具有理论特殊性。

仿射对的组合为

\[
(d_2,v_2)\star(d_1,v_1)
=(d_2\odot d_1,\ d_2\odot v_1+v_2). \tag{4}
\]

式 (4) 严格结合，能顺序或并行计算动作摘要，通常保留顺序差异。但对角线形式存在表达限制，有限摘要并不保证区分所有动作序列。**严格结合的是动作编码运算，不是整个 JEPA 的世界动力学。**

训练初始支持 h=1,…,16；更长查询按支持跨度分段。这个上限控制训练与单段近似的范围，不代表 h>16 不可预测，也不支持未经训练的任意跨度一步外推。

## 6. 推进与真实观察写入共用一个核心

### 动作推进

\[
T_h(W_t,\alpha)=\mathcal G(W_t,c_h(\alpha))
=(\hat z_{t+h},\hat m_{t+h}). \tag{5}
\]

细步是 h=1 的同一操作。粗步输出完整 W，因此可以直接接另一个粗步、一个细步或一次真实观察写入。原生 predictor 内部的状态相关非线性交互仍然存在；动作摘要本身不承担完整世界动力学。

### 真实观察写入

对已到达的 z^{obs}=E(o_t)，用一个学习的模式向量 e_obs 定义

\[
O(W^-,z^{obs})=
\left(z^{obs},\ \pi_m\mathcal G(W^-,z^{obs}+e_{obs})\right). \tag{6}
\]

完整预测前驱 (z^-,m^-) 和实际观察都进入同一个 Transformer。观测模式不推进物理时间；该次 latent 输出不作为事实，z 分量直接取实际编码。m 分量根据预测前驱与实际观察共同更新。

式 (6) 是一个具体的学习更新规则，不是精确 Bayes 更新定理。它的监督来自写入之后的预测任务，避免仅重建当前帧就完成所谓修订。观察写入使用已有条件通道的新类型，离线微调让同一 core 学会两类调用。

### 实际任务中的完整顺序

```text
初始化：z = E(首帧)，W = O((z, 0), z)

每次获得新的真实观察：
    用实际已执行的动作前缀推进 W，得到 W_minus
    z_obs = E(已经到达的图像)
    W = O(W_minus, z_obs)

需要比较候选动作时：
    每个候选都从同一个 W 复制出分支
    将动作序列按训练支持的跨度分段
    每段调用同一个 T_h，保存所需端点的 z 和完整分支 W
    使用既定目标代价评分；未执行的分支不写回实际 W
```

多个端点可共用一条分段推进。例如请求 1、2、4、8、16，可执行长度 1、1、2、4、8 的五段。此时每段返回的完整状态承担下一段计算；不是每个端点都从头调用一个独立 head。

## 7. 决定方法身份的学习约束

取相同起点 W_t 与一段实际记录的动作 α，长度 h。构造

\[
W_c=T_h(W_t,\alpha),\qquad
W_f=T_1(\cdots T_1(W_t,a_t)\cdots,a_{t+h-1}). \tag{7}
\]

两条路径在 α 内都不读取未来真实观察。细步路径不能拿教师强制真帧，而让粗步路径只看动作，然后要求两者等价。

接着从当前宿主的合法候选动作生成分布 μ 中抽取后续动作段 β。该生成器只使用当前合法信息，沿用宿主动作边界；不另训练候选网络，也不根据未来结果筛选。两条路径使用相同 β。令 T_1^β 表示按 β 连续调用细步核，选择以下两类后续计算：

\[
C_{\rm act}(W)=T_1^\beta(W),
\]
\[
C_{\rm obs}(W)=T_1^\beta(O(W,E(o_{t+h}))),\qquad |\beta|\geq1. \tag{8}
\]

第二类先在实际记录段 α 的端点写入已到达观察，再分叉到候选 β。从反事实 β 分叉以后，不再输入原记录轨迹的后续图像，也不把其终点当作该分支真值。不比较刚写入时的 z，因为两边直接取同一真值会使该比较平凡为零。两边统一使用细步续算，直接约束压缩状态对原生后续计算的作用，避免另一个学习中的粗续段掩盖差异。

续算替换目标是

\[
\mathcal L_{sub}=\mathbb E_{t,h,\beta\sim\mu,\omega}
\frac1{192}\left\|
\pi_z C_\omega(W_c)
-\operatorname{sg}[\pi_z C_\omega(W_f)]
\right\|^2. \tag{9}
\]

真实预测损失独立使用实际记录的 α 及其真实后续动作 γ。两条路径的端点和这些实际后续结果以固定真实 encoder 的输出为目标：

\[
\mathcal L_{data}=\mathbb E\left[
\frac1{|\mathcal S|}\sum_{(b,\tau)\in\mathcal S}
\frac1{192}\|\hat z^{\,b}_\tau-\operatorname{sg}E(o_\tau)\|^2
\right]. \tag{10}
\]

S 包含细步和粗步在 t+h 的端点，以及用真实后续 γ 续算的目标。没有匹配真实结果的候选 β 只参与式 (9) 的计算蒸馏，不参与真实预测损失。真实未来仅用于离线目标或在明确的观察到达事件中输入。任务内工作态从对应时刻之前的真实经历生成。

这一分工决定了两个目标的不同作用：真实轨迹约束预测应当是什么；候选动作续算约束时间压缩后仍保留原生计算对不同动作的响应。若两个目标都只作用于同一条记录后续，续算一致性主要只是对同一真值双路拟合的附加正则，不能声称增加了新的响应监督。候选续算提供额外的计算监督范围，但细步参考仍是模型预测，不是反事实物理真值。

总目标为

\[
\mathcal L=\mathcal L_{data}+\lambda\mathcal L_{sub},\qquad \lambda=1\text{ 为初始设置}. \tag{11}
\]

两项均按同一原生 latent 维度和样本平均归一化。λ 只控制“真实未来拟合”与“压缩后续算一致”之间的权衡；后续与 λ=0 的同结构对照才能将作用归因于此绑定。r=32、最大单段跨度16与 λ=1 是明确可改的实现选择，不是论证中的数学常数。

训练在同一个模型上联合进行，不引入独立教师网络或新的奖励、IDM、目标评分 loss。stop-gradient 只作用于式 (9) 的细步参考；式 (10) 仍直接训练细步与粗步路径，避免只复写细步模型自身的错误。

沿真实片段随机选择观察到达位置，因果展开工作态，再抽取压缩段、真实后续及合法候选后续。初始 h 与后续长度均从 1,…,16 的可用范围采样。按 episode 初始化，采用截断反向传播管理训练内存。优化器沿用宿主 AdamW 设置；新增参数与 predictor 同一训练过程更新。

这里没有把 m 的欧氏坐标对齐作为主要目标。m 只需保留后续原生运算所需的区别；续算输出提供这种功能约束。该目标仍只覆盖训练采样的后续条件，不保证任意后续上的完全等价。

## 8. 多时域能力与计算收益的来源

多时域来自式 (5) 对动作片段的一次执行，以及完整 W 的可接续性。式 (9) 明确训练这种接续。它不要求在上层建立独立 latent space，也不要求逐细步生成所有中间 z。

设 C_1 为原生单帧一次 predictor 成本，C_2 为双 token core 加一次原生 latent 输出的成本，C_a(H) 为 H 个动作的编码和组合成本。查询使用 J 个分段，则

\[
C_{base}\approx H C_1,
\qquad C_{method}\approx C_a(H)+J C_2. \tag{12}
\]

C_a(H) 至少包含 O(H) 的输入读取。C_2 大于 C_1 的可能性必须计入；不能用调用次数比例冒充实际加速。只有 H C_1 > C_a(H)+J C_2 时，这次查询才节约计算。

每个新观察还有实际前缀推进和一次 O 的维护成本。该成本在同起点的 N 个候选之间共享，过去经历不再完整重编码。总成本需要把启动、维护、动作编码、全部查询和训练分别列出。已有输入缓存优化作为共同工程条件，不属于新贡献。

若请求每个中间端点，J 接近 H，计算优势可能消失。若为保持准确必须不断把宏步拆成细步，也会失去优势。这里不加入学习调度器；初始分块按请求端点和支持跨度直接确定。

该方法减少的是所需端点之间的 predictor 展开，不自动减少候选动作搜索的维数。它也没有证明更多无观察内部迭代会使共同真实工作态越来越正确。没有新观察时，可以继续已有预测分支或发起新查询；这项能力应准确称为持续状态上的多时域计算。

## 9. 与现有方法的实质关系

| 方法 | 同样具有的部分 | 本提案明确新增或改变的部分 |
| --- | --- | --- |
| 普通递归 JEPA / RSSM | 因果工作态、动作推进、观察影响后续预测 | 将多个细步替换为同 core 的宏步，并训练其完整结果可继续执行；普通递归本身仍可实现这些结构，不能宣称表达能力上严格超越 RNN |
| 递归状态＋直接多时域读出 | 持久历史与多个未来端点 | 远期输出返回完整 W，并受动作续算和观察后续算约束；仅有多个端点头没有这项要求 |
| 共享权重多时域 predictor | 同一个预测器支持不同跨度 | 将持久原生中间状态和跨观察续算纳入片段替换目标；这是最近的结构参照，必须正面比较 |
| HWM / H-JEPA | 时间跨度扩展、用 latent 进行预测与规划 | 不建立独立预测层级；同一 W 可以交替接细步、粗步、观察写入。H-JEPA 的独立抽象目标空间是其额外能力，本提案没有自动获得 |
| RMT / SSM 与动作扫描 | 记忆 token 或便宜序列聚合 | 这些是实现原语；仅增加它们不足以构成本提案的贡献 |
| TD-VAE / Shortcut World Models | 信念或 latent 的跨步预测、远期接续思想 | “会跳步”“有状态”已有先例。拟研究的具体差异是预训练 JEPA 原生中间计算的跨观察续算替换，不声称这些论文缺少一切相似思想 |
| AdaJEPA | 真实经历影响后续预测 | 本提案任务内只变 activation，离线训练宏步与观察写入；AdaJEPA 在真实执行循环中更新参数。参数与 activation 的区别本身不构成创新 |

若把本提案相同的共享 core、完整状态宏转移、观察写入和式 (9) 全部加入“递归多时域基线”，它就已经实现了本提案；不能继续声称两者仍属于不同算法。真正需要研究的是，这项额外绑定是否让同等结构的模型获得更可靠的片段替换与更好的质量—计算关系。

因此，候选贡献是一项具体的原生 JEPA 改造与学习原则，不是新半群定理，也不是宣称发现了此前不存在的模型类别。多步学习、预测状态与功能蒸馏都是已有思想；包括 [PlaNet 的 latent overshooting](https://proceedings.mlr.press/v97/hafner19a.html) 在内的先例意味着多步一致性本身不是贡献。当前检索不能支持“首次提出”的表述。

## 10. 这份构造已经决定了什么

已决定：一个192维持久 token；当前 latent 与它组成联合状态；一个原生 Transformer 核；一个小动作片段编码器；同核观察写入；真实预测与续算替换两个目标；按支持跨度执行的宏步；完整的维护与查询成本式。

尚待经验回答的是这些选择是否能学到有用工作态、可用宏步跨度有多大，以及在真实任务中是否有净收益。此外，本轮深读明确了一项仍属方法构造的问题：宏步为何来自任务中已形成的原生计算，以及该内容怎样在新观察后保留可用性。该问题不能仅交给 token 与损失自行发现。它由当前创新构造工作继续处理，不通过增加冻结诊断替代，也不自动以本草案启动训练。

本文没有解决未知随机未来的恢复、任意长动作序列的无损压缩、自动形成合理目标距离，或固定证据下自主计算的单调改进。它给出了本次五项要求对应的一条完整计算路径，没有用未定义的更新函数留出主体算法。
